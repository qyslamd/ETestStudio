## 常见问题

### 约束条件常见的编写问题：  

- 字符串要用英文引号引用。例如："制冷"
- 语句结尾用英文分号";"结束。
- 参数名称用英文括号括起来。例如：if [温度传感器]==40  then [工作模式]=="制冷" ;
- 控制语句的赋值表达式，要覆盖所有取值的情况。例如：

错误实例：

```lua
if  [温度传感器]==40  then [红外接收器指令]=="16" else [红外接收器指令]=="30" ; 

```
#此语句问题是，“温度传感器”40的用例中，把“红外接收器指令”赋值为16。否则“红外接收器指令”赋值为30，   
那么生成的用例中“红外接收器指令”就缺少了其他值的覆盖。因此不成立，语句有误。
