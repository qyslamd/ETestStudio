## 安装配置
### Windows
- 下载或者复制软件压缩包至本地
- 鼠标右键进行解压并选择指定的解压路径，直至解压完成
- 打开解压目录下的dev目录
- 双击该路径下的exe可执行程序即可完成启动

    **注意：**
    - **软件为绿色免安装版，无需安装，解压即可启动运行**
    - **首次启动时系统会提示是否允许访问网络，必须选择允许**
    - **安装路径下不能存在中文**       
             
- 如果 ETestD4 无法启动，可能是系统缺少运行时库，请执行以下操作
    - 双击安装目录下`VC_redist.x64`
    - 勾选`我同意许可条款和条件`后，点击`安装` 
    - 等待安装完成，安装完成后重启计算机
### Linux
#### 桌面操作系统
- 复制软件安装包至Linux系统文件路径下
- 解压安装包
- 在解压路径下执行命令`cd setup `进入安装目录
- 执行`sudo sh install setup.sh desk`即可完成安装
- 重启计算机
#### 实时下位机
- 复制软件安装包至Linux系统文件路径下
- 解压安装包
- 在解压路径下执行命令`cd setup `进入安装目录
- 执行`sudo sh install setup.sh serve`即可完成安装
- 重启计算机  
### Macos
- 安装方法同Windows
