## 使用开关量输入通道
该通道支持以下操作：read_digital、read_digital_sync、read_digital_multi_sync、on_digital_recv

### 简介
开关量输入通道又称数字量输入通道, 是一种用于将数字信号输入到计算机系统中的接口。它可以将开关、按钮、传感器等数字信号转换为计算机可以识别的二进制信号。数字量输入通道通常由数字量输入模块提供, 这些模块可以插入到计算机系统的扩展槽中或通过网络连接到计算机系统

数字量输入通道的主要特点是其输入信号只能是0或1, 即数字信号。这种输入通道通常用于监测和控制数字信号, 例如开关状态、按钮按下、传感器信号等。数字量输入通道在工业自动化、机器人控制、安防监控等领域中广泛应用

### 开关量输入通道的属性配置
- maxu：值类型为number, 最大工作电压

### 开关量输入通道的数据读写
**1.异步读开关量输入**
> local r_res = read_digital(channel)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.value：boolean类型, 读取到的值

**2.同步读开关量输入**
> local r_res = read_digital_sync(channel)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.value：boolean类型, 读取到的值

**3.同步读多个开关量输入**
>local r_res = read_digital_multi_sync(channel1_list)
- 输入参数：
    - channel1_list：array类型, 通信通道对象组成的数组
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.values：array类型, 读取到的值

**4.开关量输入事件订阅**
> on_digital_recv(channel, callback)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - callback：function类型函数原型为fn(ch, res)
        - ch: EChannel类型, 通信通道对象
        - res: dict类型, 事件触发的消息
