## 使用开关量输出通道
该通道支持以下操作：write_digital、write_digital_sync、write_digital_multi_sync

### 简介
开关量输出通道又称数字量输出通道, 是一种用于控制数字信号输出的通道, 通常用于控制开关、继电器、电机等设备的开关状态。数字量输出通道可以将数字信号输出为高电平或低电平, 从而实现对设备的控制

数字量输出通道通常具有以下特点：
1. 输出电平稳定：数字量输出通道的输出电平通常比较稳定, 能够保证设备的稳定运行
2. 输出电流大：数字量输出通道的输出电流通常比较大, 能够驱动需要较大电流的设备
3. 输出方式多样：数字量输出通道的输出方式可以是开关式、脉冲式、PWM调制式等多种方式
4. 可编程控制：数字量输出通道通常可以通过编程来实现对输出信号的控制, 可以根据不同的需求来设置输出信号的频率、占空比等参数


### 开关量输出通道的属性配置
- maxu：值类型为number, 最大工作电压
- init：值类型为number, 通道初始状态

### 开关量输出通道的数据读写
**1.异步写开关量输出**
> local r_res = write_digital(channel, value)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - value：boolean/number类型, 输出状态值(true、false、1、0)
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.value：boolean/number类型, 输出值

**2.同步写开关量输出**
> local r_res = write_digital_sync(channel, value)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - value：boolean/number类型, 输出状态值(true、false、1、0)
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.value：boolean/number类型, 输出值

**3.同步写多个开关量输出**
> local r_res = write_digital_multi_sync(channel_list, value_list)
- 输入参数：
    - channel_list：array类型, 同时输出通信通道对象组成的数组
    - value_list：array类型, 通信通道对象对应的状态值, 值为boolean类型
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.values：array类型, 写出的值
