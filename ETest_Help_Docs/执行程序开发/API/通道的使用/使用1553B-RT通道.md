## 使用1553B-RT通道
该通道支持以下操作：read_buff、read_buff_sync、read_msg、read_msg_sync、write_buff、write_buff_sync、write_msg、write_msg_sync、on_buff_recv、iocmd
### 简介

1553B-RT又称远程终端，具有以下特点：

1. 高可靠性：采用冗余设计，即使在某个通道出现故障时，仍然可以继续传输数据。

2. 实时性：通信延迟低，能够满足实时数据传输的要求。

3. 多点通信：支持多个设备同时进行通信，通过区分器（Bus Controller）控制通信流程。

4. 高速传输：数据传输速率可达到最高每秒1Mbit。

### 1553B-RT通道的配置及属性

- voltage：输出工作电压(V)，值类型为 number
- mode：工作模式，值类型为 string，可选 1M/4M
- coupling：耦合方式，值类型为 string，可选 none(默认)/direct(直接耦合)/transformer(变压器耦合)
- aotu_changebus：自由切换总线，值类型为boolean
- en_code：使用模式代码，值类型为boolean
- en_broadcase：使能广播，值类型为 bool
- en_internalbus：使用内部总线，值类型为boolean

### 1553B-RT通道的数据读写
**1.异步写入RT通道原始数据**
> local w_res = write_buff(channel, buff, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - buff：EBuff类型, 数据缓存
    - option：dict类型
        - option.address：number类型，地址
        - option.sub_address：number类型，子地址
        - option.bufferid：number类型，缓存区索引
- 返回值
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.size：number类型, 输出的字节长度
        - w_res.value：EBuff类型, 输出值

**2.同步写入RT通道原始数据**
> local w_res = write_buff_sync(channel, buff, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - buff：EBuff类型, 数据缓存
    - option：dict类型
        - option.address：number类型，地址
        - option.sub_address：number类型，子地址
        - option.bufferid：number类型，缓存区索引
- 返回值
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.size：number类型, 输出的字节长度
        - w_res.value：EBuff类型, 输出值

**3.异步写入RT通道消息数据**        
> local w_res = write_msg(channel, prot, msg, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - prot：EProtocol类型, 协议对象
    - msg：dict类型, 报文数据
    - option：dict类型
        - option.address：number类型，地址

- 返回值：

        - w_res.size：number类型, 输出的字节长度
        - w_res.value：EBuff类型, 输出值

**4.同步写入RT通道消息数据**

- 返回值：

        - w_res.value：EBuff类型, 输出值

**5.异步读取RT通道原始数据**
> local r_res = read_buff(channel, size, tout_ms, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - size：number类型, 需要读取的字节长度, 0表示全部读取
    - tout_ms：number类型, 超时时长（单位ms）, 超时返回nil
    - option：dict类型
        - option.address：number类型，地址
        - option.sub_address：number类型，子地址
        - option.bufferid：number类型，缓存区索引
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.size：number类型, 读取到的数据缓存字节长度
        - r_res.value：EBuff类型, 读取到的数据缓存结果

**6.同步读取RT通道原始数据**

**9.事件订阅**
> on_buff_recv(channel, fn)
- 输入参数：
	- channel：EChannel类型, 通信通道对象
	- fn：回调函数, 函数原型为fn(ch, res)
        - ch: EChannel类型, 通信通道对象
        - res: dict类型, 事件触发的消息

**10.事件订阅获取数据更新次数**
> local opt = ebuff.first_frame_option(buff)
- 输入参数：
	- buff：Ebuff类型, 事件订阅数据缓存(res.value)
- 返回值：
	- opt：dict类型
        - opt.updated: number类型，数据更新的次数

### 1553B-RT通道IO命令
**1.启动BC通道**
>  local b = iocmd(channel, "Start", {})
- 输入参数：
    - channel：EChannel类型, 通信通道对象
- 返回值：
	- b：boolean类型, true表示成功

**2.停止BC**
> local b = iocmd(channel, "Stop", {})
- 输入参数：
	- channel：EChannel类型, 通信通道对象
- 返回值：
	- b：boolean类型, true表示成功

**3.执行非周期消息**
> local  = iocmd(channel，"RunAperiod"，option)
- 输入参数：
	- channel：EChannel类型, 通信通道对象
	- option: dict类型
		- option.id: 消息ID
		- option.emerg: boolean类型，可选参数是否紧急
- 返回值：
	- b：boolean类型, true表示成功
