## 使用模拟量输出通道
该通道支持以下操作：write_analog、write_analog_sync、start_write_analog
### 简介
模拟量输出通道是指可以通过该通道输出模拟信号的通道。模拟信号是连续变化的信号, 例如电压、电流、温度等

模拟量输出通道通常由模拟量输出模块提供, 它们可以将数字信号转换为模拟信号, 并通过输出通道输出

模拟量输出通道通常具有以下特点：
1. 输出范围：模拟量输出通道可以输出一定范围内的模拟信号, 例如0-10V或4-20mA。
2. 分辨率：模拟量输出通道的分辨率通常是指数字信号与模拟信号之间的转换精度, 例如12位分辨率的模拟量输出通道可以将数字信号转换为4096个不同的模拟信号值。
3. 稳定性：模拟量输出通道的稳定性是指输出的模拟信号的稳定性和精度。稳定性越高, 输出的模拟信号越精确。
4. 响应时间：模拟量输出通道的响应时间是指从数字信号输入到模拟信号输出的时间。响应时间越短, 输出的模拟信号越及时

### 模拟量输出通道的配置及属性
- minu：值类型为number, 电气量最小值
- maxu：值类型为number, 电气量最大值
- mind：值类型为number, 电气量最小值对应的工程量最小值
- maxd：值类型为number, 电气量最大值对应的工程量最大值
- unit：值类型为string, 电气量单位
- unitd：值类型为string, 工程量单位
- adjust：值类型为number, 电气量误差校准, 校准通道输出

### 模拟量输出通道数据读写
**1.异步写模拟量输出**
> local r_res = write_analog(channel, value)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - value：float类型, 输出的值
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 执行时的时间（ns）
        - r_res.value：float类型, 输出的值

**2.同步写模拟量输出**
> local r_res = write_analog_sync(channel, value)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - value：float类型, 输出的值
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 执行时的时间（ns）
        - r_res.value：float类型, 输出的值

**3.模拟量波形输出**
> local res = start_write_analog(rate, opt1,  opt2, ......, optn)
- 输入参数：
    - rate：nunber类型, 采样率
    - opt1 ~ optn：dict类型
        - opt1.channel：EChannel类型, 通信通道对象
        - opt1.data：array类型, 波形输出的数据
- 返回值：
    - res：dict类型
        - res.timestamp：number类型, 启动时间（ns）
        - res.task_id：number类型, 任务ID
