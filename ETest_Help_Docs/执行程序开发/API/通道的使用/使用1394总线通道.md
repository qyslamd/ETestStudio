## 使用1394通道
该通道支持以下操作：read_buff、read_buff_sync、read_msg、read_msg_sync、write_buff、write_buff_sync、write_msg、write_msg_sync、on_buff_recv、iocmd
### 简介
1394通道，也称为FireWire或i.LINK，是一种高速串行数据传输接口，它提供了一种快速、可靠的数据传输方法，用于连接计算机、音频/视频设备、外部存储设备和其他外围设备。

1394通道具有以下特点：

1. 高速传输：1394通道支持高达400 Mbps（FireWire 400）或800 Mbps（FireWire 800）的数据传输速度，远远超过了传统的并行接口。

2. 热插拔能力：1394通道支持热插拔功能，这意味着可以在计算机运行时插入或拔出设备，而无需重新启动计算机。

3. 灵活性：1394通道支持点对点和多点连接，可以通过简单的拓扑结构连接多个设备。它还支持链式连接，允许多个设备通过一个接口连接到计算机。

4. 实时性：1394通道具有低延迟和高带宽的特性，非常适用于实时音频和视频数据传输。

5. 自供电：1394通道可以为外部设备提供电源，无需额外的电源适配器。

6. 支持多种数据类型：1394通道可以传输多种数据类型，包括音频、视频、图像和数据文件等。

### 1394通道的配置及属性

- config_file：选择1394节点配置文件，值类型为string

### 1394通道的数据读写
**1.异步写入原始数据**
> local w_res = write_buff(channel, buff, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - buff：EBuff类型, 数据缓存
    - option：dict类型
        - option.msgID：number类型, 消息ID
- 返回值
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.size：number类型, 输出的字节长度
        - w_res.value：EBuff类型, 输出值

**2.同步写入原始数据**
> local w_res = write_buff_sync(channel, buff, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - buff：EBuff类型, 数据缓存
    - option：dict类型
        - option.msgID：number类型, 消息ID
- 返回值
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.size：number类型, 输出的字节长度
        - w_res.value：EBuff类型, 输出值

**3.异步写入消息数据**        
> local w_res = write_msg(channel, prot, msg, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - prot：EProtocol类型, 协议对象
    - msg：dict类型, 报文数据
    - option：dict类型
        - option.msgID：number类型, 消息ID
- 返回值：
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.size：number类型, 输出的字节长度
        - w_res.value：EBuff类型, 输出值

**4.同步写入消息数据**
> local w_res = write_msg_sync(channel, prot, msg, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - prot：EProtocol类型, 协议对象
    - msg：dict类型, 报文数据
    - option：dict类型
        - option.msgID：number类型, 消息ID
- 返回值：
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.size：number类型, 输出的字节长度
        - w_res.value：EBuff类型, 输出值

**5.异步读取原始数据**
> local r_res = read_buff(channel, size, tout_ms, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - size：number类型, 需要读取的字节长度, 0表示全部读取
    - tout_ms：number类型, 超时时长（单位ms）, 超时返回nil
	- option：dict类型
		- option.msgID：number类型, 消息ID
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.size：number类型, 读取到的数据缓存字节长度
        - r_res.value：EBuff类型, 读取到的数据缓存结果

**6.同步读取原始数据**
> local r_res = read_buff_sync(channel, size, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - size：number类型, 需要读取的字节长度, 0表示全部读取
	- option：dict类型
		- option.msgID：number类型, 消息ID
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.size：number类型, 读取到的数据缓存字节长度
        - r_res.value：EBuff类型, 读取到的数据缓存结果

**7.异步读取消息数据**    
> local r_res = read_msg(channel, prot, tout_ms, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - prot：EProtocol类型, 协议对象
    - tout_ms：number类型, 超时时长（单位ms）, 超时返回nil
	- option：dict类型
		- option.msgID：number类型, 消息ID
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.size：number类型, 读取到的数据缓存字节长度
        - r_res.value：EBuff类型, 读取到的数据缓存结果

**8.同步读取消息数据**
> local r_res = read_msg_sync(channel, prot, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - prot：EProtocol类型, 协议对象
	- option：dict类型
		- option.msgID：number类型, 消息ID
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.size：number类型, 读取到的数据缓存字节长度
        - r_res.value：EBuff类型, 读取到的数据缓存结果

**9.事件订阅**
> on_buff_recv(channel, fn)
- 输入参数：
	- channel：EChannel类型, 通信通道对象
	- fn：回调函数, 函数原型为fn(ch, res)
        - ch: EChannel类型, 通信通道对象
        - res: dict类型, 事件触发的消息

**10.事件订阅获取附件属性**
> local opt = ebuff.first_frame_option(buff)
- 输入参数：
	- buff：Ebuff类型, 事件订阅数据缓存(res.value)
- 返回值：
	- opt：dict类型
        - opt.msgID: number类型，消息ID
        - opt.Heartbeat: number类型，32位整数心跳
        - opt.type: number类型，节点类型
        - opt.nodeID: number类型，节点ID
### 1394通道IO命令
**1.设置通道属性**
>  local b = iocmd(channel, "SetConfig", option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - option: dict类型
        - option.Heartbeat: number类型，32位整数心跳值
        - option.HeartStatus: number类型，心跳状态
- 返回值：
	- b：boolean类型, true表示成功
