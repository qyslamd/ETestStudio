## 使用模拟量输入通道
该通道支持以下操作：read_analog、read_analog_sync、start_read_analog、on_analog_recv
### 简介
模拟量输入通道是指用于接收模拟量信号的通道, 通常用于测量温度、压力、流量等物理量的变化。模拟量输入通道可以通过传感器将物理量转换成电信号, 然后将电信号传输到数据采集设备中进行处理和分析

模拟量输入通道通常包括以下几个方面：

1. 信号输入：模拟量输入通道需要提供相应的接口, 以便将传感器输出的模拟量信号输入到数据采集设备中
2. 信号转换：模拟量输入通道需要将传感器输出的模拟量信号转换成数字信号, 以便后续的数字信号处理
3. 采样率：模拟量输入通道需要提供足够高的采样率, 以确保能够捕捉到物理量的变化, 同时还需要保证采样率不会过高, 以免增加数据处理的复杂度
4. 分辨率：模拟量输入通道需要提供足够高的分辨率, 以确保能够捕捉到物理量的微小变化
5. 精度：模拟量输入通道需要提供足够高的精度, 以确保采集到的数据能够准确反映物理量的变化
### 模拟量输入通道的配置及属性
- minu：值类型为number, 电气量最小值
- maxu：值类型为number, 电气量最大值
- mind：值类型为number, 电气量最小值对应的工程量最小值
- maxd：值类型为number, 电气量最大值对应的工程量最大值
- unit：值类型为string, 电气量单位
- unitd：值类型为string, 工程量单位
- event_ratio：值类型为number, 工程量-事件订阅函数触发精度

### 模拟量输入通道数据读写
**1.异步读模拟量输入**
> local r_res = read_analog(channel)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.value：float类型, 读取到的值

**2.同步读模拟量输入**
> local r_res = read_analog_sync(channel)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.value：float类型, 读取到的值

**3.模拟量输入事件订阅**
> on_analog_recv(channel, callback)
- 输入参数：
- channel：EChannel类型, 通信通道对象
- callback：function类型函数原型为fn(ch, res)
	- ch: EChannel类型, 通信通道对象
	- res: dict类型, 事件触发的消息

**4.连续采集**
> local res = start_read_analog(rate, opt1, opt2, ......, optn)
- 输入参数：
    - rate：nunber类型, 采样率
    - opt1 ~ optn：dict类型, 
        - opt1.channel：EChannel类型, 通信通道对象
        - opt1.topic：any类型, 主题数据标识
- 返回值：
    - res：dict类型
        - res.timestamp：number类型, 采集开始时间（ns）
        - res.task_id：number类型, 任务ID
