# QScintilla 2.11.3 Demo for Qt 5.12.12

## 已实现特性

### 1. 基础编辑特性
- ✅ 行号显示：左侧边栏显示行号
- ✅ 代码折叠：支持函数/代码块折叠（点击左侧折叠图标）
- ✅ 括号匹配：自动高亮匹配的括号，不匹配时标红
- ✅ 自动缩进：回车后自动对齐缩进，Tab宽度4个空格

### 2. 多语言支持
支持4种语言语法高亮切换：
- C++
- Python
- JavaScript
- HTML

每种语言自带示例代码，可通过顶部下拉框切换。

### 3. 代码补全
内置常见关键词补全，输入2个字符后自动弹出补全列表，支持：
- C++ 关键词：int, float, class, if, for 等
- Python 关键词：def, import, class 等
- JavaScript 关键词：function, const, let, var 等

### 4. 辅助功能
- ✅ 当前行高亮：光标所在行背景高亮显示
- ✅ 缩放功能：Ctrl + 鼠标滚轮 放大/缩小字体
- ✅ 空白符显示：缩进后的空格和制表符可见
- ✅ 断点标记：点击左侧行号旁边的边栏添加/删除红色断点标记

### 5. 搜索替换
- 输入搜索关键词后按回车或点击"查找"按钮搜索
- 找到匹配项后输入替换内容点击"替换"按钮替换

## 编译运行
依赖已经配置好，直接编译项目即可运行，运行后会自动生成 `run_qscintilla-demo.bat` 脚本。
