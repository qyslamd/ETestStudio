## 二、各模块技术细节
### 1. 核心数据结构
测试用例采用自定义JSON格式存储，后缀`.etcase`，核心结构：
```json
{
  "version": "1.0",
  "name": "测试用例名称",
  "description": "用例描述",
  "param_list": [
    {"name": "参数名", "type": "string/int/float", "values": ["值1", "值2"]}
  ],
  "action_list": [
    {"type": "动作类型", "params": {}, "comment": "注释"}
  ]
}
```

### 2. 编辑器UI
采用左右布局方案：
- 左侧动作库面板：按4大类分类折叠展示所有动作，支持搜索，动作可拖拽到右侧表格
- 右侧表格编辑区：每行对应一个动作，参数直接在表格单元格内嵌编辑器编辑，操作高效直观

### 3. 动作组件明细
| 动作分类 | 包含动作 | 实现细节 |
|----------|----------|----------|
| 基础动作 | 变量声明、延时（支持变量延时）、打印日志、自定义Lua脚本、退出用例 | 自定义Lua脚本支持访问测试用例上下文变量 |
| IO动作 | 原始字节数据收发、ICD协议报文收发、模拟量采集/输出、数字量采集/输出 | IO动作支持下拉选择已配置的设备通道+已定义的ICD协议，自动关联ICD打包解包能力，用户仅需填写字段值 |
| 测试动作 | 合格/失败断言、单条件数值限度测试 | 数值测试支持常规比较符：>、<、>=、<=、==、!=、区间判断；断言失败默认终止用例执行 |
| 流程控制 | if单分支、if-else双分支、while条件循环 | 现有流程控制无需新增其他类型 |

### 4. Lua集成方案
- 虚拟机隔离：每个测试用例执行时创建独立Lua虚拟机，用例间完全隔离，无变量污染，稳定性高
- 权限控制：仅允许Lua脚本调用测试框架提供的官方接口，禁止访问系统API（文件IO、网络、执行系统命令等），安全性高
- 上下文访问：Lua脚本可直接读写测试用例上下文变量，支持变量传递

### 5. 参数化功能
采用用例内置参数列表方案：
- 用户在参数列表中定义多组参数值
- 动作中通过`{{参数名}}`语法引用参数
- 用例执行时按顺序循环执行多轮，每轮传入一组参数值

### 6. 编辑器特性
全部支持以下功能：
✅ 动作拖拽调整顺序
✅ 动作复制/粘贴
✅ 多级撤销/重做
✅ 动作批量删除
✅ 用例导出为模板，支持跨项目导入复用
✅ 实时语法检查：动作参数不合法时自动标红提示

## 三、跨平台适配要点
1. Lua库采用跨平台源码集成，CMake中配置Windows/Linux下编译规则，无平台依赖
2. 所有JSON序列化/反序列化逻辑复用阶段1通用工具类，跨平台无差异
3. UI组件全部基于Qt原生组件实现，天然跨平台兼容
4. 所有文件路径、编码处理复用现有通用工具，避免乱码、路径格式问题
