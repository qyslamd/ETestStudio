# 使用Qt开发仿凯云ETest计划

## 一、核心功能分析报告
### 1. 整体架构
基于凯云ETest核心能力，Qt实现版本划分为5个核心模块：
| 模块 | 核心功能 |
|------|----------|
| 基础框架层 | 类VSCode的UI布局，项目/文件管理，基础工具链 |
| 设备管理层 | 常用总线设备配置、连接管理、状态监控，统一通道读写接口 |
| ICD协议管理层 | 图形化协议编辑，XML/Excel导入导出，协议打包解包能力 |
| 测试用例编辑层 | 表格拖拽式可视化用例编辑，支持常用动作和流程控制 |
| 测试执行层 | 用例调度执行，实时监控，数据记录，测试报告生成 |

### 2. 各模块详细功能
#### 2.1 设备管理层
- 支持的总线类型：串口（RS232/422/485）、CAN、TCP客户端/服务端、UDP、模拟量输入输出（AI/AO）、开关量输入输出（DI/DO）
- 功能：设备参数配置、连接状态监控、通道抽象层（为上层提供统一的read/write接口）

#### 2.2 ICD协议管理层
- 图形化协议编辑器：支持字段增删改、拖拽排序、属性配置（名称、类型、长度、偏移、默认值）
- 导入导出：支持XML、Excel格式导入导出，支持图形化和yaml格式互转
- 核心能力：协议自动打包解包，提供API供测试用例调用

#### 2.3 测试用例编辑层
- 表格拖拽式编辑：支持动作拖拽添加、移动、复制、删除
- 支持的动作类型：
  - 基础动作：变量声明、延时、打印、自定义脚本、退出
  - IO动作：数据/报文收发、模拟量/数字量采集输出
  - 测试动作：合格/失败断言、数值限度测试
  - 流程控制：if判断、while循环
- 自动生成可执行代码，支持绑定设备通道

#### 2.4 测试执行层
- 执行调度：支持用例启动、暂停、停止控制
- 实时监控：展示通道数据、执行日志、断言结果
- 数据记录：全量执行过程数据存储
- 测试报告：自动生成HTML/Excel格式测试报告，包含执行结果、数据统计

## 二、开发计划
总周期：12~16周，分6个阶段执行
| 阶段 | 周期 | 核心交付内容 |
|------|------|--------------|
| 阶段1：基础框架搭建 | 1~2周 | Qt项目搭建，类VSCode UI布局实现，项目/文件管理功能 |
| 阶段2：设备管理层开发 | 2~3周 | 所有支持总线的配置界面，设备连接管理，统一通道读写抽象层 |
| 阶段3：ICD协议管理层开发 | 2~3周 | 图形化协议编辑器，XML/Excel导入导出，协议打包解包核心能力 |
| 阶段4：测试用例编辑层开发 | 2~3周 | 表格拖拽式用例编辑器，所有动作类型支持，用例转可执行代码 |
| 阶段5：测试执行层开发 | 2~3周 | 执行调度引擎，实时监控面板，数据存储，测试报告生成 |
| 阶段6：测试与优化 | 1~2周 | 全流程功能测试，bug修复，性能优化 |
