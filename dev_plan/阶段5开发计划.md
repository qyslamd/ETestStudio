## 二、各模块技术细节
### 1. 执行引擎核心
- 线程模型：每个测试执行创建独立后台线程，所有动作串行执行，不阻塞UI线程，稳定性高
- 调试能力：仅支持普通断点，用户可在动作行前点击打标，执行到断点自动暂停，支持三种操作：单步执行（仅执行下一个动作后暂停）、继续执行（到下一个断点或结束）、终止执行
- 控制功能：支持启动、暂停、继续、终止、重新执行五种控制操作
- 异常处理：执行过程中发生设备断开、IO错误、脚本错误、断言失败等异常时，直接终止执行，记录详细错误日志并弹窗提示用户，无需异常重试

### 2. 实时监控面板
采用可停靠拖拽的四面板布局：
| 面板 | 功能细节 |
|------|----------|
| 执行日志面板 | 支持日志分级着色：info绿色、warn黄色、error红色、debug灰色，支持关键词搜索、日志级别过滤 |
| 通道数据面板 | 展示所有通道收发数据，同时显示原始十六进制字节和关联ICD后的结构化解析字段值，符合统一数据接口规范 |
| 变量上下文面板 | 实时显示测试用例所有变量当前值，符合阶段1定义的统一上下文数据结构，变量值更新时高亮提示变化部分 |
| 执行进度面板 | 显示当前执行的动作序号、总进度百分比、已执行耗时 |

### 3. SQLite数据存储
- 存储范围：完整保存所有执行过程数据：执行基本信息（用例名称、开始/结束时间、结果、耗时）、动作执行日志、通道收发全量数据、变量变化记录、断言结果
- 保留策略：所有执行记录永久保留，支持手动删除单条/批量删除记录
- 扩展功能：支持执行记录导出为独立SQLite备份文件，可导入其他环境的ETest系统查看历史执行记录
- 数据结构：完全符合阶段1定义的统一数据规范，与其他模块无缝对接

### 4. 测试报告生成
- 报告格式：同时支持HTML、Excel、PDF三种格式，执行完成后可一键生成，自动保存到用户指定目录
- 报告内容：包含基础信息（用例名称、执行时间、结果、耗时）、执行日志、断言结果、IO数据汇总、测试结论
- 模板能力：默认提供通用固定模板，支持后续扩展自定义模板能力
- PDF实现：基于阶段1预研选定的跨平台C++开源PDF库实现，兼容Windows7系统，支持用户自定义页头页脚、嵌入公司LOGO

## 三、跨平台适配要点
1. SQLite数据库采用Qt原生QSqlite模块，天然跨平台兼容，数据库文件格式Windows/Linux通用
2. Excel报告生成复用阶段3集成的Qt Xlsx库，跨平台无依赖
3. PDF库跨平台编译适配，确保Windows7/10/11、Ubuntu所有平台生成PDF样式一致
4. 所有文件路径、编码处理复用阶段1通用工具类，避免路径格式、乱码问题
