# Guidance引导系统设计分析

## 二、核心功能
这是一个基于Qt的交互式分步引导/教程系统，主要功能包括：

### 1. 流程管理
- 支持多个独立的引导流程（Flow）
- 每个流程包含多个引导步骤（Step）
- 灵活的步骤配置和管理

### 2. 交互引导
- **目标高亮**：支持QWidget、QRect、QPixmap三种目标类型的高亮显示
- **气泡提示**：显示当前步骤的标题和详细描述
- **导航控制**：提供上一步、下一步、跳过按钮
- **回调支持**：每个步骤可以设置进入(`onEnter`)和退出(`onExit`)回调函数

### 3. 双模式支持
- **手动模式**：用户通过导航按钮控制步骤切换
- **自动模式**：系统自动执行引导步骤，支持倒计时显示

### 4. 视觉效果
- **半透明遮罩**：突出显示目标区域，其他区域变暗
- **平滑动画**：使用Qt动画框架实现流畅的UI过渡效果
- **响应式布局**：气泡提示会根据目标位置自动调整显示位置，避免超出屏幕边界

## 三、架构设计
采用MVC-like分层架构，职责清晰：

### 1. Model层（guidance_config.cpp/h）
- `GuidanceStep`：单个引导步骤的数据模型，包含目标、标题、描述、回调函数等
- `GuidanceFlow`：引导流程模型，包含多个步骤和流程元信息
- `GuidanceConfig`：配置管理器，统一管理所有引导流程

### 2. Controller层（guidance_controller.cpp/h）
- 控制引导流程的执行逻辑
- 管理当前步骤索引
- 处理用户导航操作（上一步/下一步/跳过）
- 协调Model层和View层的交互
- 支持自动模式的执行控制

### 3. View层
- **guidance_presentation.cpp/h**：负责引导过程的可视化展示，包括遮罩绘制、气泡显示、动画效果等
- **guidance_homepage.cpp/h/.ui**：引导系统主页，显示可用引导流程列表，提供运行入口

## 四、设计意图
### 1. 通用可复用框架
设计为独立的通用引导框架，可嵌入任何Qt应用中，无需修改核心逻辑即可快速添加引导功能。

### 2. 用户体验优化
- 非侵入式设计：引导过程不影响应用的正常功能
- 直观的交互方式：清晰的导航按钮和提示信息
- 明确的视觉反馈：高亮目标区域和气泡提示降低用户学习成本

### 3. 教学/演示目的
在ETest项目中，主要用于：
- 为新用户提供应用操作指引
- 演示复杂测试功能的操作流程
- 创建交互式功能教程

## 五、关键特性
1. **多目标类型支持**：支持QWidget、QRect、QPixmap三种目标类型，满足不同场景的高亮需求
2. **灵活的回调机制**：每个步骤支持进入和退出回调，可实现复杂的交互逻辑
3. **智能位置计算**：气泡提示会自动计算最佳显示位置，避免超出屏幕或遮挡重要内容
4. **丰富的动画效果**：遮罩过渡、气泡弹出等动画提升用户体验
5. **事件过滤机制**：通过事件过滤器实现复杂的交互逻辑处理
6. **窗口拖动支持**：引导窗口支持拖动，不遮挡用户需要查看的内容

## 六、应用场景
1. **新用户上手引导**：帮助新用户快速了解应用的主要功能和操作流程
2. **复杂功能演示**：分步演示复杂测试功能的使用方法
3. **版本更新引导**：在应用版本更新时，引导用户了解新增功能
4. **交互式教程制作**：制作产品功能的交互式教学教程

## 七、技术亮点
1. 使用`std::variant`实现多类型目标的统一管理
2. 基于Qt动画框架实现流畅的视觉效果
3. 智能的气泡位置计算算法，适配不同屏幕尺寸
4. 清晰的分层架构设计，核心逻辑与UI实现分离
5. 良好的代码组织和命名规范，易于维护和扩展

## 八、潜在改进方向
1. **配置文件支持**：添加JSON/YAML配置文件支持，无需编译即可修改引导内容
2. **国际化支持**：支持多语言提示文本
3. **进度保存**：记录用户已完成的引导流程，下次启动时不再重复显示
4. **更多动画效果**：提供多种可选的动画效果和主题样式
5. **键盘快捷键支持**：支持ESC跳过、空格下一步等键盘操作
