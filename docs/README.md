# 项目文档

本项目是基于Qt、C++的仿凯云ETest学习和研究项目的文档资料库。

## 文档结构

所有文档按以下分类组织：

### 01-规划/ - 项目规划和设计文档
- 整体架构设计、发展路线图
- 各阶段开发计划和实施步骤

### 02-研究/ - 技术研究和资料收集
- ETest功能和架构分析
- 总线协议研究和硬件分析
- Schema文件和配置文件

### 03-开发/ - 开发过程文档
- 开发环境配置指南
- 构建和运行说明
- 代码规范和最佳实践

### 04-参考/ - 参考资料
- API参考和速查手册
- 第三方库使用说明
- 技术问题和解决方案

### assets/ - 资源文件
- 图片、图表、示意图
- 配置模板和示例文件

## 使用说明

1. **阅读顺序**：建议按数字顺序阅读文档（01 → 02 → 03 → 04）
2. **更新维护**：所有文档应保持与技术实现同步
3. **贡献文档**：新增文档按分类放入对应目录，更新README说明
