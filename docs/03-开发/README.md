# 03-开发

本目录存放开发过程相关的文档，包括环境配置、构建指南、代码规范等。

## 目录说明

- **环境配置**：开发环境搭建、工具安装、依赖管理
- **构建指南**：编译构建、测试运行、打包发布
- **代码规范**：代码编写规范、命名约定、最佳实践
- **开发流程**：开发工作流、版本控制、质量保证

## 当前文档

- [环境配置指南](环境配置指南.md) - 开发环境搭建步骤
- [构建使用指南](构建使用指南.md) - 项目构建和运行说明
- [代码规范](代码规范.md) - 项目代码编写规范（基于rules.txt）

## 使用说明

1. 环境配置指南应详细说明每个步骤和可能的问题
2. 构建指南应包含从源码到可执行程序的完整流程
3. 代码规范应与实际项目实践保持一致
