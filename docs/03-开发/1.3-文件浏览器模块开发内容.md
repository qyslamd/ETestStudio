## Context

- 文件模型：QFileSystemModel（Qt内置，自动文件监听、图标、排序）
- 右键菜单：基础菜单（新建文件/文件夹、重命名、删除、复制/粘贴路径、在文件系统中打开）
- 双击打开：ProjectManager发射信号，编辑器模块后续对接

## 二、核心类设计

### 2.1 FileExplorerWidget

```cpp
// src/app/FileExplorerWidget.h
namespace etest::app {

class FileExplorerWidget : public QWidget {
  Q_OBJECT
public:
  explicit FileExplorerWidget(QWidget* parent = nullptr);

  void setRootPath(const QString& path);
  QString rootPath() const;

Q_SIGNALS:
  void fileOpenRequested(const QString& filePath);

private:
  void initUi();
  void initSignals();

  // 右键菜单
  void onContextMenu(const QPoint& pos);
  void onNewFile();
  void onNewFolder();
  void onRename();
  void onDelete();
  void onCopyPath();
  void onCopyRelativePath();
  void onOpenInFileSystem();

  QTreeView* tree_view_;
  QFileSystemModel* model_;
  QString root_path_;

  // 右键菜单相关
  QModelIndex context_index_;  // 右键点击的索引
  QMenu* context_menu_ = nullptr;
};

}
```

**关键实现逻辑**：

- `setRootPath()`：设置model的rootPath，`setRootIndex()`只显示项目目录以下的内容（隐藏项目目录的父级）
- 使用 `QFileSystemModel`，设置 `setNameFilters` 过滤不显示的文件（如 .etproj 备份文件），设置 `setNameFilterDisables(false)` 隐藏过滤掉的文件
- 监听 `ProjectManager::projectOpened` → 设置rootPath；`projectClosed` → 清空树
- 双击 `QTreeView::doubleClicked` → 检查是文件则发射 `fileOpenRequested`
- 右键菜单操作：
  - 新建文件：`QFile` 创建空文件，`FileUtil::writeTextFile`
  - 新建文件夹：`FileUtil::createDirectory`
  - 重命名：`QFileSystemModel::rename` (内联编辑)
  - 删除：`QFile::remove` 或 `QDir::removeRecursively`，弹出确认对话框
  - 复制路径/相对路径：`QApplication::clipboard()->setText()`
  - 在文件系统中打开：`QDesktopServices::openUrl()`
