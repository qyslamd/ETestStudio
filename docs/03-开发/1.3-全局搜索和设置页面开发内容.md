# 1.3 全局搜索和设置页面开发内容

## Context

阶段1.3任务6——活动栏与视图切换。当前活动栏有3个按钮（资源管理器/全局搜索/设置），点击可切换侧边栏内容。资源管理器页面（FileExplorerWidget）已实现，但全局搜索页面和设置页面只是占位Label。本任务实现这两个页面，使其可读取ConfigManager展示配置项。

---

## 一、新增文件清单

| 文件 | 职责 |
|------|------|
| `src/app/GlobalSearchWidget.h/cpp` | 全局搜索组件，支持项目目录下文件内容搜索 |
| `src/app/SettingsWidget.h/cpp` | 设置页面，从ConfigManager加载/保存配置项 |

## 二、核心类设计

### 2.1 GlobalSearchWidget

```cpp
// src/app/GlobalSearchWidget.h
#ifndef ETEST_APP_GLOBAL_SEARCH_WIDGET_H_
#define ETEST_APP_GLOBAL_SEARCH_WIDGET_H_

#include <QWidget>

class QLineEdit;
class QPushButton;
class QTableWidget;
class QString;

namespace etest::app {

class GlobalSearchWidget : public QWidget {
  Q_OBJECT

 public:
  explicit GlobalSearchWidget(QWidget* parent = nullptr);
  void setProjectRoot(const QString& path);

 signals:
  void openFileRequested(const QString& filePath, int lineNumber);

 private:
  void initUi();
  void onSearch();
  void onSearchFinished();
  void onResultDoubleClicked(int row, int column);

  QLineEdit* search_input_;
  QPushButton* search_button_;
  QTableWidget* results_table_;
  QString project_root_;
};

}  // namespace etest::app

#endif  // ETEST_APP_GLOBAL_SEARCH_WIDGET_H_
```

**功能**：
- 输入搜索关键字，点击搜索按钮或按Enter开始搜索
- 在项目目录下递归搜索匹配的文件（过滤隐藏文件和非代码文件）
- 搜索文件内容显示匹配行
- 结果显示在表格（三列：文件名、行号、内容预览）
- 双击结果打开文件并跳转到对应行

**搜索范围**：
- 过滤目录：`.git`, `.svn`, `backup`, `.etproj`
- 过滤文件：`~*`, `*.tmp`, `*.Bak`
- 搜索文件类型：`.cpp`, `.h`, `.lua`, `.py`, `.json`, `.xml`, `.txt`, `.md`

**UI布局**：

### 2.2 SettingsWidget

```cpp
// src/app/SettingsWidget.h
#ifndef ETEST_APP_SETTINGS_WIDGET_H_
#define ETEST_APP_SETTINGS_WIDGET_H_

#include <QWidget>

class QTabWidget;
class QString;

namespace etest::app {

class SettingsWidget : public QWidget {
  Q_OBJECT

 public:
  explicit SettingsWidget(QWidget* parent = nullptr);
  void loadSettings();
  void saveSettings();

 private:
  void initUi();
  void createGeneralPage();
  void createEditorPage();
  void createLogPage();
  void createBackupPage();

  void onLogLevelChanged(int index);
  void onLogMaxFileSizeChanged(int value);
  void onLogMaxFileCountChanged(int value);
  void onLogKeepDaysChanged(int value);
  void onBackupEnabledChanged(int state);
  void onBackupIntervalChanged(int value);
  void onBackupMaxCountChanged(int value);
  void onResetToDefault();

  QTabWidget* tab_widget_;

  // General页
  QString window_info_text_;

  // Editor页
  int font_size_;
  bool show_line_number_;
  bool auto_indent_;

  // Log页
  int log_level_;
  int log_max_file_size_;
  int log_max_file_count_;
  int log_keep_days_;

  // Backup页
  bool backup_enabled_;
  int backup_interval_;
  int backup_max_count_;
};

}  // namespace etest::app

#endif  // ETEST_APP_SETTINGS_WIDGET_H_
```

| | 最大文件大小 | QSpinBox (MB) | 读写 |
| | 最大文件数 | QSpinBox | 读写 |
| | 保留天数 | QSpinBox (天) | 读写 |

## 六、验证方法

1. **全局搜索验证**：
   - 点击活动栏"全局搜索"按钮，侧边栏切换到搜索页面
   - 输入关键字点击搜索，显示匹配的搜索结果
   - 双击结果，编辑器和文件打开并跳转到对应行

2. **设置页面验证**：
   - 点击活动栏"设置"按钮，侧边栏切换到设置页面
   - 各Tab页显示对应配置项
   - 修改配置项值，关闭程序再打开，值已持久化
   - 点击"重置为默认"，配置恢复默认值

3. **视图切换验证**：
   - 点击活动栏任一按钮，侧边栏正确切换对应页面
   - 按钮保持选中高亮状态
