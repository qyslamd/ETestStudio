## 二、核心类设计

### 2.1 QtConsoleSink（Qt Sink）

spdlog的自定义Sink，将日志输出到Qt组件（OutputPanel）。

```cpp
// src/core/logger/QtConsoleSink.h
#ifndef ETEST_CORE_LOGGER_QT_CONSOLE_SINK_H_
#define ETEST_CORE_LOGGER_QT_CONSOLE_SINK_H_

#include <spdlog/sinks/base_sink.h>
#include <spdlog/common.h>
#include <QObject>
#include <QMutex>
#include <QQueue>
#include <QTimer>

class QString;

namespace etest::core::logger {

class QtConsoleSink : public QObject, public spdlog::sinks::base_sink<QMutex> {
  Q_OBJECT

 public:
  explicit QtConsoleSink(QObject* parent = nullptr);
  ~QtConsoleSink() override;

  // 注册回调，接收日志文本
  using LogCallback = std::function<void(LogLevel level, const QString& message)>;
  void setLogCallback(LogCallback callback);

 protected:
  void sink_it_(const spdlog::details::log_msg& msg) override;

 private:
  void flush_() override;
  QString formatMessage_(const spdlog::details::log_msg& msg);

  LogCallback callback_;
  bool initialized_ = false;
};

}  // namespace etest::core::logger

#endif  // ETEST_CORE_LOGGER_QT_CONSOLE_SINK_H_
```

**生命周期管理要点**：

1. **Sink创建时机**：在Logger::init()中创建，程序启动时注册
2. **Sink销毁时机**：在Logger::shutdown()前反注册，确保UI组件已销毁
3. **线程安全**：spdlog是异步日志，Sink需线程安全（已继承base_sink<QMutex>）
4. **跨线程通信**：日志在后台线程产生，需通过信号槽或QMetaObject::invokeMethod转到主线程
5. **UI组件生命周期**：Sink持有的回调需在OutputPanel销毁前清除，避免dangling callback

```cpp
void TerminalShell::setProjectRoot(const QString& path) {
  project_root_ = path;
  if (process_ && process_->state() == QProcess::Running) {
    // 当前进程在运行，发送cd命令切换目录
    QString cdCmd = QString("cd /d %1\n").arg(path);
    process_->write(cdCmd.toLocal8Bit());
  }
}
```

## 五、QtConsoleSink 生命周期管理

### 5.1 初始化流程

```
程序启动 → Logger::init() → 注册QtSink（非必须，可选）
         → OutputPanel::setLogHandler() → 创建QtSink并注册回调
         → OutputPanel显示日志
```

### 5.2 销毁流程

```
���序关闭 → OutputPanel析构 → callback_置空
        → Logger::shutdown() → 反注册QtSink
        → 程序退出
```

### 5.3 关键点

1. **回调持有**：Sink持有OutputPanel的回调，OutputPanel先销毁时清除回调
2. **线程切换**：日志在后台线程产生，通过QMetaObject::invokeMethod转到主线程
3. **避免dangling**：OutputPanel析构时立即清除Sink的回调引用

```cpp
// OutputPanel析构函数
OutputPanel::~OutputPanel() {
  // 清除回调，防止Logger继续调用已销毁的对象
  if (log_handler_) {
    log_handler_->setLogCallback(nullptr);
  }
}
```
