# 项目管理模块开发计划

## Context

阶段1.3的第3个任务——项目管理模块开发。当前程序已有主窗口6区布局和核心基础设施，但还无法创建/打开/关闭项目。本模块让程序从"空壳窗口"升级为"可管理项目的工作台"。

## 用户确认的设计决策

- 项目目录结构：scripts/、protocol/、config/、backup/（4个子目录）
- 创建向导：单页（项目名 + 位置选择）
- 关闭行为：检查未保存脏文件，提示保存（先定义接口，编辑器模块后续对接）

### 2.2 ProjectManager（单例管理器）

```cpp
// src/core/project/ProjectManager.h
namespace etest::core::project {

class ProjectManager : public QObject {
    Q_OBJECT
public:
    static ProjectManager& instance();
    ProjectManager(const ProjectManager&) = delete;
    ProjectManager& operator=(const ProjectManager&) = delete;

    // 项目生命周期
    bool createProject(const QString& name, const QString& location);
    bool openProject(const QString& filePath);
    bool closeProject();
    bool saveProject();

    // 项目状态
    bool isProjectOpen() const;
    const ProjectInfo* currentProject() const;

    // 最近项目
    QStringList recentProjects() const;
    void addToRecentProjects(const QString& projectPath);
    void removeFromRecentProjects(const QString& projectPath);
    void clearRecentProjects();

    // 脏文件检查接口（回调机制，后续编辑器模块注册）
    using DirtyCheckCallback = std::function<bool()>;
    void setDirtyCheckCallback(DirtyCheckCallback callback);
    bool hasUnsavedChanges() const;

Q_SIGNALS:
    void projectCreated(const QString& projectPath);
    void projectOpened(const QString& projectPath);
    void projectAboutToClose(const QString& projectPath);
    void projectClosed();
    void recentProjectsChanged();

private:
    ProjectManager();
    ~ProjectManager() override;
    class Impl;
    std::unique_ptr<Impl> m_impl;
};

}  // namespace etest::core::project
```

**关键实现逻辑**：

- `createProject(name, location)`：
  1. 检查名称/路径合法性
  2. 创建目录 `location/name/` 及子目录 scripts/、protocol/、config/、backup/
  3. 生成 `.etproj` 文件写入JSON
  4. 设置 currentProject，发射 `projectCreated` + `projectOpened`
  5. 加入最近项目列表

- `openProject(filePath)`：
  1. 如果当前有项目打开，先 `closeProject()`
  2. 读取并解析 `.etproj` 文件
  3. 验证版本和内容合法性
  4. 设置 currentProject，发射 `projectOpened`
  5. 加入最近项目列表
  6. 保存 `CONFIG_RECENT_LAST_OPEN_PATH` 到 ConfigManager

- `closeProject()`：
  1. 如果 `hasUnsavedChanges()` 返回 true，发射 `projectAboutToClose`（UI层处理提示）
  2. 保存当前项目（recent_files等）
  3. 清空 currentProject，发射 `projectClosed`

- `hasUnsavedChanges()`：调用 `dirty_check_callback_`（如果已注册），否则返回 false

- 最近项目：通过 ConfigManager 的 `CONFIG_RECENT_PROJECT_LIST` 存取，上限10个

- 创建按钮在校验通过前禁用

### 3.2 src/app/MainWindow.cpp

**createMenuBar()** — 改造文件菜单：
```
文件(&F)
  ├── 新建项目    → onNewProject()
  ├── 打开项目    → onOpenProject()
  ├── 关闭项目    → onCloseProject() [初始禁用，打开项目后启用]
  ├── ───────────
  ├── 最近项目 ►  [动态子菜单，最多10项]
  │             └── 清除最近项目
  ├── ───────────
  └── 退出
```

**createStatusBar()** — 新增项目名标签：
- `status_project_label_` 显示在状态栏左侧，无项目时显示"无打开项目"

**initSignals()** — 新增信号连接：
- `ProjectManager::projectOpened` → `onProjectOpened` (启用关闭菜单项、更新标题和状态栏)
- `ProjectManager::projectClosed` → `onProjectClosed` (禁用关闭菜单项、更新标题和状态栏)
- `ProjectManager::recentProjectsChanged` → `updateRecentProjectsMenu`

**onNewProject()** 逻辑：
1. 弹出 NewProjectDialog
2. 如果 accepted，调用 `ProjectManager::createProject(name, location)`

**onOpenProject()** 逻辑：
1. QFileDialog 选择 .etproj 文件，起始目录用 `CONFIG_RECENT_LAST_OPEN_PATH`
2. 调用 `ProjectManager::openProject(filePath)`

**onCloseProject()** 逻辑：
1. 调用 `ProjectManager::closeProject()`
2. 如果有未保存文件，弹出 QMessageBox 提示（是/否/取消）

**closeEvent()** 逻辑变更：
- 关闭窗口前，如果项目已打开，先尝试 closeProject()
- 如果用户取消关闭（QMessageBox::Cancel），忽略关闭事件
