# 1.3 多标签编辑器开发内容

## Context

阶段1.3任务5：多标签编辑器实现。当前中央编辑器区域只是一个QLabel占位，FileExplorerWidget的`fileOpenRequested`信号已连接但只打日志。需要实现基于QScintilla的多标签编辑器，用QADS的CDockWidget tab机制管理，支持双击文件打开、语法高亮、脏标记、关闭/切换。

## 方案：QADS多CDockWidget tab

每个打开的文件创建一个`CDockWidget`，内含`EditorWidget`（封装QsciScintilla）。新文件自动tab化到当前编辑器区域，天然支持QADS的拖拽分屏、浮动特性。

## 详细设计

### 1. EditorWidget — 单文件编辑器组件

```cpp
class EditorWidget : public QWidget {
  Q_OBJECT
 public:
  explicit EditorWidget(const QString& filePath, QWidget* parent = nullptr);

  QString filePath() const;
  QString fileName() const;
  bool isModified() const;

  bool loadFile();
  bool saveFile();
  bool saveFileAs(const QString& newPath);

  QsciScintilla* editor() const;

 Q_SIGNALS:
  void modificationChanged(bool modified);
  void fileNameChanged(const QString& newFileName);

 private:
  void setupEditor();
  QsciScintilla* chooseLexer(const QString& suffix);

  QsciScintilla* editor_;
  QString file_path_;
  bool modified_ = false;
};
```

关键行为：

- 构造时调用`loadFile()`读取文件内容
- `setupEditor()`：行号显示、代码折叠、自动缩进、UTF-8编码
- `chooseLexer(suffix)`：根据文件后缀自动设置语法高亮
  - `.cpp/.h/.c/.hpp` → QsciLexerCPP
  - `.lua` → QsciLexerLua
  - `.json` → QsciLexerJSON
  - `.xml/.html` → QsciLexerXML
  - `.py` → QsciLexerPython
  - `.yaml/.yml` → QsciLexerYAML
  - `.md` → QsciLexerMarkdown
  - `.cmake/CMakeLists.txt` → QsciLexerCMake
  - `.js` → QsciLexerJavaScript
  - 其他 → 无lexer（纯文本）
- 监听QsciScintilla的`modificationChanged`信号，更新`modified_`状态并emit
- `saveFile()`直接写回原路径，`saveFileAs()`写新路径并更新file_path_
- 脏标记通过CDockWidget的title显示 `*` 前缀

### 2. EditorManager — 编辑器管理器

```cpp
class EditorManager : public QObject {
  Q_OBJECT
 public:
  explicit EditorManager(ads::CDockManager* dockManager, QObject* parent = nullptr);

  // 打开文件（如果已打开则激活对应tab）
  void openFile(const QString& filePath);

  // 关闭文件
  bool closeFile(const QString& filePath);
  bool closeAllFiles();

  // 查询
  EditorWidget* editorForFile(const QString& filePath) const;
  bool isOpen(const QString& filePath) const;
  bool hasUnsavedChanges() const;

  // 获取当前活动编辑器
  EditorWidget* currentEditor() const;

 Q_SIGNALS:
  void fileOpened(const QString& filePath);
  void fileClosed(const QString& filePath);
  void currentEditorChanged(EditorWidget* editor);

 private:
  void onDockWidgetActivated(ads::CDockWidget* dock);

  ads::CDockManager* dock_manager_;
  QMap<QString, ads::CDockWidget*> dock_widgets_;  // filePath → CDockWidget
  QMap<QString, EditorWidget*> editors_;            // filePath → EditorWidget
  QString current_file_path_;
};
```

关键行为：

- `openFile()`：
  1. 检查文件是否已打开，是则`dock->raise()`激活tab
  2. 否则创建`EditorWidget`，包装进`CDockWidget`，addDockWidget到中央区域
  3. 新CDockWidget tab到已有编辑器dock区域（用`addDockWidgetTabToArea`）
  4. 连接modificationChanged信号更新dock标题（脏标记`*`前缀）
- `closeFile()`：如果文件已修改，弹QMessageBox确认保存/放弃/取消
- 监听QADS的`dockAreaCreated`或`focusedDockWidgetChanged`信号，更新currentEditorChanged
- `hasUnsavedChanges()`：遍历所有editor，任一modified则返回true，对接ProjectManager的dirty check

### 3. MainWindow 集成

- 移除中央编辑器占位的QLabel，改为空CDockWidget作为中央部件（编辑器tab容器）
- 新增`EditorManager* editor_manager_`成员
- 连接`FileExplorerWidget::fileOpenRequested` → `EditorManager::openFile`
- 菜单栏"文件"菜单新增：保存(Ctrl+S)、另存为、关闭当前文件(Ctrl+W)、关闭所有文件
- 将EditorManager的`hasUnsavedChanges`接入ProjectManager的dirty check回调

## 验证方法

1. 编译通过
2. 运行程序，创建/打开项目
3. 在文件浏览器中双击.cpp/.lua/.json文件，确认：
   - 文件在编辑器区域以新tab打开
   - 语法高亮正确
   - 行号显示正常
4. 再次双击已打开的文件，tab被激活而非重复打开
5. 编辑文件，tab标题出现`*`脏标记
6. Ctrl+S保存，脏标记消失
7. 关闭已修改文件，弹出保存确认对话框
8. 拖拽编辑器tab可分屏/浮动
