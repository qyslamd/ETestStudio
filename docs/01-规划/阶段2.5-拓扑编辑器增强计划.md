## 三、各模块技术细节

### 1. 端口连接约束增强

**目标**：在 `TopologyScene::finishConnectionDrag()` 中增加连接规则验证。

**修改文件**：
- `src/topology/TopologyScene.h/cpp`

**实现要点**：
- 同方向阻止：Input 不能连 Input，Output 不能连 Output
- 输入端单连线：一个 DevicePort 只能连一根线（遍历 `connection_items_` 检查）
- 功能类型匹配：连线双方的 `FunctionType` 必须兼容

```cpp
// 在 TopologyScene::finishConnectionDrag 中增加约束
if (srcPort && devPort) {
    const auto& srcDir = prod->ports[srcPort->portIndex()].direction;
    const auto& devDir = dev->ports[devPort->portIndex()].direction;

    // 约束1：同方向阻止
    if (srcDir == devDir) return;

    // 约束2：输入端单连线
    if (hasExistingConnection(dev, devPort->portIndex())) return;

    // 约束3：功能类型匹配
    if (prod->ports[srcPort->portIndex()].functionType !=
        dev->ports[devPort->portIndex()].functionType) return;

    // 约束通过，创建连线
}
```

**验收标准**：
- Input→Output（不同方向）可连线；Input→Input 或 Output→Output 被阻止
- 已有连线的端口不能再连第二根
- 功能类型不匹配时被阻止

### 3. NicePathMaker 智能路径路由

**目标**：引入多风格连线引擎，支持线型切换和避障路由。

**新增文件**：
- `src/topology/TopologyPathRouter.h`
- `src/topology/TopologyPathRouter.cpp`

**修改文件**：
- `src/topology/CMakeLists.txt` — 添加新文件
- `src/topology/topology_items.h/cpp` — ConnectionItem 引入路由引擎
- `src/topology/TopologyScene.cpp` — 传递障碍物信息

```cpp
class TopologyPathRouter {
public:
    enum Style { Bezier, Polyline, Straight };

    struct RoutingContext {
        QPointF sourcePos;
        QPointF targetPos;
        QVector<QRectF> obstacles;
        Style style;
    };

    QPainterPath route(const RoutingContext& ctx);

private:
    QPainterPath routeBezier(const QPointF& src, const QPointF& dst);
    QPainterPath routePolyline(const QPointF& src, const QPointF& dst,
                                const QVector<QRectF>& obstacles);
    QPainterPath routeStraight(const QPointF& src, const QPointF& dst);
};
```

**避障折线算法**（源自 FlowGraph）：
```
               ┌──────────┐
               │  Device   │
               └──────────┘
     ┌─────────────────────────────┐  ← 绕行路径
     │                             │
┌────┴──┐                     ┌───┴────┐
│  UUT  │                     │ Device │
└───────┘                     └────────┘
```

**验收标准**：
- 三种连线风格均可正常渲染
- Polyline 模式自动避让 UUT/Device 方块
- 拖拽移动块时连线实时更新
- 已有 Bezier 风格效果不受影响

### 6. 拖放创建 Item

**目标**：支持从面板或工具栏拖放设备到画布创建。

**修改文件**：
- `src/topology/TopologyScene.h/cpp` — 增加 drag/drop 事件
- `src/topology/TopologyEditorWidget.h/cpp` — 处理拖放信号

```cpp
// TopologyScene 新增
const char kTopologyMimeType[] = "application/x-topology-device";

void TopologyScene::dragEnterEvent(QGraphicsSceneDragDropEvent* event) {
    if (event->mimeData()->hasFormat(QLatin1String(kTopologyMimeType))) {
        event->acceptProposedAction();
        return;
    }
    QGraphicsScene::dragEnterEvent(event);
}

void TopologyScene::dropEvent(QGraphicsSceneDragDropEvent* event) {
    if (event->mimeData()->hasFormat(QLatin1String(kTopologyMimeType))) {
        QByteArray data = event->mimeData()->data(...);
        QString deviceType = QString::fromUtf8(data);
        emit deviceDropped(deviceType, event->scenePos());
        event->acceptProposedAction();
        return;
    }
    QGraphicsScene::dropEvent(event);
}
```

**验收标准**：
- 从外部拖入场景时，鼠标变为接受状态
- 松开鼠标在场景位置创建对应设备
- 非法 MIME 数据拖入被忽略

enum class ResizePos {
    None, TopLeft, TopMid, TopRight,
    RightMid, BottomRight, BottomMid, BottomLeft, LeftMid
};

void TopologyBlockItem::paint(QPainter* painter, ...) {
    if (option->state & QStyle::State_Selected) {
        painter->setBrush(Qt::white);
        painter->setPen(QPen(Qt::darkGray, 1));
        for (int i = TopLeft; i <= LeftMid; ++i) {
            painter->drawRect(calcResizeSignRect(static_cast<ResizePos>(i)));
        }
    }
}
