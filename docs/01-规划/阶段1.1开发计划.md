# 阶段1.1：开发环境与基础工程搭建迭代（更新版）

## 一、核心目标

完成开发环境统一规范、现有工程CMake配置优化、集成本地预存的所有第三方依赖源码编译，输出可在VS2017/2019/QtCreator/VSCode一键编译运行的最小Qt程序，所有依赖链接正常，为后续功能开发扫清环境障碍。

## 二、预期周期：1~2个工作日

## 三、开发环境统一规范

| 平台 | 标准配置 | 兼容配置 |
|------|----------|----------|
| Windows | Qt 5.12.12 + VS2017 64位套件 | VS2019 64位套件 |
| Linux | 暂不考虑，后续迭代适配 | - |

* 输出交付物：《Windows开发环境配置手册》，包含Qt、VS安装配置步骤、环境变量统一配置规范

## 四、详细任务拆分

| 序号 | 任务内容 | 输出物 |
|------|----------|--------|
| 1 | 目录结构确认 | 确认顶层`3rdparty/`目录已存在，所有第三方依赖源码已预存到对应子目录 |
| 2 | 顶层CMakeLists.txt优化 | 在现有基础Qt CMake配置基础上，优化本地第三方依赖编译配置，通过`add_subdirectory`编译所有依赖，配置依赖链接规则，编译产物自动输出到`bin/`目录 |
| 3 | 依赖链接验证 | 开发最小验证窗口程序，代码中引入所有依赖的头文件，调用简单API验证链接正常，运行无崩溃、无依赖缺失错误 |
| 4 | 多IDE编译验证 | 分别在VS2017、VS2019、QtCreator、VSCode中执行CMake生成、编译、运行流程，确保所有环境编译正常，无链接错误 |
