7~9个工作日（单人开发可灵活调整进度）

## 五、技术实现要求

1. 主窗口UI代码遵循 initUi() + initSignals() 分离规范
2. 插件框架基于 Qt Plugin 机制（`QPluginLoader`），接口设计遵循开闭原则
3. 项目文件统一 UTF-8 编码，路径操作统一 `QDir::toNativeSeparators()`
4. 主窗口关闭时通过 ConfigManager 保存窗口大小、位置、布局状态
5. 编辑器标签支持脏标记（未保存文件提示）

## 六、完成标准

1. 通用插件框架可正常加载、初始化、卸载插件
2. 主窗口6区布局完整，支持拖拽停靠/浮动/隐藏
3. 可创建、打开、关闭 `.etproj` 项目，文件树正确显示
4. 双击文件可在编辑器中打开，支持语法高亮和多标签切换
5. 活动栏可切换视图，底部面板功能正常
6. 窗口大小/位置关闭后可恢复
