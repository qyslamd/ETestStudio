# 明日代办：主窗口VSCode风格布局改造

## 一、现状分析
当前布局存在的问题：
1. 左侧活动栏和侧边栏布局比例不符合VSCode标准
2. 底部面板是三个独立dock的标签化，缺少统一的容器和控制按钮
3. 活动栏样式、尺寸、按钮布局与VSCode不一致
4. 侧边栏缺少视图标题栏和操作按钮
5. 状态栏信息太少，缺少VSCode式的左右分区信息展示
6. 缺少辅助侧边栏（右侧面板）的控制逻辑

## 二、改造目标
完全对齐VSCode的经典布局结构：
```
┌───────────────────────────────────────────────────────────────────────────────┐
│ 菜单栏                                │  标题栏                               │
├───────────────────────────────────────────────────────────────────────────────┤
│ 工具栏                                                                         │
├──────┬───────────────────┬───────────────────────────────────┬─────────────────┤
│ 活动 │ 主侧边栏         │  编辑器标签栏                     │ 辅助侧边栏      │
│ 栏   │                  ├───────────────────────────────────┤                 │
│      │                  │  编辑器区域                       │                 │
│      │                  │                                   │                 │
│      │                  │                                   │                 │
│      │                  │                                   │                 │
│      │                  ├───────────────────────────────────┤                 │
│      │                  │  面板标签栏（输出/问题/终端）     │                 │
│      │                  ├───────────────────────────────────┤                 │
│      │                  │  面板内容区域                     │                 │
├──────┴───────────────────┴───────────────────────────────────┴─────────────────┤
│ 状态栏（左：分支/错误数/文件名  右：光标位置/编码/语言模式）                  │
└───────────────────────────────────────────────────────────────────────────────┘
```

## 三、改造步骤

### 第一步：调整Dock区域结构（核心）
**文件修改：** `src/app/MainWindow.cpp` / `src/app/MainWindow.h`
1. **左侧区域调整：**
   - 活动栏宽度从40px改为48px（VSCode标准宽度），设置固定宽度
   - 调整dock添加顺序：先添加活动栏到LeftDockWidgetArea，再将侧边栏添加到活动栏的右侧（同一区域内左右分割）
   - 设置侧边栏初始宽度250px，可自由调整，支持关闭
   - 确保两个dock不可移动、不可浮动，保持固定在左侧
2. **底部区域调整：**
   - 创建统一的面板容器dock，替换现在的三个独立dock
   - 容器内使用QTabWidget包含输出、问题、终端三个面板，标签栏在顶部
   - 支持面板高度拖动调整，支持最大化/恢复、关闭按钮
3. **右侧区域调整：**
   - 现有属性面板改为辅助侧边栏，初始宽度250px，默认隐藏
   - 支持通过视图菜单控制显示/隐藏
4. **中央区域调整：**
   - 确保编辑器区域占满整个中央空间
   - 编辑器标签栏置顶显示，支持多标签、拖动排序

### 第二步：优化活动栏（ActivityBar）
**文件修改：** `src/app/ActivityBarWidget.h` / `src/app/ActivityBarWidget.cpp`
1. **布局调整：**
   - 宽度调整为48px，按钮大小改为40x40px，间距8px
   - 顶部排列主要功能按钮：资源管理器、搜索、Git、调试、扩展
   - 底部排列辅助按钮：设置、用户头像
2. **样式优化：**
   - 选中按钮左侧显示2px宽的蓝色竖条（VSCode标志性样式）
   - Hover时显示浅灰色背景
   - 按钮图标使用更接近VSCode的风格（暂时用文字图标，后续可替换为SVG图标）
3. **功能增强：**
   - 点击已选中的活动按钮时，切换侧边栏的显示/隐藏
   - 支持快捷键切换不同活动视图

### 第三步：优化主侧边栏（Sidebar）
**文件修改：** `src/app/SidebarWidget.h` / `src/app/SidebarWidget.cpp`
1. **增加视图标题栏：**
   - 每个视图顶部增加标题栏，显示当前视图名称（如"资源管理器"）
   - 标题栏右侧添加视图操作按钮（刷新、折叠全部、更多操作等）
2. **功能增强：**
   - 侧边栏支持拖动调整宽度
   - 支持侧边栏自动隐藏（可选功能）
   - 文件浏览器视图增加面包屑导航栏，显示当前路径

### 第四步：优化底部面板
**文件修改：** 新建`src/app/PanelContainerWidget.h` / `src/app/PanelContainerWidget.cpp`
1. **统一容器：**
   - 创建统一的面板容器组件，包含标签栏和内容区域
   - 标签栏在顶部，每个标签显示图标+文字
   - 标签栏右侧添加面板控制按钮：最大化/恢复、关闭
2. **功能增强：**
   - 支持拖动面板上边缘调整高度
   - 支持快捷键切换不同面板（Ctrl+` 切换终端，Ctrl+Shift+M切换问题面板等）
   - 面板内容支持滚动，自适应大小

### 第五步：优化状态栏（StatusBar）
**文件修改：** `src/app/MainWindow.cpp`
1. **布局调整：**
   - 左侧区域：显示Git分支图标+名称、错误警告数量图标+数字、当前文件名
   - 右侧区域：显示光标位置（行:列）、文件编码、换行符格式、语言模式
2. **功能增强：**
   - 点击分支名可切换分支
   - 点击错误警告数可跳转到问题面板
   - 点击光标位置可弹出跳转到行输入框

### 第六步：全局样式和交互优化
**文件修改：** 新建`resources/styles/vscode.qss`
1. **样式统一：**
   - 编写VSCode风格的样式表，统一所有组件的颜色、字体、边框样式
   - 支持深色/浅色主题切换预留
2. **交互优化：**
   - 所有dock的标题栏默认隐藏，只保留必要的控制按钮
   - 窗口边缘支持拖动调整大小
   - 支持VSCode标准快捷键：Ctrl+B切换侧边栏，Ctrl+J切换底部面板，Ctrl+\ 分割编辑器等

## 四、验证标准
改造完成后需达到以下效果：
1. 布局结构1:1对齐VSCode经典布局
2. 各个区域的大小、比例、位置符合VSCode的默认设置
3. 交互逻辑（切换视图、调整大小、面板控制）与VSCode一致
4. 样式风格接近VSCode的默认深色主题
5. 所有原有功能（文件浏览、编辑、终端、输出等）正常运行不受影响
