# 01-规划

本目录存放项目规划和设计相关的文档。

## 目录说明

- **整体规划**：项目整体架构、技术路线、发展蓝图
- **阶段规划**：各开发阶段的详细计划和实施步骤
- **设计文档**：模块设计、接口规范、数据模型等

## 当前文档

- [整体架构设计](整体架构设计.md) - 项目整体架构和技术选型
- [阶段1-基础框架](阶段1-基础框架.md) - 第一阶段开发详细计划

## 使用说明

1. 规划文档按数字前缀排序，便于查找和阅读
2. 每个阶段规划应包含：目标、时间线、交付物、风险点
3. 设计文档应保持与技术实现同步更新
