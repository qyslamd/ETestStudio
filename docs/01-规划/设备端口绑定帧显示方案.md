# 设备端口绑定帧显示方案

## 背景

`PropertyPanelWidget` 的设备端口（DevicePort）属性页中，`devport_bind_frames_btn_`（"绑定 ICD 帧..." 按钮）点击后弹出 `DevicePortBindingDialog` 选择帧，选中的帧写入 `TopologyDevicePort::boundFrameNames`。但界面上没有任何地方展示当前已绑定了哪些帧——用户只能再次点击按钮打开对话框才能看到。

## 目标

在按钮下方新增只读列表，显示当前设备端口已绑定的 ICD 帧名；无绑定帧时 GroupBox 内显示"暂无绑定"文字提示。支持 Undo/Redo 后自动同步刷新。

## 改动文件

| 文件 | 改动量 |
|------|--------|
| `src/topology/PropertyPanelWidget.h` | +6 行（3 include + 2 成员 + 1 方法声明） |
| `src/topology/PropertyPanelWidget.cpp` | ~+35 行 |

## 设计方案

### 布局调整

现有 DevicePort 页面使用 `QFormLayout`（`buildDevicePortPage()`），按钮是最后一行。追加一个 `QGroupBox` 包裹 `QStackedWidget`，内部分两层：空状态 `QLabel` 和 `QListWidget`。与 `buildMonitorPage()` 的"已挂载连线" GroupBox 结构一致：

```
┌─ devicePortPage (QFormLayout) ────────────┐
│ 端口名称  [________________]              │
│ 方向      [Input      ▼]                  │
│ 功能类型  [CUSTOM     ▼]                  │
│ 端口样式  [圆形       ▼]                  │
│           [绑定 ICD 帧...]                 │
│ ┌─ 已绑定 ICD 帧 ───────────────────────┐ │
│ │  CAN_Frame_100                       │ │
│ │  CAN_Frame_200                       │ │
│ │  LIN_Frame_05                        │ │
│ └──────────────────────────────────────┘ │
└───────────────────────────────────────────┘
```

GroupBox 使用 `QStackedWidget` 切换列表/空状态：

| Layer | Widget | 条件 |
|-------|--------|------|
| 0 | `QLabel("暂无绑定")` | `boundFrameNames` 为空 |
| 1 | `QListWidget` | `boundFrameNames` 非空 |

GroupBox 的 objectName 保持默认（不设置），随页面整体 QSS 渲染。

#### QStackedWidget 高度处理

`QStackedWidget` 默认只渲染当前可见层。空状态时 QListWidget 的 `setMinimumHeight(60)` 不会被计入（因为 QListWidget 不是当前可见层），所以空的 GroupBox 内仅显示一行"暂无绑定"标签（约 20px）加上 GroupBox 内边距（约 8px），总高度约 30-40px，视觉上紧凑。有绑定帧时 QListWidget 最小 60px 保证可读性。Qt 5.15 的 `QStackedWidget` 没有 `setSizeAdjustPolicy(AdjustToContents)`，当前直接依赖其默认行为即可——`sizeHint()` 只返回当前层的高度。

### 同步机制

| 时机 | 刷新方式 |
|------|----------|
| 切换到 DevicePort 页（`showPropertiesFor`） | 从 `dp.boundFrameNames` 直接填充 |
| 绑定 dialog 点确定（`onDevicePortBindFrames`） | push Command 触发 `indexChanged`，由 Step 4 连接覆盖 |
| Undo/Redo | `undoStack::indexChanged` 信号触发 |

**不保留手动刷新**：`QUndoStack::push()` 是**同步** emit `indexChanged` 的，不存在异步延迟。push 之后 `indexChanged` 在同一函数调用栈中发出，Step 4 的连接会立即响应。手动追加 refresh 是多余的重复调用。

### 连接位置

`undoStack` 的连接放在 `PropertyPanelWidget` 构造函数的末尾（所有 `build*Page()` 调用之后），以 `this` 为 context，析构时自动断开，无 dangling 风险。

### 空状态处理

`refreshDevicePortFrames()` 内根据 `boundFrameNames` 是否为空切换 `QStackedWidget` 的 currentIndex，空则显示"暂无绑定"标签，非空则显示列表。

空状态的视觉效果：仅一行灰色"暂无绑定"文字（20px）+ GroupBox 内边距（8px）+ QStackedWidget 边距，总高度约 30-40px，比有帧时（60px+）紧凑，不会造成视觉上的空白浪费。空标签使用 `QPalette` 设灰色文字，不使用 `setStyleSheet`（符合项目样式规范）。

## 具体步骤

### Step 1 — `PropertyPanelWidget.h`

```cpp
// 已有 includes 中追加
#include <QLabel>
#include <QListWidget>
#include <QStackedWidget>

// 成员区
QStackedWidget* devport_frames_stack_ = nullptr;  // 0 = 空提示, 1 = 列表
QListWidget* devport_frames_list_ = nullptr;
```

同时声明：

```cpp
void refreshDevicePortFrames();
```

### Step 2 — `buildDevicePortPage()`

在 `devport_bind_frames_btn_` 的 `lay->addRow(...)` 之后追加。使用 `addRow(groupBox)` 让 GroupBox 跨两列（QFormLayout 的非 label-field 行布局）：

```cpp
// ── 已绑定 ICD 帧列表 ──
auto* framesGroup = new QGroupBox(QStringLiteral("已绑定 ICD 帧"), w);
auto* framesLay = new QVBoxLayout(framesGroup);
framesLay->setContentsMargins(4, 4, 4, 4);

devport_frames_stack_ = new QStackedWidget(w);
devport_frames_stack_->setSizeAdjustPolicy(QStackedWidget::AdjustToContents);

auto* emptyLabel = new QLabel(QStringLiteral("暂无绑定"), w);
emptyLabel->setObjectName(QStringLiteral("devportEmptyLabel"));
emptyLabel->setAlignment(Qt::AlignCenter);
QPalette pal = emptyLabel->palette();
pal.setColor(QPalette::WindowText, QColor(128, 128, 128));
emptyLabel->setPalette(pal);
devport_frames_stack_->addWidget(emptyLabel);  // index 0

devport_frames_list_ = new QListWidget(w);
devport_frames_list_->setEditTriggers(QAbstractItemView::NoEditTriggers);
devport_frames_list_->setAlternatingRowColors(true);
devport_frames_list_->setMinimumHeight(60);
devport_frames_stack_->addWidget(devport_frames_list_);  // index 1

devport_frames_stack_->setCurrentIndex(0);
framesLay->addWidget(devport_frames_stack_);
lay->addRow(framesGroup);
```

### Step 3 — `showPropertiesFor()` DevicePort 分支

在 `devport_style_combo_` blockSignals 代码块之后、`stack_->setCurrentIndex(PageDevicePort)` 之前追加：

```cpp
refreshDevicePortFrames();
```

### Step 4 — 构造函数连接 UndoStack

`PropertyPanelWidget` 构造函数的末尾（所有 `build*Page()` 之后）连接 undoStack。`QUndoStack::push()` 和 Ctrl+Z/Y 都会同步触发此 signal，覆盖 Dialog 确认和 Undo/Redo 两种场景：

```cpp
connect(doc_->undoStack(), &QUndoStack::indexChanged, this, [this]() {
  if (stack_->currentIndex() != PageDevicePort) return;
  if (editing_device_port_device_ < 0 || editing_device_port_index_ < 0) return;
  refreshDevicePortFrames();
});
```

连接以 `this` 为 context，`PropertyPanelWidget` 析构时自动断开。

### Step 5 — 实现 `refreshDevicePortFrames()`

该方法在任意状态下都是安全的：`editing_*` 为 -1 时 `doc_->device(-1)` 返回 nullptr，代码跳过列表填充，stack 切到 index 0（"暂无绑定"）：

```cpp
void PropertyPanelWidget::refreshDevicePortFrames() {
  const auto* dev = doc_->device(editing_device_port_device_);
  bool hasFrames = false;
  if (dev && editing_device_port_index_ >= 0 &&
      editing_device_port_index_ < dev->ports.size()) {
    const auto& frames = dev->ports[editing_device_port_index_].boundFrameNames;
    devport_frames_list_->clear();
    for (const QString& frame : frames) {
      devport_frames_list_->addItem(frame);
    }
    hasFrames = !frames.isEmpty();
  }
  devport_frames_stack_->setCurrentIndex(hasFrames ? 1 : 0);
}
```

## 不做的方案（已否决）

### ❌ 空状态用 disabled QListWidgetItem 塞"暂无绑定"
hack 感强，选择高亮样式在有不可选项的列表中会闪烁。

### ❌ 用 `QLabel` 替代 QListWidget 显示帧名
帧名可能很长，QLabel 无法自然滚动，不支持多选扩展；QListWidget 提供原生滚动和未来可能的交互扩展。

### ❌ DevicePort 页改用 QVBoxLayout 整体替换 QFormLayout
当前 DevicePort 页的字段表用 QFormLayout 是合理的。QFormLayout 的 `addRow(QWidget*)`（单参数重载）可以让 QGroupBox 自然跨两列，无需重构整个页面布局。
