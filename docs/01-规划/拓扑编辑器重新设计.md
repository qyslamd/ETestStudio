# 拓扑编辑器重新设计：QFrame → QMainWindow

## 动机

当前 `TopologyEditorWidget` 继承自 `QFrame`，工具栏用手拼 `QHBoxLayout + QToolButton`，面板用 `QSplitter` 固定分区，状态栏用 `QLabel`。这带来几个问题：

1. **工具栏不专业** — 手拼布局没有溢出处理、拖拽自定义、图标尺寸切换
2. **面板不可移动** — 用户无法拖拽属性面板到右侧外部、无法分离设备面板为浮动窗口
3. **状态栏功能弱** — 只有一个 `QLabel`，没有临时消息、永久部件、进度指示等
4. **独立发布受限** — `topology-demo` 示例需要自己搭建窗口框架，无法直接复用编辑器

改为 `QMainWindow` 基类可以一次性解决以上所有问题。

## 设计

### 基类变更

```
// 旧
class TopologyEditorWidget : public QFrame, public etest::app::IEditor

// 新
class TopologyEditorWidget : public QMainWindow, public etest::app::IEditor
```

### 面板 → QDockWidget

| 当前 | 改为 | dock 位置 |
|------|------|-----------|
| `DevicePaletteWidget` (left_splitter_ 上半) | `QDockWidget("设备面板")` | LeftDockWidgetArea |
| `TopologyOutlineWidget` (left_splitter_ 下半) | `QDockWidget("导航大纲")` | LeftDockWidgetArea |
| `PropertyPanelWidget` (splitter_ 右侧) | `QDockWidget("属性面板")` | RightDockWidgetArea |

- 移除 `splitter_` 和 `left_splitter_`
- 左侧两个 dock 默认上下堆叠（`tabifyDockWidget` 或自然堆叠）
- 所有 dock 允许用户拖拽、分离、关闭、重新定位

### 工具栏 → QToolBar

```
// 旧：手拼 QHBoxLayout + QToolButton + QLabel(" | ") 分隔符
// 新：QMainWindow::addToolBar()

auto* toolbar = addToolBar(QStringLiteral("拓扑工具栏"));
toolbar->setMovable(false);  // 嵌入 IDE 时建议固定
toolbar->addAction(add_uut_action_);
toolbar->addAction(add_device_action_);
toolbar->addSeparator();
toolbar->addAction(undo_action_);
// ...
```

分组布局与之前工具栏重排方案一致：

```
[+UUT] [+设备] | [撤销▼] | [复制] [粘贴] [删除] | [排列▼] [分布▼] | [放大] [缩小] [重置] | [监听▼] | [导出] | ←stretch→ | [大纲]
```

`QToolBar` 自带的优势：
- 窗口变窄时自动溢出到扩展菜单
- 支持图标/文字/图标+文字显示模式切换
- 可拖拽定位（顶部/左侧/右侧/底部/浮动）
- `QToolBar::addSeparator()` 是专业分隔符

### 不创建独立状态栏

移除现有的底部 `statusFrame` + `status_label_`。信息分散到更合适的位置：

1. **缩放比例** — 作为 `QToolBar` 上的永久 `QLabel`，放在缩放按钮组右侧
2. **临时提示**（"监听器视图已开启"等）— 嵌入 IDE 时通过 `parentWidget()` 向上找到主窗口，调用 `mainWindow->statusBar()->showMessage()`；standalone 模式下同理走 `QMainWindow::statusBar()`

不显式创建 `QMainWindow::statusBar()`，避免嵌入时产生多余的状态栏。

### IEditor 接口兼容

`QMainWindow` 是 `QWidget` 子类，无需改接口：

```cpp
QWidget* widget() override { return this; }
```

### 状态持久化

`QMainWindow::saveState()/restoreState()` 自带 dock 布局 + 工具栏位置持久化，可以替代之前的 `QSplitter::saveState/restoreState` 手动方案：

```cpp
// 保存
QByteArray state = saveState();
ConfigManager::instance().set(CONFIG_TOPOLOGY_WINDOW_STATE, state);

// 恢复
QByteArray state = ConfigManager::instance().get<QByteArray>(CONFIG_TOPOLOGY_WINDOW_STATE);
if (!state.isEmpty())
    restoreState(state);
```

之前的 `CONFIG_TOPOLOGY_SPLITTER_STATE` 和 `CONFIG_TOPOLOGY_LEFT_SPLITTER_STATE` 可以合并为一个 `CONFIG_TOPOLOGY_WINDOW_STATE`。

## 嵌入 IDE 时的行为

`TopologyEditorWidget` 作为 `QMainWindow` 嵌入到 `ads::CDockWidget` 时：

### 隐藏 menuBar

```cpp
// 嵌入模式：由 EditorManager 在创建时调用
void TopologyEditorWidget::setEmbeddedMode(bool embedded) {
    embedded_ = embedded;
    if (embedded) {
        menuBar()->hide();
    } else {
        menuBar()->show();
    }
}
```

menuBar 在嵌入时隐藏（IDE 有自己的菜单栏）。不创建独立 statusBar，临时提示走主窗口状态栏。

### Dock 可分离

**Dock 不需要禁止分离。** 理由：

1. `ads::CDockWidget` 本身就支持浮动窗口，用户已经习惯这种交互
2. 编辑器内部的 dock 分离后是 Qt 原生浮动窗口，和 ADS 浮动窗口层级不同但可以共存
3. 如果用户把属性面板拖成浮动窗口后关闭编辑器，`saveState()` 会记住这个布局，下次恢复
4. 禁止分离会削弱 QMainWindow 的核心优势 — 用户花钱买的就是灵活性

唯一需要处理的是：嵌入模式下 dock 关闭后的恢复入口。通过 View 菜单或工具栏按钮提供面板显隐切换即可。

### 模式判断

```cpp
// standalone 模式（topology-demo）
auto* editor = new TopologyEditorWidget;  // QMainWindow 完整能力

// 嵌入模式（IDE）
auto* editor = new TopologyEditorWidget;
editor->setEmbeddedMode(true);  // 隐藏 menuBar
auto* dock = new ads::CDockWidget("拓扑编辑器");
dock->setWidget(editor);
```

## Standalone Demo 复用

`examples/topology-demo/` 当前需要自己搭建 `QMainWindow` + `QGraphicsView` 等框架。改为 `QMainWindow` 基类后：

```cpp
// topology-demo main.cpp
int main(int argc, char** argv) {
    QApplication app(argc, argv);
    TopologyEditorWidget editor;
    editor.resize(1200, 800);
    editor.show();
    return app.exec();
}
```

直接可用，不需要额外的 `MainWindow` 包装类。

## 未来扩展

改为 `QMainWindow` 后，以下方向更容易实现：

1. **独立发布** — 拓扑编辑器、协议编辑器、测试程序编辑器都可以独立打包发布
2. **菜单栏** — standalone 模式下提供完整的 File/Edit/View/Help 菜单
3. **多工具栏** — 文件工具栏、编辑工具栏、视图工具栏分开，用户可自定义
4. **面板插件化** — 第三方可以通过 `addDockWidget` 注入自定义面板
5. **快捷键绑定** — `QMainWindow` 的 action 系统和 `QShortcut` 配合更好

## 改动范围

| 文件 | 改动 |
|------|------|
| `src/topology/TopologyEditorWidget.h` | `QFrame` → `QMainWindow`；移除 `splitter_`、`left_splitter_`；新增 `QDockWidget*` 成员、`setEmbeddedMode()`、`embedded_` 标志 |
| `src/topology/TopologyEditorWidget.cpp` | `initUi()` 重写：手拼工具栏 → `QToolBar`，手拼状态栏 → `QStatusBar`，`QSplitter` → `QDockWidget`；`initSignals()` 适配 dock 显隐逻辑 |
| `src/core/config/ConfigDefs.h` | `CONFIG_TOPOLOGY_SPLITTER_STATE` + `CONFIG_TOPOLOGY_LEFT_SPLITTER_STATE` → `CONFIG_TOPOLOGY_WINDOW_STATE` |
| `src/app/EditorManager.cpp` | 创建 `TopologyEditorWidget` 后调用 `setEmbeddedMode(true)` |
| `examples/topology-demo/MainWindow.h/.cpp` | 简化或移除，直接用 `TopologyEditorWidget` |
| `src/app/resources/styles/vscode.qss` | 更新 `#topologyToolbar` → `QToolBar` 选择器，dock widget 样式 |
