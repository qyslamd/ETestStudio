## 二、各模块技术细节
### 1. ICD数据结构设计
采用分层结构「协议→消息→字段」，支持嵌套结构体/数组，字段仅保留基础类型（整数、浮点数、字符串）
- 字段核心属性：名称、类型、长度、偏移、默认值、字节序（单独配置大端/小端）、取值范围、单位、描述
- 协议元数据：协议名称、版本、描述、全局默认字节序
- 序列化支持：XML、JSON、YAML三种存储格式，内部统一数据结构，仅序列化方式不同

### 2. 图形化编辑器实现
基于QTableWidget的表格型编辑器（类似Excel操作体验）：
- 核心编辑功能：字段增删改、拖拽调整顺序，调整后自动同步更新所有后续字段偏移值
- 编辑特性：字段复制/粘贴、批量修改字段属性、多级撤销/重做、字段查找/替换、一键按偏移量升序排列
- 实时错误检查：自动检测字段重叠、偏移越界、长度不合法、类型不匹配等错误，实时在表格中标红提示

### 3. 导入导出功能
| 功能 | 实现细节 |
|------|----------|
| Excel导入导出 | 对齐凯云ETest的Excel模板，首行列名：字段名、类型、长度、偏移、描述、默认值，支持批量导入多个协议文件到当前项目 |
| XML/JSON导入导出 | 自定义格式，完整保留ICD所有元数据和字段属性 |
| YAML互转 | 支持图形化编辑的协议与YAML格式双向转换，方便批量编辑 |
| C/C++头文件导出 | 自动生成对应结构体定义头文件，自动处理字节序宏，支持跨平台使用 |

### 4. 核心接口设计
仅提供原生C++接口，性能优先：
```cpp
// 打包接口：传入字段键值对，返回打包后的字节数组
QByteArray pack(const QVariantMap &fieldValues, bool *ok = nullptr, QString *errorMsg = nullptr) const;
// 解包接口：传入字节数组，返回解析后的字段键值对
QVariantMap unpack(const QByteArray &data, bool *ok = nullptr, QString *errorMsg = nullptr) const;
// 预览接口：传入字段值，返回预览的字节数组和解析结果，用于调试
struct PreviewResult { QByteArray rawData; QVariantMap parsedData; QString error; };
PreviewResult previewPack(const QVariantMap &fieldValues) const;
```
- 字节序处理：每个字段可单独配置大端/小端，优先级高于协议全局默认字节序
- 协议校验支持：自动计算CRC8/CRC16/CRC32、和校验、异或校验字段值，打包时自动填充，解包时自动校验

### 5. 扩展功能
- 协议复制：支持基于现有协议快速复制生成新协议，所有字段和属性完整继承，可直接修改
- 打包预览功能：编辑器内置预览面板，填入字段值可实时预览打包后的十六进制字节数组和解析结果，方便调试
- 错误自动修复：支持一键自动修复字段重叠、偏移不连续等常见错误

## 三、跨平台适配要点
1. 所有序列化/反序列化逻辑基于Qt核心库实现，天然跨平台兼容
2. 导出的C/C++头文件自动增加跨平台字节序转换宏，兼容Windows/Linux/嵌入式平台
3. Excel导入导出基于Qt Xlsx第三方库（源码集成，跨平台无依赖）
4. 所有文件路径、编码处理复用阶段1通用工具类，确保跨平台无乱码、路径问题
