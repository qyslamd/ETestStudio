# 软件如何交互



## 详细描述
1. 运行软件。软件自动从插件目录中加载所有的硬件插件，并加载到硬件树中
   - 硬件树中需要展示硬件的状态：
     - 在线
     - 离线
     - 模拟
     - 真实
   - 硬件支持的操作：
     - 打开
     - 关闭
     - 查看详细信息
2. 创建一个测试项目
   - 在测试项目中添加硬件拓扑
   - 在测试项目中添加帧协议描述
   - 在测试项目中添加测试用例
3. 测试用例执行
   - 测试用例转换为Json
   - 使用JSON-Schema校验JSON
   - Json转换为Lua测试脚本
   - 测试引擎运行Lua脚本
   - 测试引擎记录运行过程中的信息
   - 可能还需要调试Lua脚本
   - 执行结束，生成测试报告
   - 测试报告可以编辑、修改
   - 导出保存测试报告
