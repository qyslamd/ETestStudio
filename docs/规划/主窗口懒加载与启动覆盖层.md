# MainWindow 懒加载 + 脉冲覆盖层启动方案

## 背景

主窗口初始化速度慢，原因是所有子控件（侧边栏页面、底部面板、EditorManager、插件扫描等）全在构造函数里串行创建。参考 Firefox 的 progressive paint 设计，采用两阶段初始化 + 脉冲覆盖层过渡：

1. 先显示窗口框架（Ribbon + 活动栏可见，内容区盖脉冲覆盖层）
2. 后台懒加载子控件，完成后覆盖层淡出

## 整体流程

```
用户启动
  ▼
MainWindow 构造函数
  ├── initUi()              ← 只创建窗口框架
  ├── initSignalsEarly()    ← 不依赖子控件的信号
  └── QTimer::singleShot(0) ← 安排懒加载
  ▼
show() → 窗口显示（Ribbon 可见，内容区盖脉冲覆盖层）
  ▼
lazyInit() 执行
  ├── 1. 创建 LoadingOverlay 盖住内容区
  ├── 2. 注册活动栏按钮
  ├── 3. 注册侧边栏页面（此时创建各页面 Widget）
  ├── 4. 创建底部面板
  ├── 5. 创建 EditorManager + WelcomeWidget
  ├── 6. initSignalsLate() ← 跨组件信号
  ├── 7. AuthService / 插件加载 / 硬件刷新
  └── 8. LoadingOverlay::finish() → 淡出
```

## 设计决策

- **覆盖层范围**：Ribbon 和活动栏在外面，覆盖层只盖内容区（QSplitter 区域）
- **加载动效**：脉冲光圈（呼吸透明度动画）+ 居中"正在加载..."文字
- **信号连接策略**：
  - 组件自身信号 → 在组件创建后立即连接（内聚）
  - 跨组件信号（如 ProjectManager ↔ 多个面板）→ 统一放 initSignalsLate()

## 阶段一：initUi() — 最小化初始化

构造函数只创建窗口必须的框架：

| 创建 | 说明 |
|------|------|
| `ThemeManager::instance()` | 加载 QSS，样式系统 |
| `setupRibbon()` | Ribbon 栏、QAction 定义、QuickAccessBar |
| `createStatusBar()` | 状态栏标签（7 个 QLabel） |
| `HintBarWidget` | 提示栏（轻量） |
| `ActivityBarWidget` | 活动栏（48px 宽，轻量） |
| `SidebarWidget` | **空容器**，不注册任何页面 |
| `h_splitter_` + `v_splitter_` | 水平/垂直分割器 |
| `ads::CDockManager` | QADS 停靠系统 |
| 中央占位 `new QWidget()` | 替代 WelcomeWidget |
| `BottomContainerWidget` | **空壳**，不添加子面板 |
| `aux_sidebar_widget_` | 创建但隐藏 |
| `restoreWindowState()` | 窗口位置/大小恢复 |

**不创建**：ProjectStructureWidget、HardwareTreeWidget、ProtocolManagerWidget、TestProgramManagerWidget、SearchWidget、GitWidget、OutputPanel、ProblemsPanel、TerminalPanel、EditorManager、WelcomeWidget。

**不执行**：插件扫描、AuthService 初始化。

### initSignalsEarly()

Phase 1 末尾执行，只连接不依赖子控件的信号：

- `ThemeManager::themeChanged` → `onThemeChanged`
- `ribbonBar()->ribbonModeChanged` → 持久化最小化模式
- `ActivityBarWidget::pageClicked` → 切换侧边栏显隐
- `ActivityBarWidget::settingsTriggered` → 惰性创建设置对话框
- `ActivityBarWidget::loginTriggered` → 登录菜单

## 阶段二：脉冲覆盖层

覆盖层是一个全屏半透明 QWidget，盖在主窗口内容区（v_splitter_ 区域），Ribbon 和活动栏保持可见。

### 视觉设计

```
┌─────────────────────────────────────────────────┐
│  [文件]  [主页]  [视图]  [工具]  [帮助]          │  ← Ribbon 正常显示
├────┬────────────────────────────────────────────┤
│ ██ │                                              │
│ ██ │      (脉冲光圈呼吸动画)                      │
│ ██ │        "正在加载..."                          │  ← 覆盖层
│ ██ │                                              │
│ ██ │                                              │
├────┴────────────────────────────────────────────┤
│  状态栏                                         │
└─────────────────────────────────────────────────┘
```

### 实现

继承 `QWidget`，参考 `TuxSaverOverlay` 模式：

```cpp
class LoadingOverlay : public QWidget {
    Q_OBJECT
public:
    explicit LoadingOverlay(QWidget* content_parent);
    void finish();  // 淡出后 deleteLater

protected:
    void paintEvent(QPaintEvent*) override;
    bool eventFilter(QObject*, QEvent*) override;  // 拦截鼠标事件
    void resizeEvent(QResizeEvent*) override;

private:
    int pulse_alpha_ = 180;     // 当前透明度
    QTimer* pulse_timer_;       // 脉冲驱动
};
```

- **位置**：`parent = v_splitter_`，`resizeEvent` 跟随父窗口大小
- **背景**：深色 `rgba(30, 30, 46, pulse_alpha_)` / 亮色 `rgba(245, 245, 245, pulse_alpha_)`
- **脉冲动效**：`QTimer` 每 30ms 触发，`pulse_alpha_` 在 160→220 之间正弦呼吸
- **文字**：居中绘制"正在加载..."，文字在脉冲中保持完整不透明度
- **交互拦截**：`eventFilter` 吃掉 `MouseButtonPress` / `Wheel` / `KeyPress`，阻止用户操作背后控件
- **淡出**：`finish()` 使用 `QPropertyAnimation`（或 `QTimer` 递减 `pulse_alpha_`），透明度降至 0 后 `hide()` + `deleteLater()`
- **超时保护**：10 秒后如果 `finish()` 未被调用，自动强制移除

### 脉冲动效伪代码

```cpp
void LoadingOverlay::onPulseTick() {
    // 正弦呼吸：pulse_phase_ 0→2π 循环
    pulse_phase_ += 0.15;
    if (pulse_phase_ > 6.2832) pulse_phase_ -= 6.2832;
    double val = std::sin(pulse_phase_);
    // 透明度在 160~220 之间波动
    pulse_alpha_ = 190 + static_cast<int>(val * 30);
    update();
}
```

## 阶段三：lazyInit() — 后台初始化

```
lazyInit()
  │
  ├── 1. 创建 LoadingOverlay（覆盖内容区，启动脉冲）
  │
  ├── 2. 注册活动栏按钮          ← activity_bar_->addPage() × 9
  │
  ├── 3. 注册侧边栏页面           ← sidebar_->addPage() 逐个注册
  │     ├── ProjectStructureWidget   (连接: fileOpenRequested → editor_manager)
  │     ├── HardwareTreeWidget       (连接: 无跨组件)
  │     ├── ProtocolManagerWidget    (连接: openFileRequested → editor_manager)
  │     ├── TestProgramManagerWidget (连接: openFileRequested → editor_manager)
  │     ├── SearchWidget             (连接: fileOpenRequested → editor_manager)
  │     ├── GitWidget                (连接: fileOpenRequested → editor_manager)

  ├── 4. 创建底部面板            ← BottomContainerWidget::addPanel()

  │
  ├── 5. 创建 EditorManager     ← 编辑器工厂注册
```

### initSignalsLate() 内容

```cpp
void MainWindow::initSignalsLate() {
    // ── 项目 ↔ 侧边栏页面 ──
    connect(projectMgr, &ProjectManager::projectOpened,
            project_structure_, &ProjectStructureWidget::setProjectPath);
    connect(projectMgr, &ProjectManager::projectClosed,
            project_structure_, &ProjectStructureWidget::clearProjectPath);
    connect(projectMgr, &ProjectManager::projectOpened,
            search_widget_, [this](...) { search_widget_->setSearchRoot(...); });
    connect(projectMgr, &ProjectManager::projectClosed,
            search_widget_, [this]() { search_widget_->setSearchRoot({}); });
    connect(projectMgr, &ProjectManager::projectOpened,
            git_widget_, &GitWidget::setProjectRoot);
    connect(projectMgr, &ProjectManager::projectClosed,
            git_widget_, [this]() { git_widget_->setProjectRoot({}); });
    connect(projectMgr, &ProjectManager::projectOpened,
            backup_mgr_, &BackupManager::onProjectOpened);
    connect(projectMgr, &ProjectManager::projectClosed,
            backup_mgr_, &BackupManager::onProjectClosed);
    connect(projectMgr, &ProjectManager::recentProjectsChanged,
            welcome_widget_, &WelcomeWidget::refreshRecentProjects);

    // ── 编辑器 ↔ Ribbon 操作 ──
    connect(editor_manager_, &EditorManager::currentEditorChanged,
            this, &MainWindow::onEditorChanged);
    // ... undo/redo/save/cut/copy/paste 等更新

    // ── 视图面板显隐 ──
    connect(view_panel_action_, &QAction::triggered,
            this, [this](bool checked) {
                bottom_container_->setVisible(checked);
                // ... 保存/恢复分割器大小
            });
    connect(view_aux_sidebar_action_, &QAction::triggered,
            this, [this](bool checked) {
                aux_sidebar_widget_->setVisible(checked);
            });

    // ── 底部面板关闭 ↔ 切换状态 ──
    connect(bottom_container_, &BottomContainerWidget::panelClosed,
            this, [this]() {
                bottom_container_->hide();
                view_panel_action_->setChecked(false);
            });

    // ── 剪贴板 ──
    connect(QApplication::clipboard(), &QClipboard::dataChanged,
            this, [this]() {
                edit_paste_action_->setEnabled(
                    QApplication::clipboard()->text().isEmpty());
            });
}
```

## 边界情况

- **加载失败**：覆盖层 10 秒超时自动移除，避免永久卡住
- **快速完成**：如果 lazyInit 在 < 200ms 内完成，覆盖层跳过淡出直接移除
- **深色/亮色主题**：覆盖层颜色跟随 ThemeManager
- **窗口缩放**：覆盖层通过 resizeEvent 跟随 v_splitter_
- **多屏/DPI**：使用设备独立像素

## 验证

1. 启动应用，窗口在 < 0.5s 内出现，Ribbon/活动栏可见
2. 内容区显示脉冲光圈 + "正在加载..."
3. 鼠标点击/滚轮/按键被覆盖层拦截
4. 2-3 秒后脉冲消失，覆盖层淡出，子控件就绪
5. 侧边栏切换、面板显隐、文件打开、插件加载功能正常
6. 窗口缩放时覆盖层正确跟随
7. 深色/亮色主题切换时覆盖层颜色正确
