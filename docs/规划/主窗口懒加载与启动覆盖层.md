# MainWindow 懒加载 + 模糊覆盖层启动方案

## 背景

主窗口初始化速度慢，原因是所有子控件（侧边栏页面、底部面板、EditorManager、插件扫描等）全在构造函数里串行创建。参考 Firefox 的 progressive paint 设计，采用两阶段初始化 + 模糊覆盖层过渡：

1. 先显示窗口框架（带模糊覆盖层），让用户感觉应用"秒开"
2. 后台懒加载子控件，完成后移除覆盖层

## 整体流程

```
用户启动
  ▼
MainWindow 构造函数
  ├── initUi()              ← 只创建窗口框架（Ribbon + 活动栏 + 空布局）
  └── QTimer::singleShot(0)  ← 安排懒加载
  ▼
show() → 窗口显示 + 模糊覆盖层
  ▼
lazyInit() 执行
  ├── 创建侧边栏页面（逐个注册）
  ├── 创建底部面板
  ├── 创建 EditorManager + WelcomeWidget
  ├── initSignalsLate()
  ├── 插件加载 + 硬件树刷新
  └── 移除覆盖层 → 用户开始操作
```

## 阶段一：initUi() — 最小化初始化

构造函数只创建窗口必须的框架：

| 创建 | 说明 |
|------|------|
| `ThemeManager::instance()` | 加载 QSS，样式系统 |
| `setupRibbon()` | Ribbon 栏、QAction 定义、QuickAccessBar |
| `createStatusBar()` | 状态栏标签 |
| `ActivityBarWidget` | 活动栏（48px 宽，轻量） |
| `SidebarWidget` | **空容器**，不注册任何页面 |
| `HintBarWidget` | 提示栏 |
| QSplitter 布局 | 水平/垂直分割器，确定布局结构 |
| `ads::CDockManager` | QADS 停靠系统 |
| 中央区域 | `new QWidget()` 占位（不创建 WelcomeWidget） |
| `BottomContainerWidget` | **空壳**，不添加子面板 |
| `aux_sidebar_widget_` | 创建但隐藏 |

**不创建**：ProjectStructureWidget、HardwareTreeWidget、ProtocolManagerWidget、TestProgramManagerWidget、SearchWidget、GitWidget、OutputPanel、ProblemsPanel、TerminalPanel、EditorManager、WelcomeWidget。

**不执行**：插件扫描、AuthService 初始化。

## 阶段二：模糊覆盖层

覆盖层是一个全屏半透明 QWidget，盖在主窗口内容区上方（Ribbon 和活动栏以下区域），带模糊/玻璃态视觉效果。

### 视觉设计

```
┌─────────────────────────────────────────────────┐
│  [文件]  [主页]  [视图]  [工具]  [帮助]          │  ← Ribbon 正常显示
├─────────────────────────────────────────────────┤
│ ██ 活动栏 ██                                      │
│   📁       │  ┌──────────────────────────────┐  │
│   🔗       │  │                              │  │
│   🔧       │  │     模糊覆盖层               │  │
│   📄       │  │    (半透明毛玻璃)             │  │
│   ▶️       │  │                              │  │
│   📊       │  │    "正在加载..." + 微动效    │  │
│   🔍       │  │                              │  │
│   ⎔        │  └──────────────────────────────┘  │
├─────────────────────────────────────────────────┤
│  状态栏                                        │
└─────────────────────────────────────────────────┘
```

### 实现方案

覆盖层 `LoadingOverlay` 继承 `QWidget`：

- **位置**：父窗口 resize 时跟随，覆盖在内容区域（QSplitter 区域）
- **样式**：
  - 背景色：`rgba(30, 30, 46, 200)`（暗色） / `rgba(250, 250, 250, 200)`（亮色）
  - 前景：居中显示加载指示器 + "正在加载..." 文字
  - 可选的毛玻璃效果：`setAttribute(Qt::WA_TranslucentBackground)` + 背景模糊
- **交互**：拦截鼠标事件（`setAttribute(Qt::WA_TransparentForMouseEvents, false)`），防止用户在加载完成前操作
- **动画**：使用 `QPropertyAnimation` 在移除时渐隐（opacity 1.0 → 0.0）

### Qt 实现要点

```cpp
class LoadingOverlay : public QWidget {
    Q_OBJECT
    Q_PROPERTY(qreal opacity READ windowOpacity WRITE setWindowOpacity)
public:
    explicit LoadingOverlay(QWidget* parent);
    void startAnimation();  // 加载中脉冲动效
    void finish();          // 淡出后 deleteLater

protected:
    void paintEvent(QPaintEvent*) override;
    bool eventFilter(QObject*, QEvent*) override;  // 拦截子控件事件
    void resizeEvent(QResizeEvent*) override;
};
```

由于 Qt 的 `setWindowOpacity()` 对子 widget 无效，使用 `paintEvent` 手动实现透明度：

```cpp
void LoadingOverlay::paintEvent(QPaintEvent*) {
    QPainter painter(this);
    painter.setRenderHint(QPainter::Antialiasing);

    // 背景色（带透明度）
    bool dark = ThemeManager::instance().isDarkTheme();
    QColor bg = dark ? QColor(30, 30, 46) : QColor(250, 250, 250);
    bg.setAlpha(current_alpha_);  // 渐隐时动态变化
    painter.fillRect(rect(), bg);

    // 加载指示器
    if (current_alpha_ > 50) {
        painter.setPen(dark ? Qt::white : Qt::black);
        painter.drawText(rect(), Qt::AlignCenter, "正在加载...");
    }
}
```

## 阶段三：lazyInit() — 后台初始化

使用 `QTimer::singleShot(0, ...)` 确保在窗口事件循环启动后才执行：

```cpp
// MainWindow 构造函数末尾
QTimer::singleShot(0, this, &MainWindow::lazyInit);
```

执行顺序：

```
lazyInit()
  ├── 1. 创建 LoadingOverlay（覆盖内容区）
  ├── 2. 注册活动栏按钮        ← activity_bar_->addPage() × 9
  ├── 3. 注册侧边栏页面         ← sidebar_->addPage() × 9
  ├── 4. 创建底部面板           ← OutputPanel / ProblemsPanel / TerminalPanel
  ├── 5. 创建 EditorManager    ← 编辑器管理器
  ├── 6. 创建 WelcomeWidget    ← 替换中央占位 widget
  ├── 7. initSignalsLate()     ← 依赖子控件的信号连接
  ├── 8. 插件扫描              ← PluginManager::loadAll()
  ├── 9. 硬件树刷新            ← hardwareTree()->refreshTree()
  ├── 10. AuthService          ← 初始化认证服务
  ├── 11. initSignalsEarly()中的项目信号 ← 连接项目管理器（此时子控件已就绪）
  └── 12. 移除覆盖层           ← 淡出动画 → deleteLater
```

## 边界情况

- **加载失败**：覆盖层 10 秒超时自动移除，避免永久卡住
- **快速完成**：如果 lazyInit 在 < 200ms 内完成，覆盖层不显示（或跳过动画）
- **深色/亮色主题**：覆盖层颜色跟随主题
- **窗口缩放**：覆盖层通过 eventFilter 或 resizeEvent 跟随内容区
- **多屏/DPI**：使用设备独立像素

## 未包含（后续迭代）

- 进度指示（"正在加载插件 3/5"）
- 逐组件淡入而非一次性移除
- 骨架屏替代纯色覆盖层

## 验证

1. 启动应用，窗口在 0.5s 内出现，内容区显示模糊覆盖层
2. 覆盖层上有"正在加载..."文字，可能有微动效
3. 2-3 秒后子控件逐个出现，覆盖层淡出消失
4. 所有功能正常（侧边栏切换、面板显隐、文件打开、插件加载）
5. 窗口缩放时覆盖层正确跟随
6. 深色/亮色主题切换时覆盖层颜色正确
