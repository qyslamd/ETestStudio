# 协议管理器设计

## 1. 背景

### 1.1 现状

帧协议编辑器 (`ProtocalEditorWidget`) 已经完成了单文件的编辑功能——打开一个 `.eproto` 文件，管理其中的帧定义和节点树，三面板联动编辑。

但项目级协议管理存在缺口：一个真实项目往往包含几十个 `.eproto` 文件，目前用户只能通过文件浏览器逐个查找和打开，缺少一个**专门按协议语义组织的整体视图**。

### 1.2 现有资产

| 资产 | 位置 | 说明 |
|------|------|------|
| 协议引用模型 | `src/core/project/ProjectInfo.h` | `ProtocolRef` 结构体，含 id/name/filePath |
| 项目管理器 | `src/core/project/ProjectManager.h` | `registerProtocolRef()` / `removeProtocolRef()` |
| 帧协议编辑器 | `src/protocal/ProtocalEditorWidget` | 单文件帧编辑 |
| ICD 数据模型 | `src/icd_utility/` | Frame/Node/Repository |
| 活动栏 + 侧边栏模式 | `src/app/SidebarWidget.h` | 左侧活动栏切换侧边栏页面 |

## 2. 设计

### 2.1 核心理念

遵循主窗口已有的交互模式：**活动栏 → 侧边栏列出资源 → 编辑区打开编辑**。

新增一个"协议管理"侧边栏页面，与现有的文件浏览、硬件管理、搜索等页面并列。

### 2.2 UI 布局

```
活动栏(ActivityBar)             侧边栏(Sidebar)                    编辑区(EditorArea)
┌─────────┐              ┌──────────────────────┐       ┌──────────────────────┐
│  📁 文件  │              │ 协议管理器              │       │                      │
│  🔍 搜索  │              │                      │       │  ProtocalEditorWidget│
│  🔌 硬件  │              │  ├─ 协议文件 A.eproto  │       │  (双击A后在此打开)     │
│  📐 协议  │ ← 点击       │  │  ├─ 帧 221 (CMD)    │       │                      │
│  ...   │              │  │  ├─ 帧 222 (DATA)   │       │                      │
└─────────┘              │  │  └─ 帧 ...          │       │                      │
                         │  ├─ 协议文件 B.eproto  │       │                      │
                         │  │  ├─ 帧 100 (DATA)   │       │                      │
                         │  │  └─ 帧 ...          │       │                      │
                         │  └─ ...               │       │                      │
                         │                      │       │                      │
                         │  [+ 新建] [导入XML]    │       │                      │
                         └──────────────────────┘       └──────────────────────┘
```

### 2.3 交互流程

#### 浏览协议
1. 用户点击活动栏"协议"图标
2. 侧边栏显示项目所有 `.eproto` 文件列表
3. 展开文件显示其中的帧列表（id、名称、类型、字节数）
4. 选中一个帧，状态栏/属性面板显示基本信息

#### 编辑协议
1. 在侧边栏双击 `.eproto` 文件
2. 编辑区打开 `ProtocalEditorWidget` 加载该文件
3. 编辑完成后保存，侧边栏自动刷新帧列表

#### 管理操作
- **新建协议文件**：侧边栏顶部"+"按钮 → 弹出对话框输入文件名 → 创建空白 `.eproto` → 注册到 `ProjectInfo.protocols()`
- **导入 XML**：选择 Schema XML 文件 → 转换为 `.eproto` → 注册到项目
- **删除**：右键删除 → 确认 → 删除文件 + 移除引用
- **重命名**：右键重命名 → 更新 `ProtocolRef`
- **刷新**：文件变更后刷新帧列表展示

### 2.4 数据流

```
ProjectManager::currentProject()
  └─ ProjectInfo::protocols()  →  QVector<ProtocolRef>
      └─ 遍历 ProtocolRef::filePath
          └─ loadEproto(filePath) → icd::Repository
              └─ Repository::frames() → 树形展示
```

每次切换侧边栏页或项目变更时刷新列表。

### 3.1 新增文件

### 3.2 修改文件

| 文件 | 改动 |
|------|------|
| `src/app/SidebarWidget.h/cpp` | 新增 `ProtocolManagerWidget` 页面 |
