##  测试流程模型

使用测试流程模型，采用流程图的形式对测试需求进行描述，并将有向图基于判定节点进行分割，采用基于深度的路径组合算法生成测试路径，结合模型图中数据，约束，动作序列以及期望结果等，输出最终的测试用例。

### 主要功能

1. 可视化建立测试流程

- 简单快捷的创建测试流程模型
- 包括开始、任务、网关、结束、注释等节点
- 快捷菜单操作简单
- 支持子模型多层嵌套，分解复杂逻辑

2. 输入参数配置

- 通过一定数值区间，自动生成边界值、随机数、自增、自减等取值
- 可任意设定数据取值精度
- 可自由选择配对因数
- 支持设定参数间的约束条件

3. 用例生成策略配置

- 支持路径覆盖深度配置：1、2、3、n;
- 支持数据覆盖配置： 1-wise、 2-wise、3-wise、N-wise。

4. 测试用例生成与输出

- 采取优化的路径求解算法，自动生成用例
- 以最小数量的测试用例集达到设定的组合覆盖目标
- 生成测试用例：包含操作、路径、数据、期望结果
- 生成可执行的脚本
