## YAML语法

系统中内置的数据表述统一使用 YAML 语法。
YAML (YAML Ain't a Markup Language)是一种标记语言,通常以.yml 为后缀,
是一种直观的能够被电脑识别的数据序列化格式,并且容易被人类阅读；容易和脚本
语言交互的,可以被支持 YAML 库的不同的编程语言程序导入,常用来写配置文
件。可用于如：Java,C/C++,Ruby,Python,Perl,C#,PHP 等。
- YAML 易于人们阅读。
- YAML 数据在编程语言之间是可移植的。
- YAML 匹配敏捷语言的本机数据结构。
- YAML 具有一致的模型来支持通用工具。
- YAML 具有表现力和可扩展性。
- YAML 易于实现和使用。

### 基本语法

- 大小写敏感。
- 使用缩进表示层级关系,缩进不允许使用 tab,只允许空格。
- 缩进的空格数不重要,只要相同层级的元素左对齐即可。
- 使用"#"来表示注释。

### 数据类型

- 对象：键值对的集合,又称为映射（mapping）/哈希（hashes）/字典（dictionary）。
- 数组：一组按次序排列的值,又称为序列（sequence） / 列表（list）。
- 纯量（scalars）：单个的、不可再分的值。

### 字节流（ETest中的buff）
字节流buff以关键字！buff为前缀

```yaml
        buff: !buff '00 00'
        # 表示{"buff": `00 00`} 数据类型为字节流
```


#### 对象

对象键值对使用冒号结构表示 key: value,冒号后面要加一个空格,也可以使用
key:{key1: value1,key2: value2,...},还可以使用缩进表示层级关系。

```yaml
        key: 
          key1: value1
          key2: value2

        # 以上 yml 的表示方式同

        key: {key: value1,key2: value2}

        # 转换成 json 格式为
        {
            "key": {
                "key1": "value1",
                "key2": "value2"
            }
        }
```


#### 数组

以 - 开头的行表示构成一个数组,支持多维数组,可以使用行内表示。

```yaml
        - A
        - B
        - C

        # 转化成 json 为
        ["A","B","C"]

        #############
        -
        - A
        - B
        - C
        -
        - A
        - B
        - C

        # 转化成 json 为
        [
            ["A","B","C"],
            ["A","B","C"]
        ]

        #############
        # 行内表示
        key: [value1,value2,value3]

        # 转化成 json 为
        {
            "key": ["value1","value2","value3"]
        }


```

      
#### 纯量

纯量是最基本的,不可再分的值。
- 字符串
- 布尔值
- 整数
- 浮点数
- Null
- 时间
- 日期

```yaml

        b:
            - true
            - false
        f:
            - 3.14
            - 685230.15
        int:
            - 123
            - 685230
        'null':
            nodeName: node
            parent: null
        string:
            - 我是ETest
            - Hello world
        date:
            - '2023-01-17T00:00:00'
        datetime:
            - '2023-01-17T00:00:00'


        #转成 json 如下
        {
            "b": [true, false],
            "f": [3.14, 685230.15],
            "int": [123, 685230],
            "null": {
                "nodeName": "node",
                "parent": null
            },
            "string": ["我是ETest", "Hello world"],
            "date": ["2023-01-17T00:00:00"],
            "datetime": ["2023-01-17T00:00:00"]
        }

```

       

#### 复合结构

数组和对象可以构成复合结构。

```yaml
        languages:
            - YAML
            - Lua
            - Python 
        sites:
            YAML: yaml 
            Lua: lua 
            Python: python 

        #转成 json 如下
        {
            "languages": [
                "YAML",
                "Lua",
                "Python"
            ],
            "sites": {
                "YAML": "yaml",
                "Lua": "lua",
                "Python": "python"
            }
        }
```

        

#### 多行字符串

严格按照段落显示

- 直接使用\n 换行。
- |：文中自动换行,默认仅保留一行空行。
- |+：文中自动换行,保留字符串后面所有的空行。
- |-：文中自动换行,删除字符串后面所有的空行。

```yaml
        string1: |
         hello ETest.
         ETest is best.

        string2: |+
         hello ETest.
         ETest is best.

        string3: |-
         hello ETest.
         ETest is best.

        #转成 json 如下
        {
            string1: "hello ETest.\nETest is best.\n",
            string2: "hello ETest.\nETest is best.\n",
            string3: "hello ETest.\nETest is best."
        }
```

        


不需要按段落显示

- 直接在字符串中换行写。
- \>：文中不自动换行,默认仅保留一行空行。
- \>+：文中不自动换行,保留字符串后面所有的空行。
- \>-：文中不自动换行,删除字符串后面所有的空行。

```yaml
         string1: >
         hello ETest.
         ETest is best.

        string2: >+
         hello ETest.
         ETest is best.

        string3: >-
         hello ETest.
         ETest is best.

        #转成 json 如下
        {
            "string1": "hello ETest. ETest is best.\n",
            "string2": "hello ETest. ETest is best.\n",
            "string3": "hello ETest. ETest is best."
        }
```
