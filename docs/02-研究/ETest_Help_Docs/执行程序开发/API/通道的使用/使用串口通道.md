
## 使用串口通道
该通道支持以下操作：read_buff、read_buff_sync、read_msg、read_msg_sync、write_buff、write_buff_sync、write_msg、write_msg_sync、on_buff_recv、iocmd
### 简介
串口通道包括RS-232、RS-422、RS-485、UART、TTL。两个设备之间可以通过串口传输数据, 如计算机和外部设备之间的数据传输。串口通道通常使用RS-232标准进行通信。串口通道可以通过使用串口线将两个设备连接起来。

串口通道使用串行数据传输, 这意味着数据是按位顺序传输的, 而不是同时传输的。串口通道的传输速度通常比其他通信协议慢, 但它可以在长距离传输数据时非常实用, 因为串口通道的信号可以在数千英尺的距离内传输。

串口通道的优点是它可以在不需要网络的情况下进行数据传输, 因为它只需要一条物理连接线。它也可以在不同操作系统之间进行数据传输, 因为串口通道是一种标准的通信协议。缺点是传输速度相对较慢。

### 串口通道的属性配置
- baudrate：值类型为number, 波特率
- bytesize：值类型为number, 数据位
- stopbits：值类型为number, 停止位
- parity：值类型为string, 校验方式
- flowcontrol：值类型为 string, 流控方式

### 串口通道的数据读写

**1.异步写原始数据**
> local w_res = write_buff(channel, buff, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - buff：EBuff类型, 数据缓存
    - option：dict类型, 可选参数选项nil
- 返回值：
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.size：number类型, 输出的字节长度
        - w_res.value：EBuff类型, 输出值

**2.同步写原始数据**

> local w_res = write_buff_sync(channel, buff, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - buff：EBuff类型, 数据缓存
    - option：dict类型, 可选参数选项nil
- 返回值：
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.size：number类型, 输出的字节长度
        - w_res.value：EBuff类型, 输出值

**3.异步写消息数据**
> local w_res = write_msg(channel, prot, msg, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - prot：EProtocol类型, 协议对象
    - msg：dict类型, 报文数据
    - option：dict类型, 可选参数选项nil
- 返回值：
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.size：number类型, 输出的字节长度
        - w_res.value：EBuff类型, 输出值

**4.同步写消息数据**
>local w_res = write_msg_sync(channel, prot, msg, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - prot：EProtocol类型, 协议对象
    - msg：dict类型, 报文数据
    - option：dict类型, 可选参数选项nil
- 返回值：
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.size：number类型, 输出的字节长度
        - w_res.value：EBuff类型, 输出值

**5.异步读原始数据**
> local r_res = read_buff(channel, size, tout_ms)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - size：number类型, 需要读取的字节长度, 0表示全部读取
    - tout_ms：number类型, 超时时长（单位ms）, 超时返回nil
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.size：number类型, 读取到的数据缓存字节长度
        - r_res.value：EBuff类型, 读取到的数据缓存结果

**6.同步读原始数据**
> local r_res = read_buff_sync(channel, size)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - size：number类型, 需要读取的字节长度, 0表示全部读取
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.size：number类型, 读取到的数据缓存字节长度
        - res.value：EBuff类型, 读取到的数据缓存结果

**7.异步读消息数据**
> local r_res = read_msg(channel, prot, tout_ms)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - prot：EProtocol类型, 协议对象
    - tout_ms：number类型, 超时时长（单位ms）, 超时返回nil
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.size：number类型, 读取到的数据缓存字节长度
        - r_res.value：EBuff类型, 读取到的数据缓存结果

**8.同步读消息数据**
> local r_res = read_msg_sync(channel, prot)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - prot：EProtocol类型, 协议对象
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.size：number类型, 读取到的数据缓存字节长度
        - r_res.value：EBuff类型, 读取到的数据缓存结果

**9.事件订阅**
> on_buff_recv(channel, fn)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - fn：回调函数, 函数原型为fn(ch, res)
        - ch: EChannel类型, 通信通道对象
        - res: dict类型，事件触发的消息

### 串口通道IO命令

**1.设置通道参数**
> iocmd(channel, "SetConfig", option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - option：dict类型, 可选参数选项
        - option.baudrate：number类型, 波特率
        - option.stopbits：number类型, 停止位
        - option.bytesize：number类型, 数据位
        - option.flowcontrol：string类型, 流控方式
        - option.parity：string类型, 校验方式

**2.获取通道参数**
> local res = iocmd(channel, "GetConfig")
- 输入参数：
	- channel：EChannel类型, 通信通道对象
- 返回值：
	- res：dict类型, 可选参数选项
        - res.baudrate：string类型, 波特率
        - res.stopbits：string类型, 停止位
        - res.bytesize：number类型, 数据位
        - res.flowcontrol：string类型, 流控方式
        - res.parity：string类型, 校验方式
- **注意：仅 232 全功能串口支持此操作**
