## 使用1553B-BM通道
该通道支持以下操作：on_buff_recv、iocmd
### 简介
1553B-BM又称总监监视器，有以下特点：

1. 1监听总线消息

### 1553B-BM通道的配置及属性

- voltage：输出工作电压(V)，值类型为 number
- mode：工作模式，值类型为 string，可选 1M/4M
- coupling：耦合方式，值类型为 string，可选 none(默认)/direct(直接耦合)/transformer(变压器耦合)
- aotu_changebus：自由切换总线，值类型为 bool
- en_code：使用模式代码，值类型为 bool
- en_broadcase：使能广播，值类型为 bool
- en_internalbus：使用内部总线，值类型为 bool

### 1553B-BM通道的数据读写

**1.事件订阅**
> on_buff_recv(channel, fn)
- 输入参数：
	- channel：EChannel类型, 通信通道对象
	- fn：回调函数, 函数原型为fn(ch, res)
        - ch: EChannel类型, 通信通道对象
        - res: dict类型, 事件触发的消息

**2.事件订阅获取数据更新次数**
> local opt = ebuff.first_frame_option(buff)
- 输入参数：
	- buff：Ebuff类型, 事件订阅数据缓存(res.value)
- 返回值：
	- opt：dict类型
        - opt.updated: number类型，数据更新的次数

### 1553B-BM通道IO命令

**1.启动BM通道同时启动数据过滤**
>  local b = iocmd(channel, "Start", option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - option：dict类型
		- option.ignore_dup: 布尔类型，忽略重复数据
		- option.ignore_sts: 布尔类型，忽略状态字
- 返回值：
	- b：boolean类型, true表示成功

**2.停止BM**
> local b = iocmd(channel, "Stop", {})
- 输入参数：
	- channel：EChannel类型, 通信通道对象
- 返回值：
	- b：boolean类型, true表示成功
