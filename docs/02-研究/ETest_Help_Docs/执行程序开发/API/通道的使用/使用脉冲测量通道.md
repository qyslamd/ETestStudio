## 使用脉冲测量通道
该通道支持以下操作：read_pulse、read_pulse_sync、iocmd
### 简介
脉冲测量（脉冲输入）通道是一种用于测量脉冲信号频率、脉冲宽度和脉冲计数的电子测量通道
脉冲测量通道通常具有以下特点：

1. 计数功能：脉冲测量通道可以对输入的脉冲信号进行计数。它可以记录脉冲信号的数量，并提供一个计数器值作为输出

2. 频率测量：脉冲测量通道可以测量脉冲信号的频率。它可以计算单位时间内脉冲信号的数量，并将其转换为频率值

3. 脉冲宽度测量：脉冲测量通道可以测量脉冲信号的宽度。它可以确定脉冲信号的上升沿和下降沿之间的时间间隔，并将其转换为脉冲宽度值

4. 触发功能：脉冲测量通道通常具有触发功能，可以根据特定的触发条件来启动测量。触发条件可以是脉冲信号的上升沿、下降沿、特定的脉冲宽度等

5. 精确度和分辨率：脉冲测量通道的精确度和分辨率取决于其硬件和测量范围。通常情况下，脉冲测量通道具有高精确度和高分辨率，可以满足各种测量需求

### 脉冲测量通道数据读写
**1.异步读取脉冲输入通道的测量结果**
> local w_res = read_pulse(channel)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
- 返回值
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.value：EBuff类型, 数据内容

**2.同步读取脉冲输入通道的测量结果**
> local w_res = read_pulse_sync(channel)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
- 返回值
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.value：EBuff类型, 数据内容


### 脉冲测量通道IO命令


**1.启动**
> iocmd(channel, "Start", option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - option：dict类型, 可选参数选项
        - option.type：string类型，表示测量类型，`counter：计数`|`freq_low：低频频率测量`|`freq_high：高频频率测量`|`width_low：低电平脉宽测量`|`width_high：高电平脉宽测量`| `dutycycle：占空比测量`
