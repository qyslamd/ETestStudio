## 使用ARINC429输入通道

该通道支持以下操作：read_buff、read_buff_sync、read_msg、read_msg_sync、on_buff_recv

### 简介
ARINC429输入通道是一种专为航空电子系统设计的高可靠性数字通信接口，具有灵活性和强大的数据处理能力，适用于航空航天领域的数据传输需求。

ARINC429输入通道具有以下特点：

1. 高可靠性：ARINC429输入通道设计用于航空航天领域，具有高度可靠性和稳定性，能够在恶劣环境下工作。

2. 数据传输速率：ARINC429输入通道支持数据传输速率为每秒100kbps的标准速率，以及每秒12.5kbps的低速率。

3. 数据格式：ARINC429输入通道使用双线式差分数据传输，采用标准的32位数据帧格式，包括标签、数据和校验位等信息。

4. 灵活性：ARINC429输入通道可以通过配置进行灵活地适应不同的数据传输需求，包括数据帧格式、速率和标签识别等方面的设置。

5. 数据处理能力：ARINC429输入通道通常配备有数据解析和处理功能，能够对接收到的数据进行解码、验证和转换，以满足系统对数据的需求。

### ARINC429输入通道的配置及属性

- 波特率：值类型为string，表示传输速率
- 校验方式：值类型为string，表示数据传输过程中数据校验的方式
- 数据位长度：值类型为number，表示通道传输的比特位位数

### ARINC429输入通道的数据读写
**1.异步读取原始数据**
> local r_res = read_buff(channel, size, tout_ms)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - size：number类型, 需要读取的字节长度, 0表示全部读取
    - tout_ms：number类型, 超时时长（单位ms）, 超时返回nil
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.size：number类型, 读取到的数据缓存字节长度
        - r_res.value：EBuff类型, 读取到的数据缓存结果

**2.同步读取原始数据**
> local r_res = read_buff_sync(channel, size)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - size：number类型, 需要读取的字节长度, 0表示全部读取
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.size：number类型, 读取到的数据缓存字节长度
        - r_res.value：EBuff类型, 读取到的数据缓存结果

**3.异步读取消息数据**    
> local r_res = read_msg(channel, prot, tout_ms)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - prot：EProtocol类型, 协议对象
    - tout_ms：number类型, 超时时长（单位ms）, 超时返回nil
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.size：number类型, 读取到的数据缓存字节长度
        - r_res.value：EBuff类型, 读取到的数据缓存结果

**4.同步读取消息数据**
> local r_res = read_msg_sync(channel, prot)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - prot：EProtocol类型, 协议对象
- 返回值：
    - r_res：dict类型
        - r_res.timestamp：number类型, 读取发生时的时间（ns）
        - r_res.size：number类型, 读取到的数据缓存字节长度
        - r_res.value：EBuff类型, 读取到的数据缓存结果

**5.事件订阅**
> on_buff_recv(channel, fn)
- 输入参数：
	- channel：EChannel类型, 通信通道对象
	- fn：回调函数, 函数原型为fn(ch, res)
        - ch: EChannel类型, 通信通道对象
        - res: dict类型, 事件触发的消息
