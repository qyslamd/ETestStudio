## 表格相关术语
这里会详细介绍表格的各个动作及其用法。

### 常用动作
![table](./images/table2-1.png)

#### 声明
- 功能：定义local变量，并添加初始值。

  ![table](./images/table2-2.png)

- 【标题】：可以填写适当的内容，也可以为空。
- 【初始值】可以填写各种类型的内容，也可空着不填写。
  - number：
    - 10
    - 52.1
  - boolean：
    - true
    - false
  - string：
    - "我shi字符串"
    - '我shi字符串'
    - [[我shi字符串]]
  - table：
    - {10,20,30,40}
    - {a=10,b=20,c=30,d=40}

- 在【声明】里添加的变量属于本地local变量，只能在当前表格使用。

  ![table](./images/table2-3.png)  

- 在表格中使用的变量需要【声明】里添加定义。如没有声明直接使用某变量，那么该变量的值为nil。

#### 标签
- 相当于lua脚本的注释

  ![table](./images/table2-59.png)

#### 打印
- 对应API：print(v1，v2，...)
- 【标题】填写的内容显示在表格的【标题】栏。
- 【打印内容】
  - 遵循print()的Lua语言语法

    例如："ucdata=",ucdata,"pram=",pram,"msg=",msg,"data=",data

    ![table](./images/table2-4.png)
    
- 【声明】和【打印】的示例：

  ![table](./images/table2-5.png)


#### 延时
- 功能：延长一段时间
- 对应API：etimer.delay(tout_ms)
- 【标题】：可以填写适当的内容，也可以为空。
- 【延时时间】整数类型（大于等于零的整数）。例：200，10000

![table](./images/table2-6.png)

#### 当前时刻
- 功能：程序启动后至当前点的时长
- 对应API：value = etimer.now(format)
- 【标题】：可以填写适当的内容，也可以为空。
- 【变量赋值】可为空。可填写【声明】中的local变量。【执行完当前时刻】后，该变量的值为程序启动后至当前点的时长。

  ![table](./images/table2-7.png)

- 【延时】和【当前时刻】的示例
  - 如下图，因为延时100ms，所以两次当前时刻的值的差**大概**也是100ms。

  ![table](./images/table2-8.png)


#### 退出
- 功能：退出执行程序
- 对应API：exit()
- 示例：

  - 如下图，没有添加动作【退出】，点击执行，程序会一直执行，点击界面右上角的方块才会停止[STOP]。

    ![table](./images/table2-9.png)

  - 添加【退出】后，会自动停止[stop]
    
    ![table](./images/table2-55.png)

#### 自定义脚本
- 功能：可以自定义Lua脚本内容，使用方法灵活。
- 可以填写一条或多条代码，内容不限（定义局部变量，或者调用API等）。建议一个【自定义脚本】只写一条代码。
  - 多条脚本

    ![table](./images/table2-10.png)

  - 一条脚本

### 输出

  ![table](./images/table2-13.png)

#### 数据发送
- 功能：异步输出缓冲区数据。适用于总线型通道。
- 对应API：result = write_buff(channel，buff，option)

  ![table](./images/table2-14.png)

- 【标题】：可以填写适当的内容，也可以为空。
- 【数据格式】与【数据】
  - 【数据格式】有两种：十六进制，字符串
    - 选择【十六进制】时，对应的【数据】输入如下：“112233”或“11 22 33”

      ![table](./images/table2-15.png)

    - 选择【字符串】时候，对应【数据】输入如下：

      ![table](./images/table2-16.png)

- 【通道参数选项】：k-v键值对，缺省参数 nil
  - 根据不同的通道类型，填写对应的参数。可以为空。
    
    ![table](./images/table2-18.png)

  - 【通道参数选项】和流程图的【IO选项】是一样的，只是叫法不同，它们都对应API的参数option。[点击查看【IO选项】](#/document?catalogId=42&id=43&type=doc#option-id)

- 示例

  ![table](./images/table2-17.png)

#### 报文发送
- 功能：使用协议打包报文数据，并在通信通道异步输出。适用于总线型通道。
- 对应API：result = write_msg(channel，prot，msg，is_strict，option)

![table](./images/table2-19.png)

- 【报文数据】
  - 【报文数据】根据【协议】内容填写【报文数据】，以下面协议为例，说明报文数据可填写的几类内容
    
     ![table](./images/table2-20.png)
  - 【报文数据】填写内容：
    - 空：{}（所有协议字段为协议的【自动值】）

       ![table](./images/table2-21.png)

    - 仅指定协议中个别字段的值：{header=0xABCD}（未指定的协议字段为协议的【自动值】）

       ![table](./images/table2-22.png)

    - 十六进制数据：{header=0xABCD,data=11,tail=12} 

       ![table](./images/table2-23.png)

    - 十进制数据：{header=43981,data=11,tail=12}

       ![table](./images/table2-24.png)

- 【通道参数选项】：k-v键值对，缺省参数 nil
  - 根据不同的通道类型，填写对应的参数。可以为空。
    
    ![table](./images/table2-18.png)

  - 【通道参数选项】和流程图的【IO选项】是一样的，只是叫法不同，它们都对应API的参数option。[点击查看【IO选项】](#/document?catalogId=42&id=43&type=doc#option-id)


#### 模拟量输出
- 功能：模拟量通道异步输出
- 对应API：result = write_analog(channel，value)

  ![table](./images/table2-25.png)

- 【数据】：类型为number，也就是双精度的实浮点数。
  - 例：0，2，1.2，-10

#### 数字量输出

- 功能：数字量通道异步输出
- 对应API：result = write_digital(channel，value)

- 【数据】：输出的状态值。
  - true
  - false
  - 1
  - 0
  
  ![table](./images/table2-26.png)

### 输入
![table](./images/table2-27.png)

#### 数据接收
- 功能：异步读取通信通道的输入数据。适用于总线型通道。
- 对应API：result = read_buff(channel，size，tout_ms，option) 
  
![table](./images/table2-28.png)

- 【字节长度】：integer 类型，读取数据的字节长度，0 表示全部读取
- 【超时时长】：当超过输入的时间，就停止接收。单位ms，number 类型(双精度浮点型) 
- 【通道参数选项】：k-v键值对，缺省参数 nil
  - 根据不同的通道类型，填写对应的参数。可以为空。    
  - 【通道参数选项】和流程图的【IO选项】是一样的，只是叫法不同，它们都对应API的参数option。[点击查看【IO选项】](#/document?catalogId=42&id=43&type=doc#option-id)

- 【变量赋值】：需要事先在【声明】里定义该变量，然后在【变量赋值】中填写该变量。如上图，接收数据后，将接收的数据赋值给变量data。

### 测试
![table](./images/table2-36.png)

#### 合格/失败测试
- 功能：当条件成立，返回true；当条件不成立，返回false
- 对应API：passed = verify(condition，fail_tip)
- 【测试条件】：填写条件。例如：a==b
- 【测试失败信息】：string 类型，条件不成立时的提示信息。

- 示例：
  - 【声明】添加变量data，初始值为3.8。所以，条件【data~=3.8】失败，输出测试失败信息【测试失败】和测试结果【false】

    ![table](./images/table2-37.png)

  - 在【声明】中改变data的值【data=0】。条件【data~=3.8】成功，输出测试结果【true】

    ![table](./images/table2-38.png)

#### 数值限度测试
- 功能：当【测试数据源】值在范围内的时候，返回true；值不在范围内时候，返回false。
- 对应API：passed = verify(condition，fail_tip)    

    输入值：    
    condition：boolean类型，预期结果为true的表达式    
    fail_tip：string类型，断言失败时的提示信息    
    返回值：    
    passed：boolean类型，断言是否通过    

  ![table](./images/table2-39.png)

- 【测试数据源】：要判定的变量名称
- 【测试失败信息】：条件失败时的提示信息。输入字符串时需要加上英文引号；也可以输入变量名。
- 【结果赋值】：就是变量赋值，可以进行打印输出或其他操作
- 【限度类型】

  ![table](./images/table2-40.png)

- 示例：将【限度类型】选为【区间】为例

  ![table](./images/table2-41.png)

  - data=10时，在10~20的范围内，所以返回true

    ![table](./images/table2-42.png)

  - data=5时，不在10~20的范围内，输出【测试失败信息】“不在范围内”，返回false。

    ![table](./images/table2-43.png)
