# 02-研究

本目录存放技术研究、资料收集和分析相关的文档。

## 目录说明

- **ETest研究**：凯云ETest功能、架构、技术分析
- **协议研究**：各种总线协议（1553B、ARINC429、CAN等）研究
- **硬件研究**：测试硬件板卡、驱动、接口研究
- **Schema文件**：协议Schema和相关配置文件

## 当前文档

- [ETest功能分析](ETest功能分析.md) - 凯云ETest功能和技术分析
- [总线协议研究](总线协议研究/) - 各种总线协议相关文档
- [Schema文件](Schema/) - 协议Schema和配置文件

## 使用说明

1. 研究文档应包含：来源、分析过程、结论、参考链接
2. 图片等资源文件统一放在 `assets/images/` 目录
3. Schema文件保持原始格式，便于直接使用
