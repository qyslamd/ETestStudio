## 使用脉冲输出通道

该通道支持以下操作：write_pulse、write_pulse_sync

### 简介
脉冲输出通道是一种用于将数字信号转换为脉冲信号的通道，具有以下特点：

1. 脉冲输出：脉冲输出通道将数字信号转换为脉冲信号输出。脉冲信号通常是一系列短暂的高电平或低电平脉冲，用于表示数字信号的高低状态。脉冲输出通道可以通过控制脉冲的频率、占空比等参数来实现对数字信号的精确表示

2. 高速性能：脉冲输出通道通常具有很高的速度和响应能力。它可以快速地将数字信号转换为脉冲信号，并输出到外部设备或其他系统中。高速性能使得脉冲输出通道在需要快速响应的应用中非常有用，例如高速数据传输、时序控制等

3. 精确度高：脉冲输出通道通常具有很高的精确度。它可以通过精确控制脉冲的参数，如频率、占空比等，来准确地表示数字信号的高低状态。精确度高使得脉冲输出通道在需要精确控制和测量的应用中非常有用，例如时钟同步、信号调制等

4. 可编程性强：脉冲输出通道通常具有很强的可编程性。它可以通过软件或硬件配置来实现不同的输出模式和功能。可编程性强使得脉冲输出通道在需要灵活配置和适应不同应用需求的场景中非常有用

5. 多通道支持：一些脉冲输出通道支持多通道输出，可以同时输出多个独立的脉冲信号。多通道支持使得脉冲输出通道在需要同时控制多个信号的应用中非常有用，例如多路信号发生器、多通道数据采集等

### 脉冲输出通道数据读写
**1.异步输出PWM信号**
> local w_res = write_pulse(channel, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - option：dict类型, 可选参数选项
        - option.type：string类型, 固定值`pwm`
        - option.dutycycle：number类型，占空比;`0.5`:表示占空比为50%
        - option.frequency：number类型，频率；`100000`:表示100KHz
- 返回值
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.value：EBuff类型, 数据内容

**2.同步输出PWM信号**
> local w_res = write_pulse_sync(channel, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - option：dict类型, 可选参数选项
        - option.type：string类型, 固定值`pwm`
        - option.dutycycle：number类型，占空比;`0.5`:表示占空比为50%
        - option.frequency：number类型，频率；`100000`:表示100KHz
- 返回值
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.value：EBuff类型, 数据内容

**3.异步输出数字波形信号**
> local w_res = write_pulse(channel, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - option：dict类型, 可选参数选项
        - option.type：string类型, 固定值`waveform`
        - option.time_high：array类型，高电平时间，时间单位s
        - option.time_low：array类型，低电平时间，时间单位s
- 返回值
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.value：EBuff类型, 数据内容

**4.同步输出数字波形信号**
> local w_res = write_pulse_sync(channel, option)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - option：dict类型, 可选参数选项
        - option.type：string类型, 固定值`waveform`
        - option.time_high：array类型，高电平时间，时间单位s
        - option.time_low：array类型，低电平时间，时间单位s
- 返回值
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.value：EBuff类型, 数据内容

**注意：高电平持续时间+低电平持续时间 = 1个周期(单位为秒); 频率=1/周期；占空比一般指一个周期内，高电平所占的比例即高电平时间/周期**
