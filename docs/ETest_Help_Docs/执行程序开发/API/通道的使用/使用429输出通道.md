## 使用ARINC429输出通道

该通道支持以下操作：write_buff、write_buff_sync、write_msg、write_msg_sync

### 简介

ARINC 429输出通道是一种在航空航天领域广泛应用的数字通信接口，具有高可靠性、适应性强、标准化和适合多种数据格式的特点。

ARINC429输出通道具有以下特点：

1. 高可靠性：ARINC 429输出通道设计用于在恶劣环境下稳定可靠地传输数据，能够满足航空航天领域对通信系统高可靠性的要求。

2. 数据传输速率：ARINC 429输出通道通常支持标准的数据传输速率，通常为每秒1000比特，适用于传输飞行数据、控制指令等信息。

3. 灵活性：ARINC 429输出通道可以根据需要配置为单向或双向通信，同时支持多种不同的数据格式和传输模式，使其适用于多种应用场景。

4. 标准化：ARINC 429输出通道符合ARINC 429标准，这意味着它与其他符合该标准的设备和系统具有良好的兼容性，能够实现与其他设备的无缝集成。

5. 数据格式：ARINC 429输出通道通常采用32位字长，其中包括24位的数据字段和8位的标签字段，这种数据格式适合于传输各种类型的航空数据

### ARINC429输出通道的配置及属性

- 波特率：值类型为string，表示传输速率
- 校验方式：值类型为string，表示数据传输过程中数据校验的方式
- 数据位长度：值类型为number，表示通道传输的比特位位数

### ARINC429输出通道的数据读写
**1.异步写入原始数据**
> local w_res = write_buff(channel, buff)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - buff：EBuff类型, 数据缓存
- 返回值
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.size：number类型, 输出的字节长度
        - w_res.value：EBuff类型, 输出值

**2.同步写入原始数据**
> local w_res = write_buff_sync(channel, buff)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - buff：EBuff类型, 数据缓存
- 返回值
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.size：number类型, 输出的字节长度
        - w_res.value：EBuff类型, 输出值

**3.异步写入消息数据**        
> local w_res = write_msg(channel, prot, msg)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - prot：EProtocol类型, 协议对象
    - msg：dict类型, 报文数据
- 返回值：
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.size：number类型, 输出的字节长度
        - w_res.value：EBuff类型, 输出值

**4.同步写入消息数据**
> local w_res = write_msg_sync(channel, prot, msg)
- 输入参数：
    - channel：EChannel类型, 通信通道对象
    - prot：EProtocol类型, 协议对象
    - msg：dict类型, 报文数据
- 返回值：
    - w_res：dict类型
        - w_res.timestamp：number类型, 执行的时间（ns）
        - w_res.size：number类型, 输出的字节长度
        - w_res.value：EBuff类型, 输出值
