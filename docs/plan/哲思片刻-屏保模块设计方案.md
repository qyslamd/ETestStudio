> 日期：2026-06-18

## 一、项目愿景

开发一款跨平台（Win/Mac/Linux）的 C++ Qt 独立桌面应用，名为**"哲思·片刻"**（WisdomMoment）。

**功能极简**：全屏/窗口展示中国古诗词中的哲理金句 + 简短赏析。

**数据完全内置**，零联网、零外部依赖，编译后单文件或极简绿色包。

**CMake 构建**，支持一行 `add_subdirectory(wisdom)` 集成到其他 Qt 项目。

## 四、接口设计

### 4.1 SaverWidgetBase（纯头文件化）

将原有的 .h + .cpp 合并为纯头文件：

```cpp
// src/tuxsaver/SaverWidgetBase.h
#pragma once
#include <QWidget>

class SaverWidgetBase : public QWidget {
    Q_OBJECT
public:
    explicit SaverWidgetBase(QWidget* parent = nullptr) : QWidget(parent) {}
    ~SaverWidgetBase() override = default;

    virtual void onActivate() {}           // 覆盖层显示时
    virtual void onDeactivate() {}         // 覆盖层隐藏时
    virtual QString displayName() const = 0;
    virtual void setIdleThreshold(int) {}  // 可选覆盖
};
```

约 15 行有效代码，inline 在头文件中。

## 五、数据层设计

### 5.1 SQLite 表结构

```sql
CREATE TABLE poems (
    id        INTEGER PRIMARY KEY AUTOINCREMENT,
    sentence  TEXT NOT NULL,          -- 金句正文
    source    TEXT NOT NULL,          -- 出处（如 "苏轼《赤壁赋》"）
    commentary TEXT,                   -- 简短赏析（50-200字）
    tag       TEXT,                   -- 标签（"哲理"/"人生"/"自然"/"壮志"）
    dynasty   TEXT                    -- 朝代
);
```

### 5.2 初始化流程

```
应用启动
  │
  ├─ 检查 QStandardPaths::AppDataLocation + "/wisdom/poems.db"
  │     │
  │     ├─ 存在 → 打开 SQLite 连接
  │     │
  │     └─ 不存在 → 调用 createFallbackDatabase()
  │                   └─ 在可写路径创建 .db 文件
  │                      ├─ CREATE TABLE
  │                      └─ INSERT INTO 50+ 条硬编码金句
  │
  └─ SELECT id FROM poems → 全部 ID 加载到 QVector<int>
       └─ std::shuffle 打乱 → currentIndex = 0
```

### 5.3 轮播算法

```cpp
QVector<int> ids_;
int currentIndex_ = 0;

void shuffleIds() {
    std::shuffle(ids_.begin(), ids_.end(), rng_);
    currentIndex_ = 0;
}

void nextPoem() {
    currentIndex_++;
    if (currentIndex_ >= ids_.size()) {
        shuffleIds();  // 遍历完重新打乱
    }
    // 根据 ids_[currentIndex_] 加载诗词
}
```

## 七、构建配置

### 7.1 wisdom/CMakeLists.txt

```cmake
cmake_minimum_required(VERSION 3.16)

find_package(Qt5 COMPONENTS Core Gui Widgets Sql QUIET)
if(NOT Qt5_FOUND)
    find_package(Qt6 REQUIRED COMPONENTS Core Gui Widgets Sql)
endif()

# ── 库 ──
add_library(wisdom_lib STATIC
    src/WisdomWidget.cpp
    src/WisdomDatabase.cpp
)

target_include_directories(wisdom_lib PUBLIC include ${CMAKE_SOURCE_DIR}/src)
target_link_libraries(wisdom_lib PUBLIC Qt5::Core Qt5::Gui Qt5::Widgets Qt5::Sql)
qt5_use_modules(wisdom_lib Core Gui Widgets Sql)  # Qt6 兼容
set_target_properties(wisdom_lib PROPERTIES AUTOMOC ON)

# ── 独立可执行 ──
if(WISDOM_BUILD_VIEWER)
    add_executable(wisdom_viewer src/main.cpp)
    target_link_libraries(wisdom_viewer PRIVATE wisdom_lib)
endif()
```

### 7.2 根 CMakeLists.txt 集成

```cmake
# 根 CMakeLists.txt 中
add_subdirectory(wisdom)
```

## 八、TuxSaverOverlay 集成方案

### 8.1 模式选择机制

在 `TuxSaverOverlay` 构造函数中创建多个 `SaverWidgetBase` 实例，用 `QStackedWidget`（或 `setVisible(false)` 切换）管理：

```cpp
// TuxSaverOverlay 构造
modes_.append(new TuxSaverWidget(this));
modes_.append(new WisdomWidget(this));
currentMode_ = 0;
saver_ = modes_[0];  // 默认企鹅屏保
```

通过键盘快捷键（如 `Ctrl+Left/Right`）或在右上角加模式切换按钮。切换时调用 `onDeactivate()` → 切换策略 → `onActivate()`。

### 8.2 空闲检测不变

主窗口的 `tux_idle_check_timer_` 逻辑不变，`TuxSaverOverlay` 的 `activate()` 和 `deactivate()` 接口对 `main_window.cpp` 透明。

## 十、风险与备忘

| 风险 | 缓解措施 |
|------|---------|
| 楷体在 Mac/Linux 缺失 | QFont fallback 到 Noto Serif CJK / system serif |
| SQLite 驱动在 Qt 静态编译时缺失 | 文档注明需确保 QSqlite plugin 可用 |
| 50+ 条金句硬编码数组文件较大 | 分文件存储，或使用 raw string literal |
| TuxSaverOverlay 切换到 WisdomWidget 后背景截图冲突 | WisdomWidget 自身绘制宣纸背景，不依赖 overlay 截图 |
