# 哲思·片刻 — 诗词屏保模块设计方案

> 日期：2026-06-18（修订版）
> 作者：Claude Code assistant
> 相关模块：`etest_tuxsaver` → 已合并到 `src/app/widgets/`

---

## 一、项目愿景

在 ETestStudio 应用内实现两种屏保模式的策略切换：
- **模式 A**：企鹅动画屏保（已有）
- **模式 B**："哲思·片刻"诗词屏保（新增）

展示中国古诗词中的哲理金句 + 简短赏析。数据完全内置，零联网、零外部依赖。

---

## 二、架构概述

```
┌──────────────────────────────────────────────────────────┐
│                    TuxSaverOverlay                        │
│  (覆盖层: 暗色遮罩 + 关闭按钮 + 模式切换按钮)             │

```

### 4.1 SaverWidgetBase


### 4.3 WisdomDatabase 接口

```cpp
class WisdomDatabase {
public:
    static WisdomDatabase& instance();

    bool initDatabase(const QString& writablePath);
    QVector<int> getAllIds() const;
    bool getPoem(int id, QString& sentence, QString& source,
                 QString& commentary, QString& tag, QString& dynasty) const;

    // 内置 50+ 条保底数据
    static void createFallbackDatabase(const QString& dbPath);
    static QVector<PoemData> builtinPoems();
};
```

> **简化设计**：去除 WisdomDatabase 到 WisdomWidget 的数据解耦。
> WisdomWidget 在构造时从 WisdomDatabase 加载所有诗词到内存 `QVector<PoemData>`，
> 轮播在内存中完成，减少每次切换的数据库查询开销。

## 五、数据层设计

### 5.1 SQLite 表结构

```sql
CREATE TABLE poems (
    id        INTEGER PRIMARY KEY AUTOINCREMENT,
    sentence  TEXT NOT NULL,          -- 金句正文
    source    TEXT NOT NULL,          -- 出处（如 "苏轼《赤壁赋》"）
    commentary TEXT,                   -- 简短赏析（50-200字）
    tag       TEXT,                   -- 标签（"哲理"/"人生"/"自然"/"壮志"）
    dynasty   TEXT                    -- 朝代
);
```

### 5.2 初始化流程

```
WisdomWidget 构造
  │
  ├─ WisdomDatabase::instance().initDatabase(writablePath)
  │     │
  │     ├─ poems.db 存在 → 打开 SQLite 连接
  │     │
  │     └─ 不存在 → createFallbackDatabase()
  │                    ├─ CREATE TABLE
  │                    └─ INSERT INTO 50+ 条硬编码金句
  │
  ├─ getAllIds() → QVector<int> ids
  ├─ std::shuffle 打乱
  └─ 按序加载第一句显示
```

### 5.3 轮播算法

```cpp
int currentIndex_ = 0;

void shuffleIds() {
    std::shuffle(ids_.begin(), ids_.end(), rng_);
    currentIndex_ = 0;
}

void nextPoem() {
    // 淡出动画 → 切换文本 → 淡入动画
    fadeOut();
    // 在淡出结束后执行：
    currentIndex_++;
    if (currentIndex_ >= ids_.size()) {
        shuffleIds();
    }
    loadPoem(ids_[currentIndex_]);
    fadeIn();
}
```

## 八、TuxSaverOverlay 集成方案

### 8.1 模式选择机制

```cpp
// TuxSaverOverlay 构造
modes_.append(new TuxSaverWidget(this));
modes_.append(new WisdomWidget(this));
currentMode_ = 0;
```

右上角关闭按钮旁增加模式切换按钮（左右箭头），点击时切换策略。
切换流程：
```
onDeactivate() → 切换 saver_ 指针 → setGeometry → onActivate()
```

### 8.2 空闲检测不变

主窗口的 `tux_idle_check_timer_` 逻辑不变，`TuxSaverOverlay` 的 `activate()` 和 `deactivate()` 接口对 `main_window.cpp` 透明。

## 十、风险与备忘

| 风险 | 缓解措施 |
|------|---------|
| 楷体在 Mac/Linux 缺失 | QFont fallback 到 Noto Serif CJK / system serif |
| SQLite 驱动在 Qt 静态编译时缺失 | 编译期检查，缺失时降级为纯内存数组模式 |
| 50+ 条金句硬编码数组文件较大 | 使用 raw string literal 减少转义 |
| TuxSaverOverlay 切换到 WisdomWidget 后背景截图冲突 | WisdomWidget 自身绘制宣纸背景，不依赖 overlay 截图 |
