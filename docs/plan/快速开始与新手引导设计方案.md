# 快速开始与新手引导设计方案

## 1. 问题陈述

Ribbon 新增的「开始」页目前只有文件操作（新建/打开项目、新建/打开文件），缺少对新
用户的**引导性**。两处增强：

- **快速开始**：给新用户一条"几步建好第一个测试工程"的快捷路径，走向导（wizard）
  模式。本期先做 **UI 空壳**（入口 + 向导界面骨架），业务动作后接。
- **新手引导**：帮助新用户了解 ETest Studio 各功能（新建项目/拓扑/协议/测试程序/
  执行）。仓库已有可复用的引导演示机制（`examples/guidance-demo`），整体迁移到主
  程序，并在 ribbon「帮助」页加入口。

## 2. 架构回顾（现状）

### 2.1 Ribbon「开始」页

`MainWindow::setupRibbon` 新增常驻「开始」页（tab 最左 index 0），文件 panel 含
新建项目/打开项目/新建文件/打开文件 4 个大按钮（复用现有 QAction）。无独立入口承载
"快速开始"。

### 2.2 guidance-demo（可复用机制）

`examples/guidance-demo/`（独立小 demo，仅 Qt Widgets）：

| 文件 | 职责 |
|---|---|
| `guidance_config.h/.cpp` | `GuidanceStep`（单步：target=QWidget*/QRect/QPixmap，标题/描述，进入/退出回调）、`GuidanceFlow`、`GuidanceConfig` |
| `guidance_controller.h/.cpp` | 引导流程控制器（步骤推进、进入/退出） |
| `guidance_homepage.h/.cpp/.ui` | 引导首页（`Qt::Popup` 浮动面板 + 主题列表，点击进入） |
| `guidance_presentation.h/.cpp` | 演示层（高亮 target、遮罩/箭头/气泡） |
| `window_mover.h/.cpp` | 窗口移动辅助 |
| `utility_qt.h/.cpp` | 通用 Qt 工具（`createGraphicsShadow` 等） |

**迁移前需注意的既有问题**（审查发现）：
- `guidance_presentation.cpp` 大量 C++ `setStyleSheet` 硬编码样式（违项目规范，须 QSS 化）。
- 3 个头文件用 `#ifndef`（须改 `#pragma once`）。
- `guidance_homepage.cpp` 首页是 `Qt::Popup` 浮动面板（非全屏遮罩），迁入须改形态。
- `pixmap_smile_` 资源路径拼错（`resrouces`）且为 emoji 风格图，删除。
- `guidance_homepage.cpp:71-78` paintEvent 先 return 后绘制（不可达死代码）；
  `withDescripton` 拼写错误；`guidance_controller.cpp` 引入未使用的 `QDesktopWidget`。

### 2.3 已存在的可复用件

- `BaseWizardDialog`（`src/app/wizards/`）：addPage/setCurrentPage/上一步/下一步/完成/
  取消 导航，`WizardTemplateCard` 模板卡片。快速开始复用。
- `src/app/utils/window_mover.h/.cpp`：与 demo 的 WindowMover 接口一致，**直接复用，
  不迁移 demo 版本**。
- 内嵌编辑器注册：`etopo→topology`、`eproto/eprotox→protocol`、`etprog→testprogram`
  （EditorManager.cpp:110-113），`openFile` 可打开；`navigateTo(1)` 切执行页。

## 3. 目标设计

### 3.1 快速开始（UI 空壳）

- **入口**：ribbon「开始」页文件 panel 最前加「快速开始」大按钮（强调色，图标 `plus`，
  已存在），点击弹出快速开始向导。
- **向导**：`QuickStartWizard : BaseWizardDialog`，`setCreateButtonText("完成")`，三页
  占位：
  1. **模板选择**：设备类模板卡片（综合测试台 / AD 采集 / DA 输出 / 串口·CAN·A429，
     对应 TopologyFileWizard 的设备卡模板语义）。**空壳期用静态占位卡片**；功能后接时
     把该模板数据抽为公共源（如 `wizards/DeviceTemplates.h`）供 TopologyFileWizard 与
     QuickStartWizard 复用，避免两份维护。
  2. **项目信息**：名称 / 位置 / 浏览（占位控件，无实际创建）。
  3. **摘要**：显示所选模板与项目信息（占位），完成按钮。
- 底部导航由 BaseWizardDialog 承载；`onCreateValidate()` 返回 true，完成/取消本期
  **仅关闭不创建**（D3）。功能后接：映射到 `ProjectController::newProject`。

### 3.2 新手引导（整体迁移 guidance-demo）

- **迁移清单**（至 `src/app/guidance/`）：
  - `guidance_config`、`guidance_controller`、`guidance_homepage`、`guidance_presentation`
    （含 `.ui`）。
  - `utility_qt`：只迁所需子集（`createGraphicsShadow`），并入 `etest::app`。
  - **剔除 `window_mover`**：复用 `src/app/utils/window_mover`。
- **迁移规范**：类入 `etest::app` 命名空间（`Q_DECLARE_METATYPE` 同步）；头保护符改
  `#pragma once`；`setStyleSheet` 全部改 QSS（objectName 选择器，如 `#guidanceBubble`/
  `#guidanceTitle`），注册到 `src/app/resources/styles/`（default + vscode 对称），颜色
  经 `ThemeManager` token（hoverBackground/textColor/accentColor 等）自绘或 QSS 引用，
  明暗主题适配；删除坏资源（emoji 笑脸）与死代码。
- **入口**：ribbon「帮助」页「关于」panel 加「新手引导」动作，点击打开引导首页。
- **引导首页形态**：`Qt::Popup` 浮动面板改为**全屏遮罩**（普通无边框顶层，覆盖整个主
  窗口；参考 OverlayDialog 的遮罩思路），列 5 个主题，点击进入对应 `GuidanceFlow`。
- **viewport**：演示层遮罩覆盖 **MainWindow 全窗口**（含 ribbon）。引导期间 ribbon 被
  遮罩属预期，用户通过气泡上的导航按钮操作；这样主题 1/5（高亮 ribbon 的新建项目/
  运行按钮）也能经 `mapFromGlobal` 正确映射高亮，避免 central_stack_ 边界裁剪目标。
- **引导主题**（GuidanceConfig 5 条）与 enter 回调：
  1. 新建项目 → 高亮「开始」页新建项目（经 SARibbon API 定位按钮）。
  2. 拓扑编辑 → `openFile` 打开 `.etopo` 后高亮画布。
  3. 协议编辑 → `openFile` 打开 `.eproto` 后高亮节点树/位图。
  4. 测试程序 → `openFile` 打开 `.etprog` 后高亮步骤表格。
  5. 执行运行 → `navigateTo(1)` 后高亮运行按钮。
- **enter 回调耦合**：Guidance 通过 MainWindow 公开方法访问（`openFile`/`navigateTo`/
  编辑器定位），不依赖私有成员；MainWindow 持有 Guidance 实例或注入回调。
- **无项目兜底**：主题 2-4 需要已打开的项目及对应文件；无项目时首页该主题置灰/提示
  "先新建项目"。
- **高亮时序**：编辑器是 `openFile` 后才创建 dock，enter 回调后需在编辑器加载完成
  （或 QTimer 单次延时）后再映射 target 高亮，避免 `highlightRect_` 计算错误。

## 4. 方案选项对比

### 快速开始

- **A（推荐）**：独立 `QuickStartWizard`，复用 `BaseWizardDialog` 与模板卡片，模板数据
  后接时抽公共源。
- B：复用 `NewProjectWizard` 加参数。耦合高，语义混淆。

### 新手引导

- **A（推荐）**：整体迁移 guidance-demo 机制（QSS 化 + 主题适配 + 全屏遮罩），功能
  完整。
- B：精简静态引导列表（无分步高亮）。轻量但引导性弱，放弃 demo 已有能力。

## 5. 决策记录

| 编号 | 决策 | 理由 |
|---|---|---|
| D1 | 快速开始走 `BaseWizardDialog` 独立向导，UI 空壳先行 | 复用向导基础设施；本期只做界面骨架 |
| D2 | 快速开始三页：模板选择（设备类）/ 项目信息 / 摘要 | 引导"几步建测试工程"，模板为设备卡类 |
| D3 | 快速开始完成/取消本期不创建 | 功能后接；UI 先行验证界面与导航 |
| D4 | 新手引导整体迁移 guidance-demo 机制 | 复用成熟的分步高亮/窗口移动能力 |
| D5 | 新手引导入口放 ribbon「帮助」页 | 用户确认：新手引导属于"帮助"范畴 |
| D6 | 引导主题覆盖 5 大功能（新建项目/拓扑/协议/测试程序/执行） | 覆盖核心操作闭环 |
| D7 | 迁移后 guidance-demo 保留 | 独立参考 demo，不删除 |
| D8 | 迁移剔除 window_mover，复用 `utils/window_mover` | 主程序已有同接口实现，避免重复 |
| D9 | 迁移时 setStyleSheet 全部改 QSS + ThemeManager token，明暗主题适配 | 符合项目规范，避免 demo 固定浅色 |
| D10 | 引导首页改全屏遮罩（非 demo 的 Popup 浮动面板） | Popup 顶层不随主窗口移动且形态不符 |
| D11 | 模板数据后接时抽公共源（DeviceTemplates.h），空壳期静态卡片 | 避免快速开始与 TopologyFileWizard 两份模板维护 |

## 6. 影响范围与实现要点

- 快速开始：
  - `src/app/wizards/QuickStartWizard.h/.cpp`：BaseWizardDialog 三页占位。
  - `src/app/MainWindow.cpp`：setupRibbon「开始」页加「快速开始」大按钮（`plus` 图标，
    已存在），trigger new QuickStartWizard（exec）。
  - `src/app/CMakeLists.txt`：注册 QuickStartWizard。
- 新手引导：
  - `src/app/guidance/`：迁移 guidance_config/controller/homepage/presentation +
    utility_qt 子集（createGraphicsShadow），命名空间/头保护/QSS 化/删死代码。
  - `src/app/guidance/GuidanceConfig.cpp`：配置 5 条主题与各自 Flow（含 enter 回调）。
  - `src/app/MainWindow.cpp`：帮助页加「新手引导」动作，trigger 打开引导首页；提供
    Guidance 所需公开方法（openFile/navigateTo/编辑器定位）；MainWindow 持有 Guidance。
  - `src/app/resources/styles/default.qss` + `vscode.qss`：引导气泡/遮罩 QSS。
  - `src/app/CMakeLists.txt`：注册 guidance 源文件 + .ui。
- guidance-demo 保留。

## 7. 验收标准

1. ribbon「开始」页有「快速开始」大按钮，点击弹出三页向导（设备模板/项目信息/摘要），
   导航正常，完成/取消仅关闭不创建。
2. 「帮助」页有「新手引导」入口，点击打开全屏遮罩引导首页，列出 5 个主题。
3. 选择主题后分步高亮对应 UI 元素，标题/描述气泡显示，步骤可前进/后退/退出；无项目
   时依赖文件的主题有兜底提示。
4. 明暗主题下引导首页、气泡、遮罩正常（QSS + ThemeManager，无硬编码色）。
5. 编辑器类主题在编辑器加载完成后再高亮，无错位。
6. Windows 与 WSL Linux 编译通过。
