# 新建项目和新建文档向导设计方案

## 背景

新建文件/项目缺乏统一的向导框架：新建文件仅弹 `QFileDialog` 选路径或直接创建
空文件后 inline 重命名，新建项目为单页对话框。目标是为新建项目与每类已注册
文件类型提供独立向导，并让所有入口（app_menu、项目树右键菜单、无项目时）指向
同一套向导框架。任务量较大，采用分阶段实施，先从新建项目向导打样通用容器。

## 问题陈述

1. **无项目时**：`createStandaloneFile()` 仅弹 `QFileDialog::getSaveFileName`，无法配置文件初始内容或模板。
2. **有项目时**：`createNewFile()` 在分类目录下直接创建空文件，inline 重命名，无参数收集步骤。
3. **新建项目**：单页对话框（`NewProjectDialog`），无向导式引导。
4. **入口分散**：快捷按钮、右键菜单、侧边栏管理器各自实现新建逻辑，缺乏统一框架。

## 现状分析

### 新建文件入口

| 入口位置 | 当前行为 |
|---|---|
| ProjectStructureWidget 占位页快捷按钮 | `createNewFile` / `createStandaloneFile` |
| 项目树右键菜单（空白区 / 分类节点） | `createNewFile(QString(), ...)` / `createNewFile(catId, ext, label)` |
| Ribbon Application Button 菜单 | 无新建文件 action |
| 侧边栏 TopologyManagerWidget / TestProgramManagerWidget | `onNewTopology()` / `onNewTestProgram()` 弹对话框创建 |
| 侧边栏 ProtocolManagerWidget | `onNewIcdConfig()` / `onNewFrame()` 创建 ICD 配置/帧 |

### 已注册文件类型（来自 `defaultCategories()`）

| 类型 ID | 显示名 | 扩展名 | 新建标签 |
|---|---|---|---|
| protocol | 协议 | .eproto | 新建协议文件 |
| topology | 拓扑 | .etopo | 新建拓扑文件 |
| testprog | 测试程序 | .etprog | 新建测试程序 |
| script | 脚本 | .lua | 新建脚本 |
| config | 配置 | .json | 新建配置文件 |
| run | 运行 | .erun | 新建运行配置 |

> report / backup 无新建能力（`newFileExt` 为空）。

## 方案设计

### 决策记录

| # | 决策 | 理由 |
|---|---|---|
| 1 | 向导容器用 QDialog + QStackedWidget 自绘，不用 QWizard | 主题统一，可复用 OverlayDialog，页面导航可控 |
| 2 | 类型选择页 → 具体类型页采用同一容器动态换页 | 避免嵌套弹窗，流程连贯 |
| 3 | 侧边栏特殊新建（ICDConfig / 帧）V1 不纳入向导 | 非文件树节点，避免向导框架变味 |
| 4 | 模板 V1 只做「空文件 / 默认模板」两级 | 仅 testprog 有默认模板，不做扩展死口 |
| 5 | 无项目时新建文件保存后不自动打开所在项目 | 不动项目状态，避免误切工作区 |

### 整体架构

```
新建入口
└── 向导容器 (BaseWizardDialog : OverlayDialog)
    ├── QStackedWidget
    │   ├── 类型选择页 (FileTypeSelectionPage)  ← 从 app_menu / 空白区进入时展示
    │   └── 具体类型页面组 (各类型 1~N 页, 按需 addWidget)
    └── 底部导航栏 (上一步 / 下一步 / 完成 / 取消)
```

### 向导入口路由

1. **app\_menu "新建文件" action**：从类型选择页进入，选中类型后动态加载对应页面组。
2. **项目树右键（分类节点）**：按 `catId` 直接进入该类型第一页，跳过类型选择页。
3. **项目树右键（空白区）**：从类型选择页进入。
4. **无项目时**：同上，但不显示"保存到项目目录"选项，改为路径选择器。

### 通用向导容器 BaseWizardDialog

- `WizardPage` 基类：`virtual bool isComplete()` + 信号 `completeChanged()`。
- 容器：`addPage()` / `setCurrentPage()` / `next()` / `back()`，页面切换时同步导航
  按钮使能（首页 back 禁用，末页 finish 显示、next 隐藏，next/finish 使能由当前页
  `isComplete()` 驱动）。
- 通过 `setWidget(contentWidget)` 走 `OverlayDialog` 的阴影/圆角/飞入动画。

### 类注册机制（文件向导，待实施）

```cpp
struct FileWizardInfo {
  QString typeId;           // "protocol", "topology", ...
  QString displayName;      // "协议文件"
  QString iconName;         // 图标名
  std::function<int(BaseWizardDialog* wizard)> addPages;  // 追加页面, 返回页数
};

class FileWizardRegistry {
public:
  static FileWizardRegistry& instance();
  void registerWizard(const FileWizardInfo& info);
  QStringList registeredTypeIds() const;
  BaseWizardDialog* createWizard(const QString& typeId, bool hasProject,
                                 const QString& projectPath,
                                 QWidget* parent = nullptr);
};
```

### 与现有代码的关系

- `createNewFile()` / `createStandaloneFile()` 保留作为兼容入口，内部改为调用向导。
- 侧边栏管理器特殊新建（ICDConfig / 帧）保持现状。
- 向导完成后发 `fileOpenRequested(path)` 打开编辑器。注意现有 `fileCreated` 信号
  在 `src/app` 无任何 connect 消费（信号死角），向导不走它。

#### 审查与修复记录（subagent 代码审查，2026-08-07）

5 个并行 subagent 分工审查（CLAUDE.md 合规、容器逻辑、页面、自绘控件、集成/脚本/QSS/图标），
严重度 [高]/[中]/[低] 分级。已修复项如下：

- **BaseWizardDialog（Enter 键）**：移除 `setDefault`（其与 `keyReleaseEvent` 兜底存在
  双重触发隐患），改为 `keyReleaseEvent` 处理 Enter/Return（焦点不在按钮上时触发下一步/创建）。
  新增 `closeEvent`（Alt+F4 走同一 `requestCancelConfirmation()` 二次确认）。转场动画开始时
  立即刷新步骤条，消除 300ms 内步骤条滞后旧页。
- **信息页校验**：`onTextChanged()` 输入重新合法时立即清除 error 红框（原先等 1.2s 定时器
  到期，残留明显）；`validatePage()` 位置为空时红闪位置输入框；`projectLocation()` 空输入
  返回空串（原 `QDir("").absolutePath()` 误返回 cwd）；`initDefaultLocation()` 派生目录
  不存在时回退主目录。
- **摘要刷新**：进入完成页（`currentPageChanged` == 末页）时兜底再刷新一次，保证摘要与最终
  输入一致。
- **WizardStepBar**：标签宽度限制在本列剩余空间并用 `elidedText` 省略号截断（原整列宽
  `colW` 溢出到下一列）；字号从 `this->font()` 派生（兼容 pointSize/pixelSize 配置），
  去掉硬编码 `setPixelSize(13/14)`。
- **SwitchButton**：滑块几何钳制（直径 ≥ 4px、右端点不早于左端点、垂直居中），
  消除退化尺寸（高过小/宽小于高）下的负几何。
- **QSS 死样式**：删除 13 个主题中 25 个 legacy `NewProjectDialog` 块
  （`previewLabel` / `errorLabel` / `dlg_contentWidget`，审查确认均无代码引用）。
- **inject_wizard_qss.py 幂等瑕疵**：`tail.lstrip("\n")` 修复重复注入时尾部空行逐次累积；
  有 START 无 END 的半损坏状态改为整体替换修复。
