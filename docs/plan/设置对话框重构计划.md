# 设置对话框重构计划

## 背景

第一轮重构已完成（commit `1624fc0`）：页面重组、VS Code 风格设置行、修复 addButtonRow bug、两套 QSS 适配。

当前布局仍存在以下问题：
1. **没有底部按钮栏** — 缺少确定/取消/应用等操作入口
2. **QTreeWidget 导航老气** — 树形控件用于5个扁平分类太重
3. **QScrollArea 套 QStackedWidget** — 导致尺寸计算问题，内容少时出现滚动条空白
4. **设置行没有视觉分组** — 同一 section 下的设置行缺乏卡片容器包裹

## 改造内容

### 1. 左侧导航：QTreeWidget → QListWidget

- `QTreeWidget* tree_` → `QListWidget* list_`
- 扁平列表，每项 `QListWidgetItem` 带 text（暂不加图标，后续可补）
- `setIconSize(QSize(16,16))`，项高度通过 QSS `padding` 控制
- 选择信号从 `currentItemChanged` 改为 `currentRowChanged(int)` → `pages_->setCurrentIndex(int)`
- 固定宽度保持 180px

### 2. 去掉 QScrollArea，QStackedWidget 直接填充

- 移除 `scroll_area_` 成员
- 主 layout 改为 `QVBoxLayout`：上面是 `QHBoxLayout`（导航 + 内容），下面是按钮栏
- `pages_` 直接 add 到 content layout，不再包 QScrollArea
- **"外观"页**内容多，在该页面内部包一层 `QScrollArea`；其他页面不需要
- **头文件变更**：移除 `#include <QTreeWidget>`，新增 `#include <QListWidget>`（`<QScrollArea>` 保留，外观页仍需要）
- **后续扩展**：若某页内容未来增多超出可视区域，可独立为该页添加内层 `QScrollArea`，不影响整体结构

### 3. 设置行卡片分组

- 新增 `createSettingsCard(QWidget* parent, const QString& title)` 方法，替代 `createSectionHeader()`
- 创建 `QWidget#SettingsCard` 容器，内含：
  - `QLabel#SettingsCardTitle`（卡片标题）
  - 设置行（通过卡片内部 layout 添加）
- 卡片样式：圆角背景 + 轻微边框

**方法签名：**
```cpp
QWidget* createSettingsCard(QWidget* parent, const QString& title);
```

> **设计决策：返回 `QWidget*` 而非 `QVBoxLayout*`**
> 返回卡片容器 widget 本身，调用方通过 `cardWidget->layout()` 获取布局添加行。
> 这样更直观、更通用——调用方可以直接对卡片设置属性或嵌套，
> 不需要通过 `parentWidget()` 反查，避免隐式依赖。

**页面改造示例：**
```cpp
// 之前
layout->addWidget(createSectionHeader(QStringLiteral("编辑器")));
addSpinBoxRow(page, ...);

// 之后
auto* card = createSettingsCard(page, QStringLiteral("编辑器"));
addSpinBoxRow(card, ...);  // addSettingRow 内部调用 card->layout()->addWidget(row)
```

### 4. 底部按钮栏

**布局结构：**
```
QVBoxLayout (主)
├── QHBoxLayout (content)
│   ├── QListWidget (list_, 180px)
│   └── QStackedWidget (pages_, stretch=1)
└── QHBoxLayout (button bar)
    ├── stretch
    ├── 确定 (btn_ok_)
    ├── 取消 (btn_cancel_)
    └── 应用 (btn_apply_)
```

**按钮语义（实时生效模式）：**
- **确定** → `accept()`（关闭对话框，设置已实时生效）
- **取消** → `reject()`（关闭对话框，设置已实时生效，取消仅是语义上的"我改完了"）
- **应用** → `ConfigManager::instance().sync()`（立即同步到磁盘）

> **设计决策：为什么选择实时生效而非暂存模式？**
> 当前所有设置控件通过 `ConfigManager::set()` 实时写入，`onConfigChanged` 双向同步。
> 改为暂存模式（点确定才生效、取消可回退）需要：记录打开前快照、暂存所有改动、
> 确定时批量写入、取消时回滚——改动量大且与现有 ThemeManager 即时响应机制冲突
> （主题切换需要立即生效以提供预览效果）。因此保持实时生效，底部按钮仅作为
> 关闭/保存入口。这与 VS Code 设置界面理念一致。

**按钮栏样式：**
- 上方 1px 分隔线通过 QSS `border-top` 实现
- 按钮栏 `QHBoxLayout`，右侧靠齐

### 5. QSS 变更

#### default.qss（浅色）

- `SettingsDialog QTreeWidget` → `SettingsDialog QListWidget`（导航样式）
  - 背景 `#F5F5F5`，选中 `#CCE4F7`，hover `#E0E0E0`
- 新增 `QWidget#SettingsCard`：
  ```css
  background-color: #FAFAFA;
  border: 1px solid #E0E0E0;
  border-radius: 8px;
  ```
- 新增 `QLabel#SettingsCardTitle`：
  ```css
  color: #333333;
  font-weight: bold;
  font-size: 13px;
  padding: 8px 12px 4px;
  ```
- 新增 `QWidget#SettingsButtonBar`：
  ```css
  border-top: 1px solid #E0E0E0;
  background-color: #FFFFFF;
  ```
- 移除旧的 `SettingsDialog QScrollArea` 相关选择器（外层不再有 ScrollArea）
- **清理重复选择器**：`default.qss` 当前第 601 行和第 604 行有两个重复的 `SettingsDialog QStackedWidget > QWidget`，重构时合并为一个

#### vscode.qss（深色）

- 同上深色版本
- `QListWidget` 导航：背景 `#252526`，选中 `#094771`，hover `#2A2D2E`
- `QWidget#SettingsCard`：背景 `#2D2D2D`，边框 `#3C3C3C`，圆角 8px
- `QLabel#SettingsCardTitle`：`#CCCCCC`，bold
- `QWidget#SettingsButtonBar`：`border-top: 1px solid #1E1E1E`，背景 `#252526`
- 移除 `SettingsDialog QScrollArea > QWidget` 选择器

## 不改动的部分

- `addSettingRow()` 的左标题+描述、右控件布局不变
- `addSpinBoxRow`/`addCheckBoxRow`/`addComboBoxRow`/`addButtonRow` 签名不变
- 实时生效机制不变（设置改动立即写入 ConfigManager）
- `onConfigChanged()` 双向同步逻辑不变
- 主题切换/样式同步逻辑（`onThemeChanged`、`setStyleSheet(qApp->styleSheet())`）不变

## 后续扩展

- **导航图标**：`QListWidget` 暂用纯文字，后续可利用 `QListWidgetItem::setIcon()` 添加每项图标
- **页面滚动**：当前仅"外观"页内嵌 `QScrollArea`，后续若其他页面内容增多超出可视区域，可独立为该页添加内层 `QScrollArea`
