# 拓扑监听器运行时 — 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) for tracking.

**Goal:** 实现监听器在引擎运行时的数据采集、UI 实时展示和 .etlog 持久化。

**Architecture:** 新增独立 `MonitorManager` 组件，通过 `StepRunner::hardwareOperationFinished` 信号被动嗅探硬件操作数据，按 `(deviceId, devicePort)` 查表匹配监听器通道。`central_stack_` 提升到 `setCentralWidget`，page 1 为完全独立的 `ExecutionDashboard`。

**Tech Stack:** Qt 5.14.2 (Core, Widgets), QScintilla, QGraphicsView, QCustomPainter (WaveformWidget)

## 接口契约

### MonitorManager

```cpp
// MonitorManager.h
namespace etest::engine {

struct MonitorTapInfo {
  int monitorIndex;
  int channelIndex;      // = taps[] 数组下标，非物理通道号
  QString deviceId;       // 来自 tap.deviceId（UUID）
  QString devicePort;     // 来自 tap.devicePort
};

struct MonitorSample {
  int monitorIndex;
  int channelIndex;
  double engValue;           // 工程值
  double rawValue = 0.0;     // AD/DA 单整数
  QByteArray rawFrame;       // CAN/Serial/A429 帧字节
  QDateTime timestamp;       // slot 中取 currentDateTime()
};

class MonitorManager : public QObject {
  Q_OBJECT
 public:
  explicit MonitorManager(QObject* parent = nullptr);

  // 加载拓扑文档，重建查表（每次 start() 调用，单参数）
  // 遍历 monitors[].taps[]，用 tap.deviceId + tap.devicePort 建 lookup_table_
  void loadFromTopology(const QJsonObject& topologyDoc);

  // 订阅某个通道的采样通知（主线程同步调用）
  using SampleCallback = std::function<void(const MonitorSample&)>;
  void subscribe(int monitorIndex, int channelIndex, SampleCallback cb);
  void unsubscribe(int monitorIndex, int channelIndex);

  // 硬件操作完成回调（由 StepRunner 信号触发，主线程执行）
  void onHardwareOpFinished(const QString& deviceId,
                             const QString& portName,
                             const QByteArray& rawFrame,
                             double rawValue,
                             double engValue);

  // 获取监听器树状结构（供 SignalTreePanel 构建树）
  struct MonitorTreeEntry {
    int monitorIndex;
    QString name;
    QString deviceType;
    int channelCount;
  };
  QList<MonitorTreeEntry> monitorTree() const;

  // 获取缓冲数据用于 .etlog 序列化（主线程调用）
  QJsonArray flushSamples();

  // 清空所有订阅和数据
  void clear();

 private:
  QHash<QPair<QString,QString>, QList<MonitorTapInfo>> lookup_table_;
  QHash<QPair<int,int>, SampleCallback> subscribers_;
  QList<MonitorSample> buffer_;                // 全主线程访问，无需锁
  QList<MonitorTreeEntry> tree_cache_;
};
```

### StepRunner 新增信号

```cpp
// StepRunner.h
signals:
  void hardwareOperationFinished(const QString& deviceId,
                                  const QString& portName,
                                  const QByteArray& rawFrame,
                                  double rawValue,
                                  double engValue);
```

发射时机：`execSet`/`execCheck`/`execVerify` 中硬件读写成功后、return 前发射，与 PASS/FAIL 无关。异常不发射。`execDelay`/`execLoop`/`execWhile`/`execIf`/`execWait` 不发射。

emit 处填充：AD/DA `rawFrame=QByteArray(), rawValue=encode().toDouble()`；帧类 `rawFrame=帧字节, rawValue=0.0`。

- [ ] **Step 2: 实现 MonitorManager.cpp**

关键逻辑：

**loadFromTopology**：遍历拓扑 JSON 的 `monitors[]` 数组。对每个 monitor，遍历 **`monitors[].taps[]`**（无 channels 层）。每个 tap 的 JSON key 是 `productName`/`portName`/`deviceName`/`devicePort`/`deviceId`/`displayMode`（注意 connection 用短名 `product`/`port`/`device`，tap 用全名，别混）。直接用 `tap.deviceId + tap.devicePort` 为 key 插入 `lookup_table_`，value 是 `MonitorTapInfo{monitorIndex, channelIndex=taps下标, deviceId, devicePort}`。同时填充 `tree_cache_`。无需遍历 connections。

**onHardwareOpFinished**：用 `(deviceId, devicePort)` 查 `lookup_table_`。命中则对每个 `MonitorTapInfo` 构建 `MonitorSample`，追加到 `buffer_`，如果该通道有 subscriber 则调用其 callback。

**flushSamples**：遍历 `buffer_`，按 `(monitorIndex, channelIndex)` 分组，组装成设计文档中定义的 JSON 结构。返回 `QJsonArray`。清空 `buffer_`。

在 `execSet` / `execCheck` / `execVerify` 方法中，**硬件读写成功后、return 前发射**（与 PASS/FAIL 无关，CHECK 值不匹配但 read 成功也发射；异常不发射）：

```cpp
// execSet（写操作，eng=step.value 命令值，rawValue=encode 结果，rawFrame 空）
emit hardwareOperationFinished(signal.deviceId, signal.portName,
                                QByteArray(), rawValue, step.value);

// execCheck/execVerify（读操作，rawFrame=读到的帧字节，engValue=decode 结果）
// AD/DA 时 rawFrame 留空，rawValue 填 read 到的 double
emit hardwareOperationFinished(signal.deviceId, signal.portName,
                                rawFrame, rawValue, engValue);
```

注意：`execDelay`/`execLoop`/`execWhile`/`execIf`/`execWait` 不发射此信号。

void ExecutionPanelController::connectDashboard(ExecutionDashboard* dashboard) {
  if (!dashboard || !monitor_manager_) return;

  // MonitorManager tree → SignalTreePanel
  auto tree = monitor_manager_->monitorTree();
  dashboard->signalTreePanel()->setMonitorTree(tree);

  // SignalTreePanel checkbox → VisualizationArea
  connect(dashboard->signalTreePanel(), &SignalTreePanel::checkStateChanged,
          this, [this, dashboard](int mi, int ci, bool checked) {
    if (checked) {
      // 创建对应类型的 Visualizer
      auto* vis = createVisualizerFor(mi, ci);
      if (vis) {
        dashboard->visualizationArea()->addVisualizer(mi, ci, vis);
        // 订阅 MonitorManager
        monitor_manager_->subscribe(mi, ci,
            [vis](const MonitorSample& s) { vis->onSampleCaptured(s); });
      }
    } else {
      dashboard->visualizationArea()->removeVisualizer(mi, ci);
      monitor_manager_->unsubscribe(mi, ci);
    }
  });

  // RunStatusPanel 对接 StepRunner 信号
  // （已在 Engine 信号转发中处理，通过 ExecutionPanelController 中转）
}
