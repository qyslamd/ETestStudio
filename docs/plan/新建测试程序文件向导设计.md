# 新建测试程序文件向导设计

## 背景

`docs/plan/新建项目和新建文档向导设计方案.md` 规划了新建项目 + 6 类文件向导体系。
新建项目向导已打样完成，打样出了通用容器 `BaseWizardDialog`（QStackedWidget 页面栈 +
`WizardStepBar` 步骤条 + 淡入上滑转场 + 页脚导航）与模板卡片模式 `WizardTemplateCard`。

本设计针对**测试程序文件（.etprog）**向导：完整复刻
`docs/prototype/新建 测试程序文件向导设计.html` 的 4 步 UI，并接入现有新建入口
（`TestProgramManagerWidget` 侧边栏「新建测试程序」按钮）。

## 问题陈述

1. 当前 `TestProgramManagerWidget::onNewTestProgram()` 仅弹 `QInputDialog::getText`
   取文件名后创建空 `.etprog`，无模板/用例/步骤配置能力。
2. HTML 原型是 4 步向导（模板 / 程序信息 / 用例与步骤 / 完成），含用例管理、步骤表格
   （命令彩色徽章 + 操作按钮）、添加/编辑步骤模态框、摘要——需在 Qt Widgets 下复刻。
3. 原型的数据模型与现有 `TestProgramData` 存在差异，需要映射层（见「数据模型差异与决策」）。

## 视觉基准

- 原型：`docs/prototype/新建 测试程序文件向导设计.html`（Fluent 风格，居中卡片布局）。
- Qt Widgets 无法实现 CSS `backdrop-filter` 模糊，以半透明卡片 + 阴影 + 圆角近似
  （与新建项目向导一致）。
- 颜色统一走 13 主题 QSS 语义色系统，由脚本注入；禁止 `setStyleSheet` 硬编码。

- `TestProgramEditorWidget::loadProgramToUi` 用 `StepTableWidget` 填 setup/teardown/cases，

  （单一 double 容差），与 .etprog 的 `ToleranceSpec{min,max,enabled}` 不匹配——**既有问题**，
  非本任务引入，仅记录。

### 扁平模型不变量与操作语义（决策 #1 的配套规格）

**扁平模型**

```cpp
struct WizardStep {
  QString cmd;        // SET/CHECK/VERIFY/WAIT/DELAY/LOOP/WHILE/IF/ELSE/END_*
  QString target;
  QString value;
  QString tolerance;
  QString timeout;
  QString condition;  // ==, !=, >, <, >=, <=（仅 WAIT/WHILE/IF）
  QString loopCount;
  bool parent = false;  // 位于控制流块体内（缩进显示）
};
struct WizardCase {
  QString name;
  QVector<WizardStep> steps;
};
```

**不变量**（单层嵌套下恒成立）：

1. 控制流起始（LOOP/WHILE/IF）与其配对 END 之间只能有**叶子步骤**（parent=true），
   不得再有控制流起始。
2. parent 行只能出现在「未配对的控制流起始」与对应 END 之间。
3. 同一时刻至多一个未配对控制流起始（单层保证，天然满足）。
4. END_LOOP/END_WHILE/END_IF 必须紧跟其最后一个 body 叶子之后；ELSE 只能出现在 IF
   块内，且 THEN 分支非空。

**操作语义**：

| 操作 | 规则 |
|---|---|
| 添加步骤 | StepEditDialog 处于块体内时禁用 LOOP/WHILE/IF 命令项（叶子命令含 CHECK 仍可用）；新增控制流命令时**自动追加配对 END 行**；IF 新增默认 IF+END_IF（无 ELSE），编辑时勾选「包含 ELSE 分支」插入 ELSE 行（见 StepEditDialog） |
| 编辑命令类型 | 控制流↔控制流（LOOP→WHILE）：同步改名 END 行；控制流→叶子：删除配对 END 行（及内部 ELSE 行），**块内 body 叶子 parent 置 false、整体上提为顶层叶子**；叶子→控制流：仅当不在块体内，自动追加 END 行；叶子→叶子：无配对影响 |
| 删除步骤 | 删除控制流起始：连同配对 END/ELSE 及块内 body 一并删除（弹确认「将同时删除块内 N 条子步骤」）；END/ELSE 行**禁止删除**（操作列隐藏删除按钮，与 HTML 一致）；body 叶子正常删除；**删除最后一个 body 叶子使 LOOP/WHILE 空体时弹确认**（空体在编辑器校验不过） |
| 上移/下移 | **只允许同级相邻交换**：顶层叶子只与顶层叶子交换，body 叶子只在块内交换（上移止于起始、下移止于 END）；块是原子单元，**叶子不可与 START/END 行跨边界交换**（否则 parent 标志悬空）；END 行上移=整块上移、下移=整块下移；ELSE 不可移动 |
| 翻译层防御 | `buildNestedSteps` 扫描到违反不变量的结构（块体嵌套起始、END 不匹配、THEN 空、**LOOP/WHILE 空体**），`LOG_ERROR` + QMessageBox 报错 + **拒绝保存**，不静默丢弃；由 `onCreateValidate()`（决策 #13）在向导内就地触发 |

### 模板静态数据

转译 HTML JS `templates`（扁平步骤，parent 标记）：

- **empty**：1 用例「默认用例」，0 步骤。
- **basic**：1 用例「信号测试」，SET(电压输出, 5.0) / WAIT(电压输出, ==, 5.0, 5000) /
  VERIFY(电压输出, 5.0, 容差 0.05, 超时 30000)。
- **loop**：1 用例「循环测试」，LOOP(循环次数 5) [ SET(3.3) / DELAY(100) / VERIFY(3.3) ]
  END_LOOP。
- **composite**：2 用例——
  - 「初始化」：SET(电压输出, 0) / SET(电流输出, 0)。
  - 「主测试」：SET(电压输出, 5.0) / VERIFY(电压输出, 5.0) /
    IF(电压输出, >=, 5.0) [ SET(状态标志, 1) ] ELSE [ SET(状态标志, 0) ] END_IF。

### 扁平 → 嵌套翻译（buildNestedSteps）

- 输入：`QVector<WizardStep>` 扁平列表；输出：`QVector<TestStepData>`（可含 subSteps/elseSubSteps）。
- 单遍扫描 + 深度计数栈（单层下栈深至多 1）：
  - LOOP/WHILE → 生成控制流 `TestStepData`，递归收集 body 至匹配 `END_LOOP`/`END_WHILE`。
  - IF → 收集至 `END_IF`，遇 `ELSE` 拆分为 subSteps / elseSubSteps。
  - ELSE / END_* 为结构符号，不产出步骤。
  - 其余为叶子步骤。
- 字段映射：
  - value 文本 → QVariant：数值可解析则 double，否则原字符串。
  - tolerance 文本 t → `ToleranceSpec{min=v−t, max=v+t, enabled=true}`（仅 SET/CHECK/VERIFY）。
  - timeout → timeoutMs；DELAY 的 value → delayMs。
  - condition 运算符 + 目标 + 值 → `ConditionExpr{target,op,value}`（WAIT/WHILE/IF）。
  - CHECK：原样保留 `TestStepData{cmd="CHECK", value, tolerance}`，翻译层**显式将 timeoutMs
    置 0** 以表达同步语义（引擎 `execCheck` 不使用 timeoutMs，取值无害）。
  - LOOP/WHILE：loopCount；WHILE 条件来自条件字段。
- 结构防御：违反不变量的结构（块体嵌套起始、END 不匹配、THEN 空、LOOP/WHILE 空体）
  → `LOG_ERROR` + 弹窗报错 + 拒绝保存（见「操作语义」翻译层防御行）。
