# 新建文件引导向导设计方案

## 问题陈述

File 菜单（Application Button 的 QMenu）当前没有「新建文件」入口，创建文件只能通过
侧边栏分类树（右键菜单 / 加号按钮）。项目打开后缺少一个统一、可发现的入口：
在 File 菜单放「新建文件」，点击后弹出**引导 wizard**，让用户先选文件类型，
再派发到对应的具体向导（协议 / 拓扑 / 测试程序）。

## 架构回顾

- File 菜单 = Ribbon Application Button 的 QMenu（`MainWindow.cpp` setupRibbon 内
  `app_menu`，约 2262 行）。
- 各类型文件创建统一在 `ProjectStructureWidget::createNewFile(categoryId, extension,
  baseName)`，按 `extension` 分支：`eprotox`→ProtocolFileWizard、
  `etopo`→TopologyFileWizard、`etprog`→TestProgramWizard、其余→空文件；
  内部处理目标目录、重名拦截、序列化与树刷新。
  **注意：该方法当前为 private，本设计需将其声明移入 public 区（审查 🔴1）。**
- `MainWindow` 可经 `sidebar_->pageById(PageId::kProjectOverview)` +
  `qobject_cast<ProjectStructureWidget*>` 触达该对象。
- 菜单启停已有模式：`close_project_action_->setEnabled(true/false)` 在项目
  打开/关闭时切换（MainWindow 1565 / 1785 行）。
- 复用 `BaseWizardDialog` + `WizardTemplateCard`（4 个向导已打样的卡片模式）。
- 最近修复的 `AnimationDialog` Linux re-parent 到顶层窗口，保证向导覆盖 MainWindow。

## 方案选项及理由

### 引导 wizard 派发方式
- **选项 A（选定）**：引导 wizard 单页选文件类型 → 点「创建」→ 引导关闭 →
  MainWindow 调 `createNewFile(...)` 打开对应具体向导（顺序派发）。
  理由：避免嵌套两个 frameless 遮罩对话框；具体向导逻辑完全复用，不重复实现。
- 选项 B：具体向导页内嵌进引导。不选：嵌套对话框复杂、动画/模态冲突。

### 文件类型范围
- **选项 A（选定）**：仅 3 个有向导的类型：协议（.eprotox）、拓扑（.etopo）、
  测试程序（.etprog）。
- 选项 B：加脚本/配置空文件。不选：引导 wizard 的价值在向导化创建；空文件
  侧边栏已可建，V1 聚焦。

### 入口位置与启停
- File 菜单顶部（「关闭项目」之上）加「新建文件」action，图标 `file_new`；
  项目打开时 `setEnabled(true)`，关闭时 `setEnabled(false)`（跟随
  `close_project_action_` 的启停点）。

### 顺带修复
- `MainWindow.cpp` 2247-2254「退出登录」connect 两遍（logout 执行两次），
  删除重复的一处。

## 决策记录

1. 新增 `NewFileGuideWizard`（`BaseWizardDialog`，1 页）：
   3 张 `WizardTemplateCard`（协议/拓扑/测试程序），`QButtonGroup` 互斥；
   `onCreateValidate` 校验已选类型；暴露 `selectedCategoryId() /
   selectedExtension() / selectedBaseName()`。
2. 类型映射表：protocol→(`protocol`,`eprotox`,`新建协议文件`,icon `file_eproto`)；
   topology→(`topology`,`etopo`,`新建拓扑文件`,icon `file_etopo`)；
   testprog→(`testprog`,`etprog`,`新建测试程序`,icon `testprogram`)。
3. File 菜单顶部插入「新建文件」action；项目开/关时 setEnabled 联动。
4. 点击 → `NewFileGuideWizard wizard(this)` exec==Accepted →
   从 `sidebar_` 取 `ProjectStructureWidget` →
   `createNewFile(selectedCategoryId(), selectedExtension(), selectedBaseName())`。
   **审查 🟡3 采纳**：`MainWindow` 缓存 `project_structure_widget_` 成员
   （initSignalsLate 中经 `pageById` 一次 qobject_cast 赋值），派发复用缓存，
   避免每点一次就线性查找。
5. `ProjectStructureWidget.h`：将 `createNewFile` 声明从 `private:` 移入 `public:`
   （审查 🔴1）。
6. 删除重复的「退出登录」connect（保留一处）。
6. 复用现有 QSS：卡片走 `templateCard*` 通用样式；引导卡片 objectName 沿用
   `templateCard`（无需新增 QSS 块）。

## 详细设计

### 文件与类

| 文件 | 说明 |
|------|------|
| 新增 `src/app/wizards/NewFileGuideWizard.h/.cpp` | 单页引导向导 |
| 修改 `src/app/MainWindow.cpp` | File 菜单 action + 启停 + 派发 + 修复重复 connect |
| 修改 `src/app/CMakeLists.txt` | 注册 NewFileGuideWizard |

`NewFileGuideWizard : BaseWizardDialog`：
- `setHeader("file_new", "新建文件", "选择要创建的文件类型")`
- `setCreateButtonText("创建文件")`
- 内部嵌套 `TypePage : WizardPage`：3 张卡片（`WizardTemplateCard`），
  `QButtonGroup` 互斥；`selectedType()` 返回卡片 `type` 属性
- 类型→(category/ext/base) 静态映射在向导内，暴露三个查询方法

### 派发流程

```
File 菜单「新建文件」（项目已打开）
  └─ NewFileGuideWizard.exec() == Accepted
       ├─ 取 selectedCategoryId / selectedExtension / selectedBaseName
       └─ sidebar_->pageById(kProjectOverview) → qobject_cast<ProjectStructureWidget*>
            → createNewFile(category, ext, base)   // 复用既有向导+序列化+目录
```

### 启停点

在 `close_project_action_->setEnabled(true)`（项目打开）处同步 `setEnabled(true)`；
在 `setEnabled(false)`（项目关闭）处同步 `setEnabled(false)`。

## 验证

1. `scripts/build_ninja.bat -t debug -m ETestStudio` 编译通过。
2. 手动（GUI 需人工确认）：
   - 未打开项目：File 菜单「新建文件」禁用
   - 打开项目后：可用；点击弹引导 wizard，3 张卡片可选
   - 选协议/拓扑/测试程序 → 对应具体向导打开，创建的文件落在正确目录
   - 「退出登录」只触发一次 logout
