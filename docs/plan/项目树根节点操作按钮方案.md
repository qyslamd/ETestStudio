# 项目树根节点操作按钮方案

## 问题陈述

项目树（`ProjectStructureWidget`）的根节点当前仅显示项目名称和图标，没有交互能力。用户需要频繁执行以下操作但缺少快捷入口：

1. **刷新项目树**：文件系统变化后需手动等待 watcher 刷新，无即时刷新手段
2. **显示/隐藏"其他文件"**：项目中杂散文件（不属于任何标准分类）干扰视线，需要一键隐藏
3. **同步定位当前编辑文件**：在编辑器间切换后，需手动在树中找对应节点

目标：在根节点行右侧绘制三个图标按钮（刷新、显示全部、同步文档），支持 hover 高亮和点击交互。

## 架构回顾

### ProjectTreeDelegate 现状

`src/app/widgets/ProjectTreeDelegate.h` (24行) / `.cpp` (89行)：

- 继承 `QStyledItemDelegate`，有 `Q_OBJECT` 宏
- 仅实现 `paint()` override，无 `sizeHint()`、无 `editorEvent()`

### 1. ProjectTreeDelegate 改造

#### 1.1 头文件新增

使用 `#pragma once`（与 CLAUDE.md 规范一致，替换现有 `#ifndef` 风格）。

```cpp
#pragma once

#include <QStyledItemDelegate>

namespace etest::app {

class ProjectTreeDelegate : public QStyledItemDelegate {
  Q_OBJECT
 public:
  explicit ProjectTreeDelegate(QObject* parent = nullptr);

  void paint(QPainter* painter, const QStyleOptionViewItem& option,
             const QModelIndex& index) const override;
  QSize sizeHint(const QStyleOptionViewItem& option,
                 const QModelIndex& index) const override;
  bool editorEvent(QEvent* event, QAbstractItemModel* model,
                   const QStyleOptionViewItem& option,
                   const QModelIndex& index) override;

 signals:
  void refreshRequested();
  void showAllToggled(bool showAll);
  void syncRequested();

 private:
  void drawBadge(QPainter*, const QStyleOptionViewItem&,
                 const QString&, const QColor&) const;
  void drawRootButtons(QPainter*, const QStyleOptionViewItem&,
                       const QModelIndex&) const;

  enum class RootButton { None = -1, Refresh = 0, ShowAll = 1, SyncDoc = 2 };
  static QRect rootButtonRect(const QStyleOptionViewItem& option,
                              RootButton btn);
  static RootButton hitTestRootButton(const QStyleOptionViewItem& option,
                                      const QPoint& pos);

  bool show_all_ = true;  // 默认显示全部；不持久化，项目关闭后重置
};
```

#### 1.2 paint() 逻辑

```
paint(painter, option, index):
  if nodeType == "root":
    // 保留右侧 60px 空间给三个按钮
    opt.rect.setWidth(opt.rect.width() - 60)
    QStyledItemDelegate::paint(painter, opt, index)
    drawRootButtons(painter, option, index)
  else if 有 badge role:
    现有 badge 逻辑（不变）
  else:
    默认绘制
```

#### 1.3 drawRootButtons() 实现

- 从右往左排列三个按钮：SyncDoc → ShowAll → Refresh
- 每个按钮 16×16，间距 4px，右侧 margin 8px
- hover 状态从 `index.data(kRootButtonHoverRole)` 读取（与 OpenFileDelegate 的 CloseBtnHoverRole 模式一致）
- 图标通过 `AppIconProvider::instance().icon("name").paint()` 绘制
- ShowAll 按钮根据 `show_all_` 状态切换图标名：`show_all_ ? "eye" : "eye_closed"`

#### 1.4 editorEvent() 实现

hover 状态通过 `model->setData(index, buttonIndex, RootButtonHoverRole)` 写入 model，与 `OpenFileDelegate` 的 `CloseBtnHoverRole` 模式一致。`paint()` 从 model 读取 hover 状态，无需 mutable。

```cpp
// 新增 Role 常量（ProjectTreeDelegate.h 或 .cpp 中）
static constexpr int kRootButtonHoverRole = Qt::UserRole + 10;

bool editorEvent(QEvent* event, QAbstractItemModel* model,
                 const QStyleOptionViewItem& option,
                 const QModelIndex& index) {
  if (index.data(NodeTypeRole) != "root")
    return QStyledItemDelegate::editorEvent(event, model, option, index);

  auto* me = dynamic_cast<QMouseEvent*>(event);
  if (!me)
    return false;

  switch (me->type()) {
    case QEvent::MouseMove: {
      RootButton btn = hitTestRootButton(option, me->pos());
      int newHover = static_cast<int>(btn);
      int oldHover = index.data(kRootButtonHoverRole).toInt();
      if (newHover != oldHover) {
        model->setData(index, newHover, kRootButtonHoverRole);
      }
      return false;
    }
    case QEvent::MouseButtonRelease: {
      if (me->button() != Qt::LeftButton)
        return false;
      RootButton btn = hitTestRootButton(option, me->pos());
      if (btn == RootButton::None)
        return false;
      switch (btn) {
        case RootButton::Refresh:
          emit refreshRequested();
          break;
        case RootButton::ShowAll:
          show_all_ = !show_all_;
          emit showAllToggled(show_all_);
          break;
        case RootButton::SyncDoc:
          emit syncRequested();
          break;
        default:
          break;
      }
      return true;
    }
    case QEvent::ToolTip: {
      RootButton btn = hitTestRootButton(option, me->pos());
      if (btn != RootButton::None) {
        QStringList tips = {"刷新项目树", "显示/隐藏其他文件",
                            "定位当前编辑文件"};
        QToolTip::showText(me->globalPos(),
                           tips[static_cast<int>(btn)], nullptr);
        return true;
      }
      break;
    }
    default:
      break;
  }
  return false;
}
```

`drawRootButtons()` 中读取 hover 状态：
```cpp
int hoveredBtn = index.data(kRootButtonHoverRole).toInt();
if (static_cast<int>(btn) == hoveredBtn) {
  // 绘制 hover 背景
}
```

```
|  ...项目名称...  [Refresh] [ShowAll] [SyncDoc]  |
                 ← 从右往左排列 →
```

- SyncDoc: `x = right - 16 - 8`, `y = center - 8`
- ShowAll: `x = SyncDoc.x - 4 - 16`

#### 1.6 sizeHint() 实现

```cpp
QSize sizeHint(const QStyleOptionViewItem& option,
               const QModelIndex& index) const override {
  int h = qMax(option.fontMetrics.height() + 8, 24);
  if (index.data(NodeTypeRole) == "root")
    h = qMax(h, 28);  // root 行稍高
  return QSize(0, h);
}
```

### 2. ProjectStructureWidget 连接

#### 2.1 initUi() 中创建 delegate

```cpp
tree_delegate_ = new ProjectTreeDelegate(this);
tree_view_->setItemDelegate(tree_delegate_);
```

#### 2.2 initSignals() 中连接信号

```cpp
// 刷新按钮 → 清空并重建树（buildTree() 不会自动清空 model）
connect(tree_delegate_, &ProjectTreeDelegate::refreshRequested,
        this, [this]() {
  model_->clear();
  root_item_ = nullptr;
  buildTree();
});

// 显示全部按钮 → 切换"其他文件"分类可见性
connect(tree_delegate_, &ProjectTreeDelegate::showAllToggled,
        this, [this](bool showAll) {
  if (!root_item_) return;
  // 遍历 root_item_ 的子节点，找到 CategoryIdRole == "other" 的项
  for (int i = 0; i < root_item_->rowCount(); ++i) {
    auto* child = root_item_->child(i);
    if (child && child->data(CategoryIdRole).toString() == "other") {
      tree_view_->setRowHidden(i, root_item_->index(), !showAll);
      break;
    }
  }
});

// 同步按钮 → 定位当前编辑器文件
connect(tree_delegate_, &ProjectTreeDelegate::syncRequested,
        this, [this]() {
  // 由 MainWindow 路由：获取 EditorManager 当前文件路径
  emit syncCurrentEditorRequested();
});
```

#### 2.4 MainWindow 中连接 EditorManager

```cpp
// 自动同步：编辑器切换时定位树节点（用 RelativePathRole 精确匹配，避免同名文件误中）
connect(editor_manager_, &EditorManager::currentEditorChanged,
        this, [this](IEditor* editor) {
  if (!editor) return;
  QString filePath = editor->filePath();
  QString relPath = QDir(project_path_).relativeFilePath(filePath);
  project_structure_widget_->locateFileByPath(relPath);
});

// 手动同步按钮
connect(project_structure_widget_, &ProjectStructureWidget::syncCurrentEditorRequested,
        this, [this]() {
  QString filePath = editor_manager_->currentFilePath();
  if (!filePath.isEmpty()) {
    QString relPath = QDir(project_path_).relativeFilePath(filePath);
    project_structure_widget_->locateFileByPath(relPath);
  }
});
```

> **注意**：需在 `ProjectStructureWidget` 中新增 `locateFileByPath(relPath)` 方法，按 `RelativePathRole` 匹配而非 `DisplayRole`，避免不同目录下同名文件误中。

## 决策记录

| 决策 | 选项 | 选择 | 理由 |
|------|------|------|------|
| 按钮位置 | 根节点行右侧 / 独立工具栏 | 行右侧 | 不额外占空间，与 badge 风格一致 |
| 按钮数量 | 3 个 | 3 个 | 覆盖刷新/过滤/同步三个核心操作 |
| show_all 状态存储 | delegate 内 / model item data / QSettings | delegate 内 | 简单，不污染数据模型；状态随 delegate 生命周期，项目关闭后重置（v1 可接受） |
| 同步方式 | 手动按钮 / 自动同步 | 两者都支持 | 按钮提供即时定位，EditorManager 信号提供自动跟踪 |
| 文件匹配方式 | DisplayRole(文件名) / RelativePathRole(相对路径) | RelativePathRole | 避免不同目录下同名文件误中 |
| hover 状态追踪 | mutable 成员 / model data role | model data role | 与 OpenFileDelegate 的 CloseBtnHoverRole 模式一致 |
| 头文件保护符 | #ifndef / #pragma once | #pragma once | 与 CLAUDE.md 规范一致 |
