1.
CAN采用标准帧格式，数据帧包含11bit CAN ID,波特率为250kbps；传输数据字节序采用Intel模式，即低字节在前，高字节在后。
通讯协议：工装（模拟惯导）向被测设备发送：
CAN ID 0x152：发送周期 50ms，DLC8。
字节顺序	内容
0~1	方向角
2~3	保留
4~5	俯仰角
6~7	倾斜角

CAN ID 0x162；发送周期 50ms DLC:8。
字节顺序	内容
0~3	经度
4~7	纬度

CAN ID 0x172；发送周期 50ms DLC:8。
字节顺序	内容
0	保留
1~3	高程
4~7	里程

CAN ID 0x312；发送周期 50ms DLC:8。
字节顺序	内容
0	惯导工作状态
1	惯导导航状态
2~3	故障提示信息
4~5	对准剩余时间

被测设备向工装（模拟惯导）发送数据：
CAN ID 0x631:发送条件：触发 DLC:8。
字节顺序	内容
0	控制命令序号
1	命令字
2	寻北方式
说明：收到此帧数据，点亮提示灯

2.
系统采用TTCAN，在规定的时间窗口内发送数据。
TTCAN最大周期为20ms，小周期为1ms，ID=0x33A为被测设备发出的定时消息，工装收到ID=0x33A后重新开始计时，在0.25ms、5.25ms、10.25ms和12.25ms发送ID=0x317的数据帧，在0.5ms、10.05ms发送ID=0x318的数据帧，在1.5ms、11.05ms发送ID=0x378的数据帧。
通讯协议：被测设备向工装（模拟系统CAN）发送数据：
CAN ID 0x33A;DLC:8。
字节顺序	内容	说明
0~1	sWPCU_ZL_JiShu	在界面显示即可
2	sWPCU_ZL_1Ji	在界面显示即可
3	sWPCU_ZL_2Ji	在界面显示即可
4~5	sWPCU_ZL_CanShu1	在界面显示即可
6~7	sWPCU_ZL_CanShu2	在界面显示即可
说明：工装收到数据后界面上系统CAN接收灯亮
